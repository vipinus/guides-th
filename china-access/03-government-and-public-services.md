# 03 · ใช้เว็บไซต์ภาครัฐและบริการสาธารณะของจีน

## อาการที่เจอ

แพลตฟอร์มบริการภาครัฐแห่งชาติ เว็บบริการภาครัฐระดับมณฑลและเมือง สำนักงานภาษีออนไลน์ การเช็กประกันสังคมและกองทุนสำรองเพื่อที่อยู่อาศัย CHSI (เว็บข้อมูลการศึกษาของจีน) และ 12306 (ระบบจองตั๋วรถไฟ): จากต่างประเทศ ถ้าไม่เปิดไม่ขึ้น ก็เปิดได้แต่รหัสยืนยันไม่มาสักที หรือสแกนใบหน้าไม่ผ่าน

## แยกให้ออกก่อนว่าปัญหาอยู่ชั้นไหน

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| หน้าเว็บเปิดไม่ขึ้นเลย หรือหมดเวลา | เว็บเปิดให้แค่ IP ในจีนแผ่นดินใหญ่ หรือแพ็กเก็ตหายบนเส้นทางข้ามประเทศ | เปลี่ยนเป็น IP จีน |
| เปิดได้ แต่รหัสยืนยันทางมือถือไม่มา | SMS ต้องส่งไปที่เบอร์โทรศัพท์จีน | เก็บซิมจีนไว้และเปิดโรมมิ่งต่างประเทศเพื่อรับ SMS |
| รหัสยืนยันมาแล้ว แต่สแกนใบหน้าไม่ผ่าน | ใช้แอปเวอร์ชันจาก App Store ต่างประเทศ หรือติดที่สิทธิ์ใช้กล้อง | ติดตั้งแอปเวอร์ชันจีน และอนุญาตให้ใช้กล้อง |
| ขึ้นว่า "สภาพแวดล้อมเครือข่ายผิดปกติ" | ระบบตรวจความเสี่ยงจับลักษณะของพร็อกซีได้ | ลองใหม่ด้วยภูมิภาคทางเข้าอื่น หรือใช้เราเตอร์ (ดูเหมือนเน็ตบ้านมากกว่า) |

## 12306 แยกพูดต่างหาก

12306 ไวต่อ IP มาก ใช้ IP ต่างประเทศอาจเปิดหน้าแรกไม่ขึ้นด้วยซ้ำ เปลี่ยนเป็น IP จีนแล้ว: สมัครต้องใช้เบอร์โทรศัพท์จีน ซื้อตั๋วต้องใช้เอกสารยืนยันตัวตนชื่อจริง และจ่ายผ่านบัตรธนาคารจีนหรือ Alipay ต้องมีครบสามอย่างนี้จึงซื้อตั๋วได้ ช่วงแย่งตั๋วยังจำกัดความถี่คำขอต่อหนึ่ง IP ด้วย อย่าเปิดหลายหน้าต่างแล้วกดรีเฟรชรัวๆ

## CHSI และการตรวจสอบวุฒิการศึกษา

CHSI เองไม่ได้เข้มงวดกับ IP ต่างประเทศเป็นพิเศษ ปัญหาหลักคือช้า แต่ SMS ยืนยันก็ส่งไปที่เบอร์จีนเท่านั้นเหมือนกัน ก่อนตรวจสอบวุฒิการศึกษา นักศึกษาที่อยู่ต่างประเทศควรเช็กก่อนว่าเบอร์จีนของตัวเองยังรับ SMS ได้

## คำแนะนำหนึ่งข้อ

ธุระกับหน่วยงานรัฐมักมีแค่ปีละครั้งสองครั้ง ถ้าต้องมาหาเส้นทางกระชั้นชิดทุกครั้งจะวุ่นมาก ตั้งเส้นทางเข้าจีนไว้เป็นจุดเชื่อมต่อประจำหนึ่งจุด ใช้เสร็จก็สลับกลับ สะดวกกว่าตั้งค่าใหม่ทุกครั้ง
