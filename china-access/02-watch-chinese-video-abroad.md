# 02 · ดูวิดีโอจีนจากต่างประเทศ

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/overseas-video?utm_source=github&utm_content=china-access-02

## ทำไมถึงดูไม่ได้

แพลตฟอร์มซื้อลิขสิทธิ์มาเฉพาะในจีนแผ่นดินใหญ่ IP ต่างประเทศจึงถูกบล็อกทั้งหมด นี่ไม่ใช่ปัญหาทางเทคนิค และทางแก้มีทางเดียวคือเปลี่ยน IP

## แต่ละแพลตฟอร์มต่างกันอย่างไร

| แพลตฟอร์ม | เว็บ | แอป | หมายเหตุ |
|---|---|---|---|
| iQIYI | เปลี่ยน IP ก็พอ | เปลี่ยน IP ก็พอ | iQIYI ฉบับต่างประเทศเป็นคนละแอป เนื้อหาน้อยกว่า อย่าลงผิดตัว |
| Tencent Video | เปลี่ยน IP ก็พอ | เปลี่ยน IP ก็พอ | WeTV ซึ่งเป็นฉบับต่างประเทศก็เช่นกัน |
| Youku | เปลี่ยน IP ก็พอ | เปลี่ยน IP ก็พอ | |
| Mango TV | เปลี่ยน IP ก็พอ | เปลี่ยน IP ก็พอ | |
| Bilibili | เนื้อหาส่วนใหญ่ดูได้อยู่แล้ว | เหมือนกัน | มีแค่อนิเมะและสารคดีบางเรื่องที่จำกัดภูมิภาค |
| Yangshipin / CCTV | เปลี่ยน IP ก็พอ | เหมือนกัน | ช่องถ่ายทอดสดไวต่อ IP ที่สุด |

**หลุมพรางของแอปฉบับต่างประเทศ**: ค้นชื่อภาษาจีนของ iQIYI ในสโตร์ต่างประเทศ มักจะเจอ iQIYI ฉบับนานาชาติ ซึ่งคลังเนื้อหาต่างกันโดยสิ้นเชิง ถ้าอยากดูคลังของจีน ต้องติดตั้งแอปฉบับจีน iPhone ต้องใช้ Apple ID ภูมิภาคจีน ส่วน Android ติดตั้งไฟล์ APK ได้โดยตรง

## เชื่อมต่อแล้ว แต่ยังขึ้นว่าติดลิขสิทธิ์

ถ้า IP ขาออกเป็นจีนแผ่นดินใหญ่แล้ว แต่เว็บยังขึ้นว่าติดลิขสิทธิ์ เก้าในสิบครั้งคือ**IPv6 หรือ DNS ของเครื่องวิ่งอ้อมเส้นทาง** ตั้งแต่เดือนกันยายน 2026 วิธีเชื่อมต่อแบบทั้งเครื่องทั้งสามวิธีของ LeoTun บล็อก IPv6 ที่ฝั่งเส้นทางแล้ว ส่วนการตั้งค่า Hiddify ที่นำเข้าก่อนเดือนกันยายน ต้องลบทิ้งแล้วสแกน QR โค้ดนำเข้าใหม่ ขั้นตอนตรวจสอบ ดู[IPv6 และ DNS คือช่องที่หลุดออกไป](../troubleshooting/03-ipv6-and-dns-leak.md)

## ดูบนทีวี

ทีวีและกล่องรับสัญญาณติดตั้งไคลเอนต์ไม่ได้ จึงมีสองทาง:

1. **ใช้เราเตอร์**: ตั้งเส้นทางเข้าจีนบนเราเตอร์แล้วเปิดการแยกเส้นทาง ทีวีที่ต่อ Wi-Fi นั้นก็ดูได้เลย ทั้งบ้านได้ประโยชน์ ดู[สำหรับผู้สูงอายุในบ้านและทีวี](../router/04-family-tv-and-router.md)
2. **แคสต์หน้าจอ**: เปิดเส้นทางเข้าจีนบนมือถือ แล้วแคสต์ขึ้นทีวี ง่าย แต่ต้องเปิดมือถือไว้ตลอด

## ความคมชัดของภาพ

1080p ต้องใช้ความเร็ว 5 Mbps ขึ้นไปอย่างสม่ำเสมอ ถ้าช่วงหัวค่ำภาพกระตุก ให้เลือกภูมิภาคที่ไฟเขียว หรือเปลี่ยนวิธีเชื่อมต่อ ถ้ายังกระตุก สาเหตุที่พบบ่อยคือเน็ตบ้านที่คุณใช้ การเลือกจุดเข้าที่อยู่ใกล้คุณและมีเส้นทางที่ปรับแต่งมาสำหรับเข้าจีนแผ่นดินใหญ่ ได้ผลกว่าการเปลี่ยนแพลตฟอร์ม
