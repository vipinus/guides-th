# 05 · เพลง พอดแคสต์ และหนังสือเสียง

## สิ่งที่คุณเจอ

ใน NetEase Cloud Music, QQ Music และ Kugou เพลงจำนวนมากเป็นสีเทา พร้อมข้อความว่า "ตามคำขอของเจ้าของลิขสิทธิ์ ขณะนี้ไม่สามารถเล่นในภูมิภาคของคุณได้" คอนเทนต์บางส่วนบน Ximalaya และ Qingting FM ก็เป็นแบบเดียวกัน

## สาเหตุ

เหมือนวิดีโอ คือเป็นเรื่องลิขสิทธิ์ตามภูมิภาค และตรวจแค่ IP เปลี่ยนเป็น IP จีนแล้วรีเฟรชรายการ เพลงสีเทาจะกลับมาทันที

## หมายเหตุของแต่ละแพลตฟอร์ม

| แพลตฟอร์ม | หมายเหตุ |
|---|---|
| NetEase Cloud Music | ตรวจ IP เข้มงวดที่สุด แต่พอเปลี่ยน IP แล้วก็ครบที่สุดเช่นกัน |
| QQ Music | บางเพลงต้องเป็นสมาชิก ซึ่งไม่ใช่ปัญหาเรื่อง IP |
| Kugou / Kuwo | เปลี่ยน IP ก็พอ |
| Ximalaya | อัลบั้มแบบเสียเงินบางอัลบั้มจำกัดภูมิภาค |

## เพลงที่ดาวน์โหลดไว้แล้ว

บางแอปตรวจภูมิภาคกับแคชในเครื่องด้วย เพลงที่ดาวน์โหลดก่อนเปลี่ยน IP จึงอาจเป็นสีเทาเหมือนกัน แค่เปิดแอปใหม่หลังเปลี่ยน IP ก็พอ ไม่ต้องดาวน์โหลดใหม่

## วิธีที่ไม่ต้องลงแรงมาก

เพลงใช้ข้อมูลน้อย ใช้**เว็บพร็อกซี**หรือวิธีที่ทำงานผ่านเบราว์เซอร์ก็พอ ไม่จำเป็นต้องให้ทั้งเครื่องผ่านเส้นทาง บนมือถือจะให้แค่แอปเพลงผ่านเส้นทาง (พร็อกซีรายแอป) แล้วให้แอปอื่นใช้เน็ตในประเทศตามปกติก็ได้ ประหยัดทั้งข้อมูลและแบตเตอรี่
