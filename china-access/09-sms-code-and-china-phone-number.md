# 09 · รหัสยืนยันไม่มาสักที และเบอร์โทรศัพท์จีน

## อาการที่คุณเห็น

รหัสยืนยันทาง SMS จากบริการภาครัฐ ธนาคาร 12306 (ระบบจองตั๋วรถไฟของจีน) และแอปต่างๆ ส่งมาที่มือถือของคุณไม่ได้ หรือขึ้นว่าส่งแล้วแต่ไม่มาถึงสักที

## สาเหตุ

รหัสยืนยันทาง SMS ส่งได้เฉพาะเบอร์โทรศัพท์จีน เมื่อคุณอยู่ต่างประเทศ: ไม่ได้เอาซิมจีนมาด้วย หรือเอามาแต่ไม่ได้เปิดโรมมิงต่างประเทศ หรือเบอร์ถูกระงับเพราะค้างชำระ เรื่องนี้ไม่เกี่ยวกับ IP และการเปลี่ยนเป็น IP จีนแก้ปัญหา SMS ไม่ได้

## วิธีแก้

1. **เก็บซิมการ์ดจีนไว้** เปิดโรมมิงต่างประเทศก่อนออกนอกประเทศ และเลือกแพ็กเกจรักษาเบอร์ ค่ายส่วนใหญ่รับ SMS ในต่างประเทศได้ฟรีหรือแทบฟรี
2. **มือถือสองซิม**: ใช้ซิมจีนแค่รับ SMS และใช้ซิมท้องถิ่นสำหรับเน็ต ใส่ทั้งสองซิมพร้อมกัน
3. **eSIM**: บางค่ายแปลงเบอร์จีนเป็น eSIM ได้ ติดตั้งบนมือถือที่รองรับ eSIM โดยไม่กินช่องใส่ซิม
4. **เบอร์เสมือนเชื่อถือไม่ได้**: เบอร์รับรหัสที่เช่ามาจากออนไลน์มักถูกแพลตฟอร์มขึ้นบัญชีดำ ห้ามใช้สมัครบริการภาครัฐหรือธนาคารเด็ดขาด

## รหัสมาแล้ว แต่ยืนยันไม่ผ่าน

- รหัสยืนยันมีอายุสั้น ปกติ 5 นาที ได้แล้วให้กรอกทันที
- ขอรหัสหลายครั้งในวันเดียวจะถูกจำกัด รอหนึ่งชั่วโมงแล้วลองใหม่
- สแกนใบหน้าไม่ผ่าน ส่วนใหญ่เป็นเรื่องเวอร์ชันแอปหรือสิทธิ์เข้าถึงกล้อง ให้ติดตั้งแอปฉบับจีนและอนุญาตให้ใช้กล้อง
