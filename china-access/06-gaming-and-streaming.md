# 06 · เกมเซิร์ฟเวอร์จีนและไลฟ์สตรีม

## เกม: ล็อกอินได้ แต่ปิงสูง

เกมเซิร์ฟเวอร์จีนส่วนใหญ่ไม่ได้บล็อก IP ต่างประเทศ ปัญหาอยู่ที่ความหน่วง ถ้าคุณอยู่ยุโรปหรืออเมริกาเหนือ ระยะทางถึงเซิร์ฟเวอร์ในจีนทำให้มีความหน่วงพื้นฐานที่หนีไม่พ้น แล้วยังมีอาการแกว่งและแพ็กเก็ตหายบนเส้นทางข้ามประเทศซ้อนเข้ามาอีก ออกมาเป็นอาการกระตุกและหลุด

สิ่งที่ "ตัวเร่งเกม" ทำคือ: ส่งทราฟฟิกของคุณไปจีนผ่านเส้นทางที่ดีกว่า ลดการอ้อมและการหายของแพ็กเก็ต เปลี่ยนการเชื่อมต่อที่แกว่งและหลุดบ่อยให้นิ่ง สำหรับเกมส่วนใหญ่ นี่คือเส้นแบ่งระหว่างเล่นได้กับเล่นไม่ได้

## เลือกจุดเชื่อมต่ออย่างไร

ภูมิภาคที่เลือกคือประเทศที่ทราฟฟิกออกไป: เกมเซิร์ฟเวอร์จีนให้เลือก**ภูมิภาคจีน** สิ่งที่ออกไปก็คือ IP จีน อย่าเลือกภูมิภาคที่ไม่รองรับ UDP อย่างเยอรมนีหรือฝรั่งเศส เกมแทบจะเชื่อมต่อไม่ได้เลย ลองหลายๆ จุด แล้วตัดสินจากค่าปิงที่เกมแสดง

## เลือกโปรโตคอล

เกมไวต่อการหายของแพ็กเก็ต จึงควรใช้โปรโตคอลที่วิ่งบน UDP และเลี่ยงภูมิภาคที่ไม่รองรับ UDP โปรโตคอลแบบ TCP จะส่งซ้ำเมื่อแพ็กเก็ตหาย ทำให้ปิงพุ่งหนัก

## ไลฟ์สตรีม

Douyin, Kuaishou, Douyu และ Huya จำกัด IP ต่างประเทศไม่เท่ากัน ส่วนใหญ่ดูได้แต่จำกัดความละเอียด พอเปลี่ยนเป็น IP จีนก็จะเลือกความละเอียดได้ครบ ไลฟ์สตรีมกินแบนด์วิดท์สูงต่อเนื่อง จึงควรเลือกจุดเชื่อมต่อที่แบนด์วิดท์เหลือเฟือ

## การยืนยันตัวตนด้วยชื่อจริง

เกมเซิร์ฟเวอร์จีนบังคับให้ยืนยันตัวตนด้วยชื่อจริง นี่เป็นข้อกำหนดระดับบัญชี ไม่เกี่ยวกับ IP เปลี่ยน IP ก็แก้ไม่ได้
