# เข้าบริการจีนจากต่างประเทศ · ทุกอย่างที่ต้องใช้ IP จีน

เมื่ออยู่นอกจีน บริการจีนจำนวนมากจะไม่ยอมให้ใช้ เพราะ IP ของคุณไม่ได้อยู่ในจีนแผ่นดินใหญ่ ไม่ว่าจะเป็นวิดีโอ เพลง บริการภาครัฐ ธนาคาร การจองตั๋ว หรือเกม เราเขียนแยกหนึ่งบทความต่อหนึ่งสถานการณ์ อธิบายให้ชัดว่า**ทำไมถึงถูกบล็อก แก้อย่างไร และมีหลุมพรางอะไรอีกบ้าง**

**บทความที่ถูกถามถึงมากที่สุด: [ปลดล็อกเว็บวิดีโอจีนจากต่างประเทศด้วยเราเตอร์](../router/06-unlock-chinese-video-with-router.md)** — ทีวี กล่องรับสัญญาณ และทุกอุปกรณ์ในบ้านตั้งค่าครั้งเดียว ต่อ Wi-Fi ปุ๊บก็ดู iQIYI, Tencent Video และ Yangshipin (CCTV) ได้ทันที
