# 08 · เลือกเส้นทางเข้าจีนอย่างไร: IP จีนมาจากไหน และของฟรีพลาดตรงไหน

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/choose-china-vpn?utm_source=github&utm_content=china-access-08

เส้นทางเข้าจีนทำแค่อย่างเดียว: ทำให้คำขอที่คุณส่งจากต่างประเทศไปถึง Tencent Video, NetEase Cloud Music หรือธนาคารออนไลน์ของคุณด้วย IP ของ**จีนแผ่นดินใหญ่** จึงต้องดูสองข้อก่อน: ขาออกเป็น IP แผ่นดินใหญ่จริงไหม และมีทราฟฟิกในเครื่องที่วิ่งอ้อมออกไปหรือเปล่า ความเร็ว ราคา และไคลเอนต์ค่อยดูทีหลัง

## IP จีนมาจากไหน

ผู้ให้บริการต้องมีเซิร์ฟเวอร์ของตัวเองในแผ่นดินใหญ่ ผู้ให้บริการคลาวด์ในจีนบังคับให้ลงทะเบียนชื่อจริงก่อนเปิดเครื่อง และคิดค่าแบนด์วิดท์ตามการใช้งาน ต้นทุนจึงสูงกว่าเครื่องในต่างประเทศมาก นี่คือเหตุผลที่บริการเข้าจีนที่ถูกต้องเกือบทั้งหมดเสียเงิน และทำไมจำนวนทางออกในจีนถึงมีจำกัด

ของทดแทนที่พบบ่อยคือเอาเครื่องในฮ่องกง ไต้หวัน หรือญี่ปุ่นมาอ้างว่าเป็น "เส้นทางเข้าจีน" ที่อยู่พวกนี้ใช้ได้กับบางโซนของ Bilibili ที่เปิดให้ฮ่องกง มาเก๊า และไต้หวัน แต่ Tencent Video, iQIYI และ Youku ยังขึ้นข้อจำกัดลิขสิทธิ์ ธนาคารออนไลน์และ 12306 ก็ยังมองว่าคุณอยู่ต่างประเทศ **วิธีแยก: หลังเชื่อมต่อ ให้เช็กว่า IP ลงทะเบียนอยู่ที่ไหน ต้องขึ้นว่า "จีน · มณฑลใดมณฑลหนึ่ง" ถึงจะนับ**

## ห้าข้อที่ต้องเช็กก่อนเลือก

| ข้อ | เช็กอย่างไร | ถ้าไม่ผ่านจะเห็นอะไร |
|---|---|---|
| ภูมิภาคขาออก | เช็กว่า IP ลงทะเบียนอยู่ที่ไหนหลังเชื่อมต่อ | ที่อยู่ฮ่องกง ไต้หวัน ญี่ปุ่น หรือเกาหลี |
| IPv6 และ DNS | ค้นหา "test ipv6" แล้วเปิดหน้าทดสอบ | ช่อง IPv6 แสดงประเทศที่คุณอยู่ → เว็บวิดีโอจะยังบล็อกคุณ ดู[การแก้ปัญหา 03](../troubleshooting/03-ipv6-and-dns-leak.md) |
| ไคลเอนต์ | เป็นโปรโตคอลมาตรฐานไหม (AnyConnect, OpenVPN, Hiddify) | มีแอปเฉพาะของเจ้านั้นตัวเดียว ถ้าถูกถอดออกจากสโตร์ก็ไม่มีอะไรให้ใช้ |
| แบนด์วิดท์ | เปิด 1080p ช่วงสองทุ่มถึงห้าทุ่มตามเวลาปักกิ่ง | กลางวันเร็ว ตกค่ำหมุนค้าง |
| หลายอุปกรณ์และเราเตอร์ | บัญชีเดียวได้กี่เครื่อง และต่อเราเตอร์ให้ทั้งบ้านได้ไหม | ทุกเครื่องต้องซื้อแยก |

## ทำไมเส้นทางเข้าจีนฟรีถึงหลุดบ่อย

ปัญหาไม่ได้อยู่ที่คำว่า "ฟรี" แต่อยู่ที่โครงสร้างต้นทุน แบนด์วิดท์ขาออกในแผ่นดินใหญ่ต้องจ่ายตามการใช้งาน บริการฟรีจึงเลือกได้แค่หนึ่งในสามทาง: ยัดคนหลายพันคนไว้บนเครื่องเดียว ทุกคนกระตุกช่วงพีค จำกัดปริมาณข้อมูลและเวลา ดูไปครึ่งทางก็เด้งให้จ่ายเงิน หรือหาเงินทางอื่น ด้วยการแทรกโฆษณา เก็บประวัติการท่องเว็บ หรือเอาเครื่องของคุณไปเป็นทางออกให้คนอื่น

ส่วนขยายเบราว์เซอร์ "เข้าจีน" ฟรียังมีจุดบอดอีกข้อ: มันพร็อกซีแค่คำขอหน้าเว็บของเบราว์เซอร์ ตัวเล่นวิดีโอ แอป และ DNS ของระบบไม่ได้ผ่านมัน อาการ "หน้าเว็บเปิดได้ แต่วิดีโอเล่นไม่ได้" จึงพบบ่อยมาก

ถ้าแค่ค้นอะไรนานๆ ครั้ง ของฟรีก็พอ แต่ถ้าดูซีรีส์ ฟังเพลง และทำธุรกรรมธนาคารออนไลน์ เวลาที่เส้นทางเสียเงินแบบนิ่งๆ ช่วยประหยัดให้ คุ้มกว่าค่าสมาชิกมาก กดรับทดลองใช้ 4 ชั่วโมงก่อน ลองดูสักครั้งช่วงพีคตอนค่ำ แล้วค่อยตัดสินใจ

## นักศึกษาต่างประเทศ นักเดินทาง และครอบครัว ควรตั้งค่าอย่างไร

- **นักศึกษาต่างประเทศ**: เน็ตหอพักส่วนใหญ่มี IPv6 ให้ใช้ไคลเอนต์ที่บล็อก IPv6 สำหรับธนาคารออนไลน์ CHSI และ 12306 ให้ต่อเส้นทางเข้าจีนเฉพาะตอนที่ต้องใช้ แล้วตัดเมื่อเสร็จ เพื่อลดโอกาสโดนระบบตรวจความเสี่ยงของบัญชี
- **เดินทางระยะสั้น**: ติดตั้งไคลเอนต์ Cisco หรือ Hiddify บนมือถือ นำเข้าด้วยการสแกน QR โค้ด ลงเครื่องปุ๊บก็ใช้ได้
- **ทั้งครอบครัวที่อยู่ต่างประเทศระยะยาว**: ต่อเราเตอร์ที่แฟลชเฟิร์มแวร์แล้วหนึ่งตัวเข้ากับเส้นทาง ทีวี กล่องรับสัญญาณ และมือถือของผู้สูงอายุไม่ต้องตั้งค่าอะไร ดู[ปลดล็อกเว็บวิดีโอจีนด้วยเราเตอร์](../router/06-unlock-chinese-video-with-router.md)

## ทดสอบตัวเอง 5 นาที

1. ต่อเส้นทางเข้าจีน ผลเช็ก IP แสดงมณฑลหนึ่งในจีนแผ่นดินใหญ่
2. หน้าทดสอบ IPv6 แสดงว่าใช้ไม่ได้ หรือแสดงเป็นที่อยู่ในแผ่นดินใหญ่เช่นกัน
3. เปิดซีรีส์ที่มีเฉพาะในจีนบน Tencent Video สักเรื่อง เล่นได้
4. เปิด 1080p อีกครั้งหลังสองทุ่มตามเวลาปักกิ่ง ไม่ค้างโหลดซ้ำๆ
5. เปลี่ยนไปใช้ทางออกในจีนอีกจุด แล้วทำสามข้อแรกซ้ำ

## คำถามที่พบบ่อย

**VPN เข้าจีนกับตัวเร่งความเร็วเข้าจีนต่างกันไหม?** ไม่ต่างกันในสาระสำคัญ "ตัวเร่ง" มักเป็นแอปที่ผู้ให้บริการเกมหรือวิดีโอทำขึ้นเฉพาะ ครอบคลุมแค่บางแอป ส่วน VPN คืออุโมงค์ที่ครอบทั้งเครื่อง

**ใช้โหนดฮ่องกงดู Tencent Video ได้ไหม?** ไม่ได้ ลิขสิทธิ์ครอบคลุมแค่แผ่นดินใหญ่

**บัญชีเดียวได้กี่เครื่อง?** สำหรับ LeoTun จำนวนที่เชื่อมต่อพร้อมกันเป็นไปตามแพ็กเกจ: ส่วนตัว 2 เครื่อง ครอบครัว 4 เครื่อง องค์กร 8 เครื่อง เราเตอร์นับเป็นหนึ่งเครื่อง อุปกรณ์ที่อยู่หลังเราเตอร์ไม่นับแยก ถ้าออนไลน์พร้อมกันเกินโควตาของแพ็กเกจ ก็อัปเกรดประเภทบัญชีชั่วคราวได้ (เวลาที่เหลือแปลงตามมูลค่าราคาเท่ากัน) แล้วเปลี่ยนกลับทีหลัง

**ใช้ Clash ได้ไหม?** ได้ LeoTun มีซับสคริปชัน sing-box ซับสคริปชัน Clash และลิงก์แชร์ hysteria2 ถ้าใช้ Clash Meta, Clash Verge, FlClash, Stash หรือตัวอื่นที่คล้ายกัน ให้คลิกปุ่ม "Clash subscription" (ซับสคริปชัน Clash) แล้ววาง URL ลงในรายการซับสคริปชันของไคลเอนต์ ไม่ต้องใช้ตัวแปลงซับสคริปชัน และอย่าใช้ลิงก์แชร์ ส่วน Clash ตัวดั้งเดิมและ Clash for Windows ใช้ไม่ได้ เพราะแกนของมันไม่รองรับ hysteria2 ซับสคริปชันนี้ส่งทุกอย่างยกเว้นเครือข่ายภายในบ้านผ่านโหนดโดยค่าเริ่มต้น ดูวิดีโอจีนจึงไม่ต้องแก้อะไร ถ้าเพิ่มกฎเอง อย่าตั้งโดเมนจีนเป็น "direct" (ต่อตรง)
