# 01 · บริการไหนบ้างที่ต้องใช้ IP จีน

เกณฑ์มีข้อเดียว: เมื่อบริการเห็นว่า IP ต้นทางของคุณไม่ได้อยู่ในจีนแผ่นดินใหญ่ ก็จะปฏิเสธหรือให้บริการแบบลดทอน ตารางด้านล่างเรียงตามความเข้มงวดในการบล็อก

| หมวด | ตัวอย่าง | ถ้าไม่มี IP จีนจะเป็นอย่างไร | นอกจาก IP แล้วตรวจอะไรอีก |
|---|---|---|---|
| วิดีโอ | iQIYI, Tencent Video, Youku, Mango TV, อนิเมะบางเรื่องบน Bilibili | ขึ้นว่าดูได้เฉพาะในจีนแผ่นดินใหญ่ หรือดูได้แค่คอนเทนต์ฟรี | ภูมิภาคของร้านแอป, ที่ที่ลงทะเบียนบัญชี |
| เพลง | NetEase Cloud Music, QQ Music, Kugou | เพลงจำนวนมากเป็นสีเทาและเล่นไม่ได้ | ไม่มี |
| บริการภาครัฐ | แพลตฟอร์มบริการภาครัฐแห่งชาติ, เว็บบริการภาครัฐระดับมณฑล, ภาษี, ประกันสังคม, กองทุนสำรองเพื่อที่อยู่อาศัย | หน้าเว็บเปิดไม่ได้ หรือรหัสยืนยันไม่มาสักที | เบอร์โทรศัพท์, การสแกนใบหน้า |
| การศึกษา | CHSI, เว็บข้อมูลวุฒิการศึกษา, ระบบงานทะเบียนของมหาวิทยาลัย | เปิดไม่ได้ หรือช้ามาก | ไม่มี |
| การเดินทาง | 12306, เว็บสายการบิน | เปิดไม่ได้ ชำระเงินไม่ผ่าน | เบอร์โทรศัพท์, การชำระเงิน |
| การเงิน | ธนาคารออนไลน์, แอปธนาคาร, Alipay, WeChat Pay | ล็อกอินแล้วถูกระบบควบคุมความเสี่ยงบล็อก โอนเงินไม่สำเร็จ | ซิมการ์ด, ลายนิ้วมือของอุปกรณ์, ใบหน้า |
| เกม | เกม PC และเกมมือถือเซิร์ฟเวอร์จีน | ล็อกอินได้ แต่ความหน่วงสูงและหลุดบ่อย | การยืนยันตัวตนด้วยชื่อจริง |
| ชีวิตประจำวัน | Meituan, Ele.me, DiDi, ฟีเจอร์บางอย่างของ Taobao | ระบุตำแหน่งผิด สั่งซื้อไม่สำเร็จ | ตำแหน่ง, เบอร์โทรศัพท์ |
| ไลฟ์สตรีม | Douyin, Kuaishou, Douyu | บางภูมิภาคดูไม่ได้ | ไม่มี |

## เรื่องสำคัญที่ต้องแยกให้ออก

**"ต้องใช้ IP จีน" กับ "ต้องใช้เบอร์โทรศัพท์จีน" เป็นคนละเรื่องกัน** วิดีโอและเพลงดูแค่ IP เปลี่ยน IP ก็พอ แต่บริการภาครัฐ ธนาคาร และการจองตั๋ว นอกจาก IP แล้วยังต้องรับรหัสยืนยันทาง SMS และผ่านการสแกนใบหน้า IP แก้เรื่อง "เปิดได้หรือไม่" ส่วนการยืนยันขั้นต่อไปขึ้นกับเบอร์โทรศัพท์จีนและเอกสารประจำตัวของคุณเอง

## วิธีแก้ปัญหาเรื่อง IP

ส่งทราฟฟิกไปที่เซิร์ฟเวอร์ในจีนแผ่นดินใหญ่ก่อน แล้วให้เซิร์ฟเวอร์นั้นเข้าเว็บปลายทาง ทำได้สามแบบ คือ ไคลเอนต์ เว็บพร็อกซี หรือเราเตอร์ จะเลือกแบบไหน ดู[วิธีเชื่อมต่อแบบไหนเหมาะกับสถานการณ์ใด](../network/02-choose-your-connection-method.md) ในหมวดพี่น้อง
