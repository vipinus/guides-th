# 04 · ธนาคารออนไลน์ แอปธนาคาร และการชำระเงิน

## ระบบควบคุมความเสี่ยงของธนาคารดูอะไร

ธนาคารไม่ได้ดูแค่ IP แต่เอาหลายสัญญาณมารวมกันแล้วให้คะแนน:

1. **IP ลงทะเบียนอยู่ที่ไหน**: IP ต่างประเทศทำให้ระดับความเสี่ยงสูงขึ้นทันที
2. **ซิมการ์ด**: แอปธนาคารบนมือถืออ่านข้อมูลซิม และซิมของค่ายต่างประเทศจะถูกหักคะแนน
3. **ลายนิ้วมือของอุปกรณ์**: เครื่องใหม่ หรือเครื่องที่เจลเบรกหรือรูทแล้ว
4. **พฤติกรรม**: โอนเงินก้อนใหญ่ตั้งแต่ล็อกอินครั้งแรกจากที่ใหม่

สถานการณ์ที่พบบ่อยจึงเป็นแบบนี้: เปลี่ยนเป็น IP จีนแล้วล็อกอินได้ แต่การโอนเงินยังถูกบล็อก เพราะ IP แก้ได้แค่ข้อแรก

## สิ่งที่คุณทำได้

- หลังเปลี่ยนเป็น IP จีน **ทำรายการเล็กๆ ก่อน** ให้ระบบควบคุมความเสี่ยงคุ้นกับสภาพแวดล้อมนี้ แล้วค่อยทำรายการใหญ่
- เก็บซิมการ์ดจีนไว้และเปิดโรมมิง เพราะทั้งรหัสยืนยันและการตรวจซิมต้องพึ่งมัน
- ถ้าทำได้ ให้ติดตั้งแอปธนาคารฉบับจีน ปัญหาเรื่องภูมิภาคของสโตร์ ดู[iOS ไม่ยอมให้ติดตั้งแอป ทำอย่างไร](../client/06-ios-app-store.md) ในคลังพี่น้อง
- ถ้าถูกบล็อก อย่าลองซ้ำไปเรื่อยๆ ล้มเหลวหลายครั้งจะทำให้บัญชีถูกระงับชั่วคราว โทรหาฝ่ายบริการลูกค้าเพื่อปลดล็อกเร็วที่สุด

## Alipay และ WeChat Pay

ทั้งสองยอมรับ IP ได้กว้างกว่าธนาคาร และปกติใช้จาก IP ต่างประเทศได้ แต่บัญชีที่ผูกกับบัตรต่างประเทศมีข้อจำกัดเรื่องวงเงินและสถานที่ใช้ เมื่อต้องจ่ายด้วยบัตรจีนหรือโอนเงินให้ร้านค้าในจีน การเปลี่ยนเป็น IP จีนจะทำให้ทุกอย่างราบรื่นขึ้นมาก

## สิ่งที่ไม่ควรทำ

อย่าทำธุรกรรมธนาคารบน Wi-Fi สาธารณะ ไม่ว่าจะผ่านเส้นทางหรือไม่ก็ตาม เส้นทางแค่เปลี่ยน IP ขาออกของคุณ ไม่ได้เข้ารหัสอะไรให้ในช่วงที่เลยจากเส้นทางไปถึงธนาคาร ความปลอดภัยมาจากการเข้ารหัสของแอปธนาคารเอง
