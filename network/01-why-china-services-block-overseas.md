# 01 · การเข้าบริการจีนจากต่างประเทศทำงานอย่างไร

## สิ่งที่คุณเจอ

คุณอยู่ต่างประเทศ เปิด iQIYI, Bilibili หรือ NetEase Cloud Music แล้วขึ้นว่า "เนื้อหานี้ดูได้เฉพาะในจีนแผ่นดินใหญ่" ธนาคารออนไลน์และ 12306 เปิดไม่ขึ้นเลย หรือรหัสยืนยันไม่มาสักที

## สาเหตุมีอย่างเดียว: IP ของคุณจดทะเบียนอยู่ที่ไหน

เมื่ออุปกรณ์ของคุณออนไลน์ ผู้ให้บริการเน็ตจะให้ที่อยู่ IP สาธารณะมาหนึ่งตัว ที่อยู่เหล่านี้มีทะเบียนกลางทั่วโลกที่บอกว่าแต่ละตัวเป็นของประเทศไหนและผู้ให้บริการรายใด แพลตฟอร์มวิดีโอและเพลงของจีนซื้อลิขสิทธิ์มาเฉพาะ**จีนแผ่นดินใหญ่**เท่านั้น และไม่มีสิทธิ์ตามกฎหมายที่จะเผยแพร่นอกพื้นที่นั้น จึงปฏิเสธทันทีที่เห็น IP ต่างประเทศ

ธนาคารและเว็บขายตั๋วใช้ตรรกะอีกแบบ สำหรับพวกเขาไม่ใช่เรื่องลิขสิทธิ์ แต่เป็นเรื่องควบคุมความเสี่ยง: การล็อกอินจาก IP ต่างประเทศถือว่าเสี่ยงสูงและถูกบล็อกไปเลย

## แนวทางแก้

ทำให้ IP ที่เซิร์ฟเวอร์เห็นเป็น IP ของจีนแผ่นดินใหญ่ วิธีคือส่งทราฟฟิกของคุณไปที่เซิร์ฟเวอร์ที่ตั้งอยู่ในจีนแผ่นดินใหญ่ก่อน แล้วให้เซิร์ฟเวอร์นั้นเข้าเว็บปลายทางแทนคุณ เว็บปลายทางเห็น IP ของเซิร์ฟเวอร์นั้นก็จะปล่อยผ่าน

นี่คือสิ่งที่ "เส้นทางเข้าจีน" ทำ: ส่งทราฟฟิกของคุณออกไปจาก IP ของจีนแผ่นดินใหญ่

## ความเข้าใจผิดที่พบบ่อยสามข้อ

- **เปลี่ยน DNS ไม่ช่วย** DNS แค่แปลงชื่อโดเมนเป็นที่อยู่ เว็บปลายทางดู IP ต้นทางของคุณ ไม่ได้ดู DNS ที่คุณใช้
- **บางแพลตฟอร์มดูภูมิภาคของระบบด้วย** นอกจาก IP แล้ว บางแพลตฟอร์มยังตรวจภาษาของอุปกรณ์และภูมิภาคของร้านแอป กรณีนั้นให้เปลี่ยนภูมิภาคของระบบด้วย
- **ความเร็วขึ้นกับคุณภาพของเส้นทางระหว่างสองจุด** ลิงก์ข้ามประเทศจากต่างประเทศเข้าจีนแผ่นดินใหญ่คือคอขวด การเลือกจุดเข้าที่อยู่ใกล้คุณและมีเส้นทางเข้าจีนที่ปรับแต่งมาแล้วจึงสำคัญกว่าสเปกของเซิร์ฟเวอร์เอง
