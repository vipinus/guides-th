# 08 · หลังติดตั้งเฟิร์มแวร์: สิ่งที่มันทำเอง และสวิตช์ไม่กี่ตัวที่ควรรู้

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/router-firmware?utm_source=github&utm_content=router-08

หลังแฟลชเฟิร์มแวร์ของเว็บไซต์นี้ หรือซื้อเราเตอร์ที่ติดตั้งมาพร้อมใช้ สิ่งเดียวที่คุณต้องทำคือล็อกอินบัญชีในหน้าแอดมิน บทความนี้อธิบายสิ่งที่เฟิร์มแวร์**ทำเอง** และสวิตช์ไม่กี่ตัวที่คุณอาจต้องแตะ ส่วนการเริ่มต้นใช้งานดู [01](01-plug-and-play-router.md) การแยกเส้นทางดู [03](03-router-split-routing.md) และการผูกกับการเปลี่ยนเราเตอร์ดู [05](05-mac-binding-and-replacing.md)

## สิ่งที่มันทำเอง

| อะไร | ทำงานอย่างไร | คุณต้องทำอะไร |
|---|---|---|
| อัปเดตส่วนประกอบและรายการแยกเส้นทาง | ตรวจตอนบูตและดาวน์โหลดอัปเดตที่มี ซึ่ง**มีผลในการบูตครั้งถัดไป** รายการเว็บที่ถูกบล็อกสำหรับเข้าบริการต่างประเทศจากในจีนก็อัปเดตเองทุกวัน | ไม่ต้องทำอะไร ที่อยู่เส้นทางที่เปลี่ยนและเว็บที่เพิ่มเข้ารายการจะถูกรับมาเอง |
| รหัสประเทศของ Wi‑Fi | พอออกเน็ตได้ก็ตรวจว่าอยู่ประเทศไหน แล้วตั้งกำลังส่งและช่องสัญญาณไร้สายให้เอง | หลังแฟลชใหม่ๆ **เสียบสาย LAN ก่อน** ให้มันออกเน็ตหนึ่งครั้ง ก่อนออกเน็ตสัญญาณอ่อนกว่าเป็นเรื่องปกติ |
| จัดการเมื่อหมดอายุ | เมื่อบัญชีหมดอายุจะหยุดส่งผ่าน VPN เครือข่ายในบ้านยังใช้ได้ตามปกติ | ต่ออายุแล้วกลับมาเอง ไม่ต้องล็อกอินใหม่ |
| ผูกเราเตอร์ | ล็อกอินครั้งแรกจะบันทึกเราเตอร์เครื่องนี้ไว้กับบัญชี | ก่อนเปลี่ยนเราเตอร์ ให้ยกเลิกการผูกบนเว็บไซต์ |

มีแค่การอัปเกรดเวอร์ชันใหญ่ของเฟิร์มแวร์ทั้งชุดเท่านั้นที่ต้องแฟลชไฟล์ sysupgrade ปีหนึ่งมีแค่ไม่กี่ครั้ง และเว็บไซต์จะแจ้งให้ทราบ

## สิ่งที่คุณอาจต้องแตะ

- **โหมดแยกเส้นทาง**: แยกเส้นทาง (ค่าเริ่มต้น) / ทั้งหมด (Global) / ตรง (Direct) ถ้าเว็บไหนเปิดไม่ได้ ให้สลับเป็น Global ก่อนเพื่อตรวจ: ถ้าเปิดได้ใน Global แปลว่าเว็บนั้นไม่อยู่ในรายการ ส่งที่อยู่ให้ฝ่ายบริการลูกค้าเพิ่มให้ ถ้าใน Global ก็ยังเปิดไม่ได้ ปัญหาอยู่ที่ตัวเว็บเอง
- **ภูมิภาค**: เลือกในหน้าแอดมิน เลือกภูมิภาคจีนเพื่อดูคอนเทนต์จีนจากต่างประเทศ และเลือกภูมิภาคต่างประเทศเพื่อเข้าบริการต่างประเทศจากในจีน
- **Blocked sites only** (เฉพาะเว็บที่ถูกบล็อก): ช่องติ๊กใต้ "VPN settings" (การตั้งค่า VPN) ในส่วนแยกเส้นทางอัจฉริยะ ติ๊กไว้เป็นค่าเริ่มต้น มีผลเฉพาะทิศทางเข้าบริการต่างประเทศจากในจีน (คุณอยู่ในจีนและเลือกภูมิภาคต่างประเทศ) เมื่อติ๊กไว้ เฉพาะเว็บและบริการที่ถูกบล็อกเท่านั้นที่ผ่าน VPN (อิงรายการเว็บที่ถูกบล็อกซึ่งอัปเดตเองทุกวัน บวกบริการอย่าง Telegram ที่เชื่อมต่อไปที่อยู่ตายตัว) ส่วนเว็บจีน และเว็บต่างประเทศที่เปิดจากในจีนได้อยู่แล้ว (เว็บบริษัทต่างชาติ การดาวน์โหลดของ Apple และ Microsoft แพลตฟอร์มเกม ฯลฯ) จะต่อตรง ไม่อ้อม ถ้าเอาติ๊กออกจะกลับไปทำงานแบบเดิม: เว็บจีนต่อตรง ที่เหลือทั้งหมดผ่าน VPN ถ้าอยู่ในจีนแล้วเว็บต่างประเทศไหนเปิดไม่ได้ ให้เอาติ๊กออก (หรือสลับเป็น Global ชั่วคราว) แล้วลองใหม่ ถ้าเปิดได้ แปลว่าเว็บนั้นถูกบล็อกแต่ยังไม่อยู่ในรายการ ส่งที่อยู่ให้ฝ่ายบริการลูกค้า เฟิร์มแวร์ที่แฟลชก่อนตุลาคม 2026 ยังไม่มีช่องติ๊กนี้ (แต่ค่าเริ่มต้นใหม่มีผลแล้วผ่านการอัปเดตอัตโนมัติ) ถ้าจะเปลี่ยน ให้ติดต่อฝ่ายบริการลูกค้าซึ่งปรับให้จากระยะไกลได้ ทิศทางเข้าจีนจากต่างประเทศไม่ได้รับผลจากสวิตช์นี้
- **เลือกเส้นทางที่เร็วที่สุดอัตโนมัติ**: อยู่ใต้ภูมิภาค ปิดไว้เป็นค่าเริ่มต้น แนะนำให้เปิดเมื่อคุณภาพเครือข่ายไม่ดี

  | | ปิด (ค่าเริ่มต้น) | เปิด |
  |---|---|---|
  | ใช้เส้นทางไหน | ภูมิภาคที่คุณเลือกเสมอ | เลือกเส้นทางที่ความหน่วงต่ำที่สุดและแพ็กเก็ตหายน้อยจากเส้นทางที่ใช้ได้ แล้ววัดใหม่เป็นระยะ ถ้าแย่ลงก็สลับเอง |
  | ประเทศขาออก | ภูมิภาคที่เลือก | ถ้าเลือกภูมิภาคจีน: เลือกเฉพาะเส้นทางในจีน ขาออกยังอยู่ในจีน ถ้าเลือกภูมิภาคต่างประเทศ: เลือกจากเส้นทางต่างประเทศทั้งหมด และ**ประเทศขาออกอาจไม่ตรงกับภูมิภาคที่เลือก** (เช่น เลือกญี่ปุ่นแต่ออกจริงที่สิงคโปร์) |
  | เหมาะกับ | สถานการณ์ที่ต้องการประเทศตายตัว: ดูสตรีมมิงของประเทศใดประเทศหนึ่ง ธนาคารและบัญชีที่อ่อนไหวเรื่องภูมิภาค | เน็ตบ้านไม่นิ่ง หรือภูมิภาคที่กระตุกบ่อย เมื่อคุณอยากได้แค่ความเร็วและไม่สนว่าออกจากประเทศไหน |

  ตอนกดสวิตช์ หน้าแอดมินจะขึ้นว่า "Switching automatic selection…" (กำลังสลับการเลือกอัตโนมัติ) และบังหน้าไว้จนสลับเสร็จ ระหว่างนี้เน็ตจะหลุดสั้นๆ ซึ่งเป็นเรื่องปกติ "Current exit" (ขาออกปัจจุบัน) ในหน้าแอดมินจะบอกว่ากำลังใช้เส้นทางไหนอยู่จริง
- **รหัสผ่านแอดมินและรหัส Wi‑Fi**: ค่าจากโรงงานเป็นค่าที่ใครก็รู้ ล็อกอินแล้วให้เปลี่ยนเป็นอย่างแรก

## ทีวี กล่องทีวี และอุปกรณ์ของผู้สูงอายุในบ้าน

- แค่ต่อ Wi‑Fi ของเราเตอร์นี้หรือต่อสาย แอปเวอร์ชันจีนแผ่นดินใหญ่ก็เล่นได้ทันที เวอร์ชันสากล (iQIYI, WeTV) มีคลังคอนเทนต์ต่างกัน ให้ติดตั้งเวอร์ชันจีนแผ่นดินใหญ่
- อุปกรณ์ต่ออยู่แต่ไม่ผ่าน VPN หรือเว็บที่ถูกบล็อกเปิดไม่ได้ทั้งที่อย่างอื่นใช้ได้ปกติ: ส่วนใหญ่เป็นเพราะอุปกรณ์ตั้ง DNS ส่วนตัวไว้เอง ("DNS ส่วนตัว" (Private DNS) ของ Android, DNS ที่ปลอดภัยของเบราว์เซอร์) เราเตอร์จึงมองไม่เห็นว่ามันกำลังค้นหาเว็บไหน ให้ปิดเสีย
- อยากให้อุปกรณ์บางเครื่องต่อตรงเสมอ (คอมพิวเตอร์ที่ทำงานซึ่งต้องต่อ VPN ของบริษัท): ให้เครื่องนั้นต่อ Wi‑Fi ของเราเตอร์ตัวหลักหรือของโมเด็มแทน

## คำถามที่พบบ่อย

**แพ็กเกจส่วนตัวใช้เราเตอร์ได้ไหม?** ได้ ทั้งส่วนตัว ครอบครัว และองค์กร รองรับเราเตอร์ทั้งหมด ไม่ต้องเปลี่ยนแพ็กเกจ

**เราเตอร์กินโควตาอุปกรณ์กี่เครื่อง?** หนึ่งเครื่อง อุปกรณ์ที่ต่ออยู่หลังเราเตอร์ไม่นับ

**เฟิร์มแวร์มีแบ็กดอร์ไหม?** คอมไพล์จาก OpenWrt โดยเพิ่มแค่ส่วนประกอบที่ใช้เชื่อมต่อ VPN กับกฎแยกเส้นทาง VPN บันทึกแค่ระยะเวลาเชื่อมต่อและปริมาณข้อมูลรวมเพื่อคิดค่าบริการเท่านั้น
