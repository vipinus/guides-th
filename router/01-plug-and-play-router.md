# 01 · เริ่มใช้เราเตอร์ที่ติดตั้งมาให้แล้ว

## แกะกล่องแล้วทำสามขั้นตอน

1. **เสียบปลั๊กไฟและสายแลน**: ต่อพอร์ต WAN ของเราเตอร์เข้ากับโมเด็มหรือเราเตอร์ตัวหลักที่มีอยู่ แล้วรอให้ไฟสถานะนิ่ง ประมาณหนึ่งนาที
2. **ต่อ Wi-Fi**: ชื่อ Wi-Fi และรหัสผ่านเริ่มต้นพิมพ์อยู่บนการ์ดคำแนะนำ (ค่าจากโรงงานของทั้งสองอย่างคือชื่อโดเมนของเว็บไซต์) ต่อแล้วเปิดเบราว์เซอร์ ไปที่หน้าแอดมิน `http://192.168.11.1`
3. **ล็อกอินบัญชี**: ในหน้าแอดมิน ใส่อีเมลบัญชีและรหัสผ่านแล้วบันทึก (บัญชีแพ็กเกจส่วนตัว ครอบครัว และองค์กรใช้เราเตอร์ได้ทั้งหมด) จากนั้นทุกอุปกรณ์ที่ต่อ Wi-Fi นี้จะผ่าน VPN โดยอัตโนมัติ

## เปลี่ยนรหัสผ่านเริ่มต้น

รหัสผ่านหน้าแอดมินและรหัสผ่าน Wi-Fi จากโรงงานเป็นข้อมูลที่ใครก็รู้ ล็อกอินแล้วให้เปลี่ยนเป็นอย่างแรก: หน้าแอดมิน → System (ระบบ) → Administration (การดูแลระบบ) และ Wireless (ไร้สาย) → Interfaces (อินเทอร์เฟซ) → Wireless Security (ความปลอดภัยไร้สาย)

## โหมดแยกเส้นทาง

ค่าเริ่มต้นคือแยกเส้นทาง: โดเมนจีนที่อยู่ในรายการผ่าน VPN ที่เหลือวิ่งตรง โหมดนี้เหมาะที่สุดถ้าคุณอยู่ต่างประเทศและดูวิดีโอจีน หรือมีผู้สูงอายุในบ้านดูทีวี เมื่อคุณอยู่ในจีนและเลือกภูมิภาคต่างประเทศ ทิศทางจะกลับด้านเอง: โดยค่าเริ่มต้นเฉพาะเว็บและบริการที่ถูกบล็อกเท่านั้นที่ผ่าน VPN ส่วนเว็บจีนและเว็บต่างประเทศที่เปิดจากในจีนได้อยู่แล้วจะวิ่งตรง ดู [03 · การแยกเส้นทางบนเราเตอร์คืออะไร](03-router-split-routing.md) ถ้าชั่วคราวต้องให้ทุกอย่างผ่าน VPN ให้สลับเป็น "Global" (ทั้งหมด) แล้วสลับกลับเมื่อใช้เสร็จ

## คำถามที่พบบ่อย

- **ไฟสถานะปกติ แต่อุปกรณ์ที่ต่ออยู่ไม่มีเน็ต**: ดูสถานะบัญชีในหน้าแอดมิน บัญชีหมดอายุหรือรหัสผ่านผิดจะแสดงไว้ตรงนั้น
- **อยากเปลี่ยนไปใช้เราเตอร์ตัวอื่น**: ยกเลิกการผูกตัวเก่าบนเว็บไซต์ก่อน ดู[การผูก MAC และการเปลี่ยนเราเตอร์](05-mac-binding-and-replacing.md)
