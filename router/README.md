# คู่มือเราเตอร์และเครือข่ายในบ้าน

ให้ทุกอุปกรณ์ในบ้านใช้ VPN พร้อมกันในครั้งเดียว: เริ่มใช้เราเตอร์ที่ติดตั้งมาให้แล้ว แฟลชเฟิร์มแวร์เอง การแยกเส้นทางทำงานอย่างไร ทีวีและผู้สูงอายุในบ้าน การผูกและเปลี่ยนเราเตอร์

**บทความที่ถูกถามถึงมากที่สุด: [ปลดล็อกเว็บวิดีโอจีนจากต่างประเทศด้วยเราเตอร์](06-unlock-chinese-video-with-router.md)** — ทีวี กล่องรับสัญญาณ และทุกอุปกรณ์ในบ้านตั้งค่าครั้งเดียว ต่อ Wi-Fi ปุ๊บก็ดู iQIYI, Tencent Video และ Yangshipin (CCTV) ได้ทันที
