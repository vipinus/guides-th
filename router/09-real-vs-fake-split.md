# 09 · การแยกเส้นทางของเราเตอร์ทำงานอย่างไร

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/router-smart-split?utm_source=github&utm_content=router-09

ทุกยี่ห้อเรียกว่า "การแยกเส้นทางอัจฉริยะ" เหมือนกัน แต่เราเตอร์บางตัวใช้แล้วขัดใจ การแยกเส้นทางคืออะไร ดู [03](03-router-split-routing.md) บทความนี้พูดแค่ว่าการแยกเส้นทางควรทำอะไรบ้าง ถ้าขาดบางส่วนจะเห็นอาการอย่างไร และเราเตอร์ของเราทำอย่างไร

## สรุปในประโยคเดียว

สิ่งที่การแยกเส้นทางควรทำ: แต่ละเว็บ**รวมทั้งรูป วิดีโอ และการล็อกอินของเว็บนั้น** ผ่าน VPN หรือวิ่งตรงตามที่ตั้งของเว็บ และ**ทุกอุปกรณ์ในบ้านใช้กฎชุดเดียวกัน** ถ้าทำได้แค่บางส่วน คุณจะเห็นอาการด้านล่าง

## เทียบอาการ

| สิ่งที่คุณเห็น | เบื้องหลังเกิดอะไรขึ้น |
|---|---|
| เปิดการแยกเส้นทางแล้ว เว็บจีนกลับช้าลง | เว็บจีนถูกเข้าใจผิดว่าเป็นเว็บต่างประเทศ ทั้งเว็บจึงอ้อมไปต่างประเทศแล้ววนกลับมา |
| หน้าเว็บเปิดได้ แต่วิดีโอหมุนไม่หยุด รูปไม่ขึ้น และค้างตอนล็อกอิน | รายการมีแค่เว็บหลัก ส่วนวิดีโอ รูป และการล็อกอินของเว็บเดียวกันไปอีกทาง |
| อยู่ต่างประเทศ เปิดเส้นทางเข้าจีนแล้ว แอปวิดีโอยังขึ้นว่า "仅限中国大陆" (เฉพาะจีนแผ่นดินใหญ่) | ข้อมูลบางส่วนไม่ได้เข้า VPN และเว็บเห็นที่อยู่ต่างประเทศ |
| มือถือเล่นได้ แต่ทีวีหรือกล่องทีวีเล่นไม่ได้ คอมพิวเตอร์เครื่องหนึ่งไม่ยอมผ่าน VPN เลย | อุปกรณ์นั้นมีการตั้งค่าเครือข่ายของตัวเองและอ้อมเราเตอร์ |
| แอปธนาคารและแอปจ่ายเงินเตือนว่า "ล็อกอินจากที่อื่น" เป็นระยะ | ข้อมูลของแอปเดียวกันเดี๋ยวออกจากจีน เดี๋ยวออกจากต่างประเทศ |
| การแยกเส้นทางหายไประหว่างใช้ (หลังรีบูตหรือเชื่อมต่อใหม่ ถ้าไม่ใช่ทุกอย่างผ่าน VPN ก็ไม่มีอะไรผ่านเลย) | การตั้งค่าไม่ถูกจำไว้ |

ทั้งหมดนี้**ไม่มีข้อความแจ้งข้อผิดพลาด** เราเตอร์แสดง "Connected" (เชื่อมต่อแล้ว) ตลอด จึงตรวจหาสาเหตุยากที่สุด และหลายคนสรุปไปว่าเส้นทางไม่ดี

## การแยกเส้นทางควรทำอะไร

- เว็บหนึ่งไปทางเดียวกันทั้งหน้าเว็บ รูป วิดีโอ และการล็อกอิน ไม่ถูกแยกออกจากกัน
- ตอนตัดสินว่า "จีนหรือต่างประเทศ" ต้องยืนถูกฝั่ง และเว็บจีนไม่ต้องอ้อม
- ทุกอุปกรณ์ในบ้านใช้กฎเดียวกัน การแก้การตั้งค่าเครือข่ายบนตัวอุปกรณ์ก็เลี่ยงไม่ได้
- ทิศทางเปลี่ยนเองตามภูมิภาคที่เลือก (การเข้าจีนจากต่างประเทศกับการเข้าบริการต่างประเทศจากในจีนเป็นกฎสองชุดที่ตรงข้ามกัน)
- รายการอัปเดตเอง ไม่ต้องแฟลชใหม่
- จำการตั้งค่าได้: รีบูตหรือเชื่อมต่อใหม่ก็ยังเหมือนเดิม และเมื่อปิดแล้วจะไม่แอบเปิดกลับมาเอง

## การแยกเส้นทางอัจฉริยะบนเราเตอร์ของเรา

| | ทำอย่างไร |
|---|---|
| สวิตช์ | เปิดเป็นค่าเริ่มต้น เลือกภูมิภาคในจีน = ทิศทางเข้าจีนจากต่างประเทศ เลือกภูมิภาคต่างประเทศ = ทิศทางเข้าบริการต่างประเทศจากในจีน ใช้ให้อัตโนมัติ ทิศทางเข้าบริการต่างประเทศจากในจีนยังมีช่องติ๊ก "Blocked sites only" (เฉพาะเว็บที่ถูกบล็อก) ("VPN settings" (การตั้งค่า VPN) → การแยกเส้นทางอัจฉริยะ) ติ๊กไว้เป็นค่าเริ่มต้น ถ้าเอาติ๊กออก = เว็บจีนวิ่งตรง ที่เหลือผ่าน VPN เฟิร์มแวร์ที่แฟลชก่อนเดือนตุลาคม 2026 ยังไม่มีช่องติ๊กนี้ ติดต่อฝ่ายบริการลูกค้าให้เปลี่ยนให้จากระยะไกล |
| รายการ | จัดเป็น "ทั้งเว็บ": หน้าเว็บไปพร้อมกับแหล่งวิดีโอ รูป และการล็อกอินที่เว็บนั้นใช้ |
| เข้าบริการต่างประเทศจากในจีน | โดยค่าเริ่มต้นเฉพาะเว็บและบริการที่ถูกบล็อกเท่านั้นที่ผ่าน VPN (อิงรายการเว็บที่ถูกบล็อกซึ่งอัปเดตเองทุกวัน รวมกับบริการอย่าง Telegram ที่เชื่อมต่อไปยังที่อยู่ตายตัว) ส่วนเว็บจีน และเว็บต่างประเทศที่เปิดจากในจีนได้อยู่แล้ว (เว็บบริษัทต่างชาติ การดาวน์โหลดของ Apple และ Microsoft แพลตฟอร์มเกม) วิ่งตรงไม่ต้องอ้อม เร็วเท่ากับตอนไม่มีเราเตอร์ |
| อุปกรณ์ในบ้าน | ควบคุมรวมทั้งหมด การตั้งค่าเครือข่ายที่แก้บนตัวอุปกรณ์ก็ยังต้องทำตามกฎ ไม่มี "ประตูหลัง" ให้อ้อมเราเตอร์ |
| การอัปเดต | รายการและกฎอัปเดตเองตอนเราเตอร์เปิดเครื่อง และรายการเว็บที่ถูกบล็อกก็อัปเดตเองทุกวัน |
| การจำค่า | ยังอยู่หลังเชื่อมต่อใหม่หรือรีบูต ปิดแล้วก็ปิดอยู่อย่างนั้น |
| เครือข่ายในบ้าน | เครื่องพิมพ์ NAS และกล้องเข้าถึงได้ตรงตามปกติ |

**กรณีเดียวที่ต้องให้คุณช่วย**: เมื่อมือถือหรือเบราว์เซอร์เปิดการตั้งค่าแบบเข้ารหัสอย่าง "DNS ส่วนตัว" หรือ "DNS ที่ปลอดภัย" อุปกรณ์จะเข้ารหัสการค้นหาชื่อเว็บเอง และเราเตอร์มองไม่เห็น ถ้าอุปกรณ์ไหนทำงานแปลกๆ หรือเว็บที่ถูกบล็อกเปิดไม่ได้ทั้งที่อย่างอื่นใช้ได้ ให้ปิดการตั้งค่าแบบนี้ก่อน

## ตรวจสอบด้วยตัวเอง

1. คุณอยู่ในจีน (เข้าบริการต่างประเทศ): Baidu, Taobao และเว็บต่างประเทศที่เปิดจากในจีนได้อยู่แล้ว เช่น การดาวน์โหลดของ Apple และ Microsoft ความเร็วปกติ ส่วนเว็บต่างประเทศที่ถูกบล็อกเปิดได้และวิดีโอเล่นได้
2. คุณอยู่ต่างประเทศ (เข้าจีน): เลือกตอนไหนก็ได้ใน Tencent Video หรือ iQIYI แล้วเล่นได้ ไม่มีข้อความ "仅限中国大陆" (เฉพาะจีนแผ่นดินใหญ่) และเว็บธนาคารกับเว็บช้อปปิงในประเทศที่คุณอยู่ใช้ได้ตามปกติ
3. ลองทุกอุปกรณ์ โดยเฉพาะทีวีและกล่องทีวี เครื่องไหนทำงานแปลก ให้เช็ก "DNS ส่วนตัว / DNS ที่ปลอดภัย" ก่อน แล้วยืนยันว่าต่อ Wi‑Fi ของเราเตอร์ตัวนี้ ไม่ใช่ของโมเด็ม
4. เว็บไหนเปิดไม่ได้ตอนแยกเส้นทาง: สลับเป็น "Global" (ทั้งหมด) ชั่วคราว ถ้าเปิดได้ใน Global แต่เปิดไม่ได้ตอนแยกเส้นทาง แปลว่ายังไม่อยู่ในรายการ ส่งที่อยู่ให้ฝ่ายบริการลูกค้าเพิ่มเข้ารายการ แล้วจะมากับการอัปเดตอัตโนมัติ ถ้าอยู่ในจีน ก็เอาติ๊ก "Blocked sites only" ในส่วนการแยกเส้นทางอัจฉริยะออกแล้วลองใหม่ได้ ถ้าเปิดได้ ก็แปลว่าถูกบล็อกแต่ยังไม่อยู่ในรายการเช่นกัน

## คำถามที่พบบ่อย

**ต้องเปิดการแยกเส้นทางอัจฉริยะเองไหม?** ไม่ต้อง ล็อกอินบัญชีและเลือกภูมิภาคแล้วมันก็เปิดอยู่

**การเข้าจีนจากต่างประเทศกับการเข้าบริการต่างประเทศจากในจีนต้องตั้งค่าแยกกันไหม?** ไม่ต้อง ทิศทางตัดสินเองจากภูมิภาคที่เลือก

**จะกระทบเครื่องพิมพ์หรือ NAS ไหม?** ไม่กระทบ อุปกรณ์ในเครือข่ายบ้านเข้าถึงได้ตรงตามปกติ
