# 01 · บริการไหนต้องใช้ IP ต่างประเทศ และเส้นทางทำงานอย่างไร

หลักการตรงข้ามกับการเข้าจีนจากต่างประเทศ: เมื่อบริการเห็นว่า IP ต้นทางของคุณอยู่ในจีนแผ่นดินใหญ่ หรือคุณเชื่อมต่อเซิร์ฟเวอร์ของมันไม่ได้เลย ก็จะเปิดไม่ได้ ถูกลดความสามารถ หรือช้ามาก ตารางด้านล่างแบ่งตามการใช้งาน

| หมวด | ตัวอย่าง | ถ้าไม่มีเส้นทางจะเป็นอย่างไร | นอกจาก IP แล้วต้องมีอะไรอีก |
|---|---|---|---|
| ทำงาน | Google Workspace, Slack, Zoom, Teams, Notion | เปิดไม่ได้ หรือหลุดตลอด | บัญชีบริษัท |
| พัฒนาซอฟต์แวร์ | GitHub, npm, Docker Hub, แหล่ง PyPI ที่ไม่ใช่มิเรอร์, Stack Overflow | ช้าจนหมดเวลา | ไม่ต้องมีอะไร |
| AI | ChatGPT, Claude, Gemini | เปิดไม่ได้ | ประเทศที่ลงทะเบียนบัญชี เบอร์โทรศัพท์ |
| งานวิจัย | Google Scholar, ฐานข้อมูลบทความวิชาการ, อีเมลมหาวิทยาลัย | เปิดไม่ได้ หรือช้ามาก | บัญชีมหาวิทยาลัย |
| เกม | Steam ภูมิภาคต่างประเทศ, PSN, Switch eShop, เซิร์ฟเวอร์ต่างประเทศ | ร้านค้าเปิดไม่ได้ ความหน่วงสูง | บัญชีของเซิร์ฟเวอร์ภูมิภาคนั้น |
| วิดีโอและเพลง | YouTube, Netflix, Disney+, Spotify | เปิดไม่ได้ | บัญชีแบบเสียเงิน และภูมิภาคของบัญชีต้องตรงกับ IP |
| โซเชียล | X, Instagram, Telegram, Discord, WhatsApp | เปิดไม่ได้ | เบอร์โทรศัพท์ |

## เรื่องสำคัญที่ต้องแยกให้ออก

**"ต้องใช้ IP ต่างประเทศ" กับ "ต้องใช้บัญชีต่างประเทศ" เป็นคนละเรื่องกัน** GitHub และ YouTube แค่เปลี่ยน IP ก็พอ Netflix ต้องมีบัญชีเสียเงินที่ภูมิภาคตรงกัน การสมัคร ChatGPT ต้องใช้เบอร์ต่างประเทศที่รับรหัสยืนยันได้ เส้นทางแก้เรื่อง "เปิดได้หรือไม่" ส่วนบัญชีเป็นเรื่องของคุณเอง

## เส้นทางทำงานอย่างไร

ทราฟฟิกของคุณจะถูกเข้ารหัสแล้วส่งไปที่เซิร์ฟเวอร์ในต่างประเทศก่อน แล้วเซิร์ฟเวอร์นั้นค่อยไปเรียกปลายทาง สิ่งที่ปลายทางเห็นคือ IP ของเซิร์ฟเวอร์นั้น ทำได้สามแบบ คือ ไคลเอนต์ เว็บพร็อกซี และเราเตอร์ จะเลือกแบบไหน ดู[วิธีเชื่อมต่อแบบไหนเหมาะกับสถานการณ์ใด](../network/02-choose-your-connection-method.md)

## ความเข้าใจผิดที่พบบ่อยสามข้อ

- **เปลี่ยน DNS ไม่ช่วย** การเชื่อมต่อไม่ได้เป็นปัญหาเรื่องเส้นทาง ไม่ใช่เรื่องการค้นหาชื่อโดเมน
- **ความเร็วขึ้นกับเส้นทางระหว่างสองจุด** ออกจากจีน คอขวดคือลิงก์ข้ามประเทศและช่องทางออกของผู้ให้บริการเน็ตของคุณ การเลือกภูมิภาคจึงสำคัญกว่าสเปกเซิร์ฟเวอร์ ดู [03](03-which-region-is-fastest.md)
- **ระหว่างใช้แอปจีน ไม่จำเป็นต้องให้ทุกอย่างผ่านเส้นทาง** เปิดการแยกเส้นทาง: ค่าเริ่มต้นคือเฉพาะเว็บที่ถูกบล็อกเท่านั้นที่ผ่านเส้นทาง ส่วนเว็บจีนและเว็บต่างประเทศที่เปิดจากในจีนได้อยู่แล้วจะต่อตรง ไม่มีฝั่งไหนต้องอ้อม ดู[การแยกเส้นทางของเราเตอร์](../router/03-router-split-routing.md)
