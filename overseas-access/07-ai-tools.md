# 07 · ใช้เครื่องมือ AI (ChatGPT, Claude, Gemini และอื่นๆ)

## อาการที่คุณเห็น

เมื่อเปิดเว็บเหล่านี้จากในจีน อาการจะต่างกันไป จึงตัดสินผิดได้ง่าย:

| อาการ | สาเหตุที่เป็นไปได้มากที่สุด |
|---|---|
| เปิดหน้าเว็บไม่ได้เลย | เข้าถึงไม่ได้ในระดับเครือข่าย |
| หน้าเว็บเปิดได้ แต่ค้างตอนล็อกอิน | บริการภายนอกที่ใช้ล็อกอินเข้าถึงไม่ได้ |
| แชตได้ แต่พอส่งข้อความยาวก็ตัดทันที | การเชื่อมต่อไม่เสถียร |
| ขึ้นข้อความว่า "ไม่รองรับในประเทศของคุณ" | ผู้ให้บริการปฏิเสธตาม IP |
| ขึ้นข้อความว่าบัญชีถูกแบนหรือต้องยืนยันตัวตน | ดู "เรื่องที่สำคัญที่สุด" ด้านล่าง |

## เรื่องที่สำคัญที่สุด: เสถียรสำคัญกว่าเร็ว

บริการเหล่านี้ไวเป็นพิเศษกับ**การเปลี่ยน IP บ่อยๆ** ถ้าการเชื่อมต่อของคุณเดี๋ยวออกทางญี่ปุ่น เดี๋ยวออกทางสหรัฐฯ สิ่งที่ผู้ให้บริการเห็นคือ "บัญชีเดียวกันข้ามหลายประเทศภายในไม่กี่นาที" ซึ่งกระตุ้นระบบควบคุมความเสี่ยงได้ง่าย เบาที่สุดคือให้ยืนยันตัวตนใหม่ หนักที่สุดคือบัญชีถูกแบน

ดังนั้นเวลาใช้เครื่องมือ AI:

- **เลือกภูมิภาคเดียวแล้วใช้ไปเรื่อยๆ** อย่าสลับบ่อย
- สมัครและใช้งานประจำใน**ภูมิภาคเดียวกัน**ให้มากที่สุด
- ถ้าสมัครผ่านสหรัฐฯ ก็ใช้สหรัฐฯ ต่อไปตลอด

เรื่องนี้สำคัญกว่า "ภูมิภาคไหนเร็วกว่า" มาก ช้าลงนิดหน่อยแค่ต้องรอนานขึ้นอีกหน่อย แต่ถ้าบัญชีมีปัญหา ต้องเริ่มใหม่หมด

## เลือกภูมิภาคไหน

ญี่ปุ่นและสิงคโปร์อยู่ใกล้ ความหน่วงต่ำ แชตทั่วไปรู้สึกดีที่สุด แต่มีสองเรื่องที่ต้องระวัง:

- บางบริการเปิดให้ใช้ไม่เหมือนกันในแต่ละภูมิภาค ก่อนสมัครให้ยืนยันก่อนว่าเปิดบริการนั้นจากภูมิภาคนั้นได้ตามปกติ
- ถ้าฟีเจอร์ที่อยากใช้เกี่ยวกับการจ่ายเงิน ประเทศของช่องทางชำระเงินไม่ควรขัดกับภูมิภาคที่คุณเลือก

ถ้าไม่แน่ใจ ใช้ช่วงทดลองฟรีเปิดดูทุกบริการที่ตั้งใจจะใช้ แล้วค่อยตัดสินใจว่าจะใช้ภูมิภาคไหนระยะยาว

## การแยกเส้นทางรายแอปในไคลเอนต์มีประโยชน์มาก

เครื่องมือ AI มักใช้ผ่านเบราว์เซอร์หรือแอปแยก ให้ใส่ตัวนั้นไว้ในรายการที่ผ่านเส้นทาง แล้วให้แอปอื่นใช้เครือข่ายตามปกติ ข้อดีคือ:

- แอปสั่งอาหาร เรียกรถ และจ่ายเงินของจีนไม่ได้รับผลกระทบ
- ภูมิภาคของคุณจะไม่ "ถูกสลับโดยไม่รู้ตัว" เพราะแอปอื่น
- ประหยัดดาต้า

## บรรทัดคำสั่งและ API

ถ้าเรียกใช้ API ผ่านเครื่องมือบรรทัดคำสั่งหรือโค้ด โปรดทราบว่าโปรแกรมพวกนั้น**ไม่จำเป็นต้องอ่านพร็อกซีของระบบ** กรณีนี้ดู [05 · Linux และบรรทัดคำสั่ง](05-linux-server.md)

## ข้อควรระวัง

อย่าวางความลับของบริษัท ข้อมูลลูกค้า หรือโค้ดที่ยังไม่เผยแพร่ลงในบริการเหล่านี้ เรื่องนี้ไม่เกี่ยวกับว่าคุณใช้เส้นทางไหน พอส่งเนื้อหาออกไปแล้ว มันก็อยู่บนเซิร์ฟเวอร์ของอีกฝ่าย
