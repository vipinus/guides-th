# 02 · Cisco AnyConnect ใช้ในจีนได้ไหม

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/anyconnect-china?utm_source=github&utm_content=overseas-access-02

ใช้ได้ AnyConnect คือโปรโตคอล VPN สำหรับองค์กรของ Cisco บริษัททั่วโลกใช้มันทำงานทางไกล และสาขาในจีนของบริษัทต่างชาติก็ใช้ทุกวัน การแบนทิ้งทั้งหมดจึงมีต้นทุนสูงเกินไป **สิ่งที่ถูกบล็อกจริงๆ คือที่อยู่เซิร์ฟเวอร์บางที่อยู่ ไม่ใช่ตัวโปรโตคอล** คำถามว่า "ใช้ได้ไหม" จึงขึ้นกับว่าผู้ให้บริการมีที่อยู่มากพอ และเปลี่ยนให้เร็วพอหรือเปล่า

## ทำไมทนการบล็อกได้ดีกว่าแอป VPN ที่ใช้โปรโตคอลเฉพาะของตัวเอง

| | AnyConnect | แอป VPN ที่ใช้โปรโตคอลเฉพาะ |
|---|---|---|
| ลักษณะของข้อมูลที่วิ่ง | TLS มาตรฐาน เหมือนเข้าเว็บไซต์ HTTPS ทั่วไป | โปรโตคอลของตัวเอง มีลักษณะเด่นที่ตายตัว |
| เมื่อถูกตรวจจับได้ | แค่ที่อยู่นั้นที่อยู่เดียวเชื่อมต่อไม่ได้ | ทั้งแอปใช้ไม่ได้ |
| ไคลเอนต์ | Cisco เป็นผู้เผยแพร่ และมีตัวเลือกโอเพนซอร์สอย่าง OpenConnect บนทุกแพลตฟอร์ม | ถูกถอดจากสโตร์เมื่อไรก็หายไปเลย |

LeoTun มีเครื่องของตัวเองใน 24 ภูมิภาค เมื่อที่อยู่ไหนถูกจับตา ก็จะถูกเปลี่ยนเป็นที่อยู่ใหม่ ชื่อโดเมนชี้ไปที่ใหม่โดยอัตโนมัติ และไม่ต้องแก้ที่อยู่ที่บันทึกไว้ในไคลเอนต์

## วิธีติดตั้ง

1. ดาวน์โหลดไฟล์ติดตั้งสำหรับระบบของคุณจากหน้า Cisco บนเว็บไซต์ มีครบทั้ง Windows 10 ขึ้นไป, macOS, iOS, Android และ Linux ส่วน Windows 7/8 ใช้ได้แค่เวอร์ชัน 4.9 ซึ่งเป็นเวอร์ชันสุดท้ายที่รองรับ
2. เปิดไคลเอนต์แล้วใส่ที่อยู่เซิร์ฟเวอร์ในช่องที่อยู่ (บนเว็บไซต์ คลิกธงของภูมิภาคเพื่อคัดลอก)
3. ใส่บัญชีและรหัสผ่านแล้วเชื่อมต่อ ไม่ต้องมีไฟล์ใบรับรอง และไม่ต้องนำเข้าการตั้งค่า
4. เมื่อเห็น "Connected" (เชื่อมต่อแล้ว) ให้เช็ก IP ขาออกของคุณ

## ถ้าเชื่อมต่อไม่ได้ ไล่ตามลำดับนี้

1. **เปลี่ยนไปภูมิภาคอื่น** ถ้าภูมิภาคอื่นเชื่อมต่อได้ แปลว่าแค่เซิร์ฟเวอร์นั้นเข้าไม่ได้ชั่วคราว
2. **เปลี่ยนเครือข่าย** เน็ตบ้านใช้ไม่ได้ให้ลองเน็ตมือถือ และกลับกัน เพราะการรบกวนบนเครือข่ายของแต่ละค่ายไม่ได้เกิดพร้อมกัน
3. **อ่านข้อความแจ้งข้อผิดพลาด** `Login failed` คือบัญชีหรือรหัสผ่านผิด หรือบัญชีหมดอายุ `Untrusted server certificate` ส่วนใหญ่เป็นเพราะนาฬิกาของระบบไม่ตรง หรือเครือข่ายที่ใช้อยู่ดักสกัด TLS ให้เปลี่ยนเครือข่าย มีแค่ `Connection attempt has failed` ที่แปลว่าเข้าถึงที่อยู่นั้นไม่ได้
4. **อัปเดตไคลเอนต์** สำคัญเป็นพิเศษหลังอัปเกรดระบบครั้งใหญ่
5. **เปลี่ยนวิธีเชื่อมต่อ** บัญชีเดียวกันใช้ OpenVPN หรือ Hiddify เชื่อมต่อเซิร์ฟเวอร์ชุดเดียวกันได้ และการบล็อกทั้งสามโปรโตคอลไม่เกี่ยวข้องกัน ดู [02 · วิธีเชื่อมต่อแบบไหนเหมาะกับสถานการณ์ใด](../network/02-choose-your-connection-method.md)

## อัปเดต Cisco AnyConnect

Cisco เปลี่ยนชื่อเป็น Cisco Secure Client แล้ว แต่ใช้งานเหมือนเดิม ไม่ต้องถอนการติดตั้งก่อน: ติดตั้งเวอร์ชันใหม่ทับได้เลย ที่อยู่ที่บันทึกไว้ยังอยู่ครบ บนมือถือให้อัปเดตใน App Store / Google Play ถ้าค้นในสโตร์ไม่เจอ ให้ใช้ OpenConnect ซึ่งเป็นโอเพนซอร์ส ใช้โปรโตคอลเดียวกันและบัญชีเดียวกัน (การเปลี่ยนภูมิภาคของสโตร์บน iOS ดู[ไคลเอนต์ 06](../client/06-ios-app-store.md))

## คำถามที่พบบ่อย

**ช้าแปลว่าถูกบีบความเร็วหรือเปล่า?** ลองเปลี่ยนภูมิภาคก่อน: ดูไฟแดง เหลือง เขียวในรายการภูมิภาคบนเว็บไซต์ แล้วเลือกอันที่เป็นสีเขียว ถ้ายังช้า สาเหตุที่พบบ่อยคือเน็ตบ้านที่คุณใช้เอง เช่น เน็ตรวมของหมู่บ้านหรือคอนโด หรือค่ายเน็ตกับภูมิภาคไม่เข้ากัน (China Unicom ทางเหนือ: ญี่ปุ่นหรือเกาหลี China Telecom ทางใต้: เอเชียตะวันออกเฉียงใต้หรือออสเตรเลีย ค่ายอื่น: จุดเข้าในจีน)

**ทำไมที่อยู่เดียวกันบางทีดี บางทีแย่?** ที่อยู่เป็นชื่อโดเมน และเครื่องที่อยู่เบื้องหลังจะถูกเปลี่ยนอัตโนมัติตามการบล็อกและภาระงาน รอสักหนึ่งสองนาทีแล้วลองใหม่ ส่วนใหญ่แค่บังเอิญเจอจังหวะที่กำลังสลับเครื่อง

**เชื่อมต่อนานๆ แล้วจะหลุดเองไหม?** ไม่หลุดเพราะเวลา แต่เมื่อบัญชีหมดอายุ เซิร์ฟเวอร์จะตัดการเชื่อมต่อ ต่ออายุแล้วเชื่อมต่อใหม่ได้เลย
