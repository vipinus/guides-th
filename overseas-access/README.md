# คู่มือเข้าบริการต่างประเทศ · ใช้บริการต่างประเทศจากในจีน

คุณอยู่ในจีน และบริการต่างประเทศที่ต้องใช้ทำงาน พัฒนาโปรแกรม ทำวิจัย เล่นเกม หรือดูสตรีมมิง เปิดไม่ได้หรือช้ามาก เราเขียนแยกหนึ่งบทความต่อหนึ่งสถานการณ์ อธิบายให้ชัดว่า**ต้องใช้อะไร เลือกอย่างไร และมีหลุมพรางอะไรบ้าง**

**ใช้ทั้งบ้านหรือทั้งออฟฟิศ**: ดู[การแยกเส้นทางบนเราเตอร์](../router/03-router-split-routing.md) โดยค่าเริ่มต้น เฉพาะเว็บที่ถูกบล็อกเท่านั้นที่ผ่านเส้นทาง ส่วนเว็บจีนและเว็บต่างประเทศที่เปิดจากในจีนได้อยู่แล้วจะวิ่งตรง และไม่ต้องติดตั้งอะไรบนอุปกรณ์เลย
