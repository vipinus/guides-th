# 05 · ให้เซิร์ฟเวอร์ Linux และเครื่องมือบรรทัดคำสั่งผ่านเส้นทาง

บน Linux มีสองทางให้ผ่านเส้นทาง เลือกตามความต้องการ ถ้าจะให้ทั้งเครื่องผ่าน (ดึงอิมเมจ Docker รันบริการที่ต้องใช้เน็ตต่างประเทศ เครื่องที่ไม่มีคนเฝ้า) ใช้ OpenVPN: ไฟล์ตั้งค่าหนึ่งไฟล์วางไว้ใน /etc/openvpn/client/ แล้วให้เปิดเองตอนบูต ถ้าจะให้แค่ไม่กี่คำสั่งผ่าน (git, pip, npm, curl) ใช้เว็บพร็อกซี: ใส่ที่อยู่พร็อกซีในตัวแปรสภาพแวดล้อม http_proxy ทราฟฟิกอื่นไม่ถูกแตะต้อง บน Linux เดสก์ท็อปยังนำเข้าผ่าน NetworkManager ได้ด้วย บทความนี้อธิบายทั้งสามทาง พร้อมวิธีเขียนไฟล์รหัสผ่านและคำสั่งตรวจสอบ

## ทางที่หนึ่ง: ให้ทั้งเครื่องผ่านเส้นทาง (OpenVPN)

1. ติดตั้งไคลเอนต์: Debian / Ubuntu sudo apt install openvpn, Fedora sudo dnf install openvpn, Arch sudo pacman -S openvpn
2. ล็อกอินเว็บไซต์นี้ แล้วในหน้า OpenVPN คลิกธงของภูมิภาคเพื่อดาวน์โหลด .ovpn ไฟล์ตั้งค่าที่ Linux ได้รับไม่ได้ฝังบัญชีและรหัสผ่านไว้ (NetworkManager ไม่รับไฟล์ที่ฝังข้อมูลล็อกอิน) จึงต้องสร้างไฟล์รหัสผ่านแยก: สองบรรทัด บรรทัดแรกคืออีเมลที่ใช้กับเว็บไซต์นี้ บรรทัดที่สองคือรหัสผ่าน แล้ว chmod 600
3. คัดลอก .ovpn ไปไว้ที่ /etc/openvpn/client/<region>.conf แล้วใส่พาธของไฟล์รหัสผ่านต่อท้าย auth-user-pass ในไฟล์นั้น
4. sudo systemctl enable --now openvpn-client@<region> ดูสถานะด้วย systemctl status openvpn-client@<region> และตรวจว่า curl -s https://ipinfo.io/country แสดงภูมิภาคที่คุณเลือก
5. ถ้าจะเปลี่ยนภูมิภาค ให้ดาวน์โหลดไฟล์ตั้งค่าอีกไฟล์แล้วเปิดใช้อีก unit หนึ่ง รันได้ทีละตัวเท่านั้น

## ทางที่สอง: ให้แค่เครื่องมือบรรทัดคำสั่งผ่านเส้นทาง (เว็บพร็อกซี)

ที่อยู่พร็อกซีที่ให้ไว้ในหน้าเว็บพร็อกซี (Web Proxy) ของเว็บไซต์นี้ ใส่รวมกับบัญชีและรหัสผ่านลงในตัวแปรสภาพแวดล้อมได้เลย: export https_proxy=https://username:password@proxy-address export http_proxy=$https_proxy อักขระพิเศษในรหัสผ่านต้องเข้ารหัสแบบ URL จากนั้น curl, wget, git, pip และ npm ในเทอร์มินัลนี้จะผ่านเส้นทางทั้งหมด โปรแกรมอื่นไม่ได้รับผลกระทบ

Docker daemon ไม่อ่านตัวแปรสภาพแวดล้อมของเชลล์ ให้เขียนไว้ใน Environment= ของ /etc/systemd/system/docker.service.d/proxy.conf แล้วรีสตาร์ต docker ส่วน apt ให้เขียน Acquire::https::Proxy ใน /etc/apt/apt.conf.d/proxy.conf

ทางนี้โดยการออกแบบไม่มีการเชื่อมต่อที่จะหลุด ไม่ต้องใช้ root และไม่เปลี่ยนเส้นทางเครือข่าย เหมาะกับเซิร์ฟเวอร์ของบริษัทและกรณีที่แค่อยากให้ดึงไฟล์เร็วขึ้น ใช้ได้เฉพาะโปรแกรมที่อ่านตัวแปรพร็อกซี ทราฟฟิกอื่นไม่ถูกแตะต้อง

## ทางที่สาม: NetworkManager บน Linux เดสก์ท็อป

1. ติดตั้ง network-manager-openvpn-gnome (คลิกเดียวในหน้า OpenVPN ของเว็บไซต์นี้จะเปิดศูนย์ซอฟต์แวร์ให้)
2. การตั้งค่า (Settings) → เครือข่าย (Network) → VPN → "+" → นำเข้าจากไฟล์ (Import from file) เลือก .ovpn ใส่อีเมลและรหัสผ่านที่ใช้กับเว็บไซต์นี้ แล้วบันทึก
3. เปิดปิด VPN จากแถบด้านบนหรือถาดระบบ ถ้าอยากให้เชื่อมต่อเองตอนบูต ให้ติ๊ก "Automatically connect to VPN" (เชื่อมต่อ VPN อัตโนมัติ) ในการตั้งค่าของการเชื่อมต่อแบบสายหรือไร้สาย

## ตรวจสอบและแก้ปัญหา

- ตรวจขาออก: ค่า country ใน curl -s https://ipinfo.io คือภูมิภาคที่คุณเลือก
- ตรวจ DNS: ใน resolvectl status ค่า DNS ของอินเทอร์เฟซ VPN ควรเป็นค่าที่เส้นทางส่งมาให้ ถ้ารั่ว ให้เพิ่ม dhcp-option DNS ในไฟล์ตั้งค่า หรือใช้สคริปต์ update-systemd-resolved
- AUTH_FAILED: ไฟล์รหัสผ่านผิด หรือบัญชีหมดอายุ ถ้าเพิ่งเปลี่ยนรหัสผ่าน ให้แก้ไฟล์รหัสผ่านด้วย
- TLS handshake timeout: UDP ไปถึงเซิร์ฟเวอร์ไม่ได้ ลองเปลี่ยนภูมิภาคหรือเครือข่าย ถ้าเป็นคลาวด์เซิร์ฟเวอร์ ต้องเปิด security group ให้ UDP ขาออกผ่านได้
- เซิร์ฟเวอร์อยู่ในจีนและอยากให้แหล่งดาวน์โหลดในจีนต่อตรง: เมื่อ OpenVPN เชื่อมต่อแล้ว ทราฟฟิกขาออกทั้งหมดจะผ่านเส้นทาง ให้เปลี่ยนแหล่งของ apt / pip / npm เป็นมิเรอร์ในจีน หรือเปลี่ยนไปใช้ทางที่สอง ให้เฉพาะบางคำสั่งผ่านเส้นทาง

## เรื่องที่ควรรู้

- Linux หนึ่งเครื่องนับเป็นหนึ่งอุปกรณ์ และใช้โควตาออนไลน์พร้อมกันร่วมกับอุปกรณ์อื่นของคุณ (แพ็กเกจส่วนตัว 2 เครื่อง ครอบครัว 4 เครื่อง องค์กร 8 เครื่อง) เว็บพร็อกซีในทางที่สองนับตามการเชื่อมต่อ และนับรวมด้วยเช่นกัน
- ไฟล์ตั้งค่ากับไฟล์รหัสผ่านมีค่าเท่ากับบัญชีของคุณ อย่า commit ลง git repository หรือใส่ไว้ในอิมเมจ
- เมื่อเปลี่ยนรหัสผ่าน ไฟล์ตั้งค่าเดิมจะใช้ไม่ได้ทันที นี่คือกลไกเพิกถอนสิทธิ์ที่ออกแบบไว้ แค่แก้ไฟล์รหัสผ่านก็พอ
- ถ้ารันเส้นทางบนคลาวด์เซิร์ฟเวอร์ ให้ปฏิบัติตามข้อกำหนดการใช้งานของผู้ให้บริการคลาวด์ เส้นทางบันทึกแค่ระยะเวลาเชื่อมต่อและปริมาณข้อมูลรวมเท่านั้น

## คำถามที่พบบ่อย

**ทำไมไฟล์ตั้งค่าสำหรับ Linux ถึงไม่ฝังบัญชีและรหัสผ่านไว้?** ตอนนำเข้าไฟล์ตั้งค่า NetworkManager ไม่รับไฟล์ที่ฝังข้อมูลล็อกอินและจะแจ้งว่านำเข้าไม่สำเร็จ ไฟล์ที่ออกให้ Linux จึงให้คุณกรอกเอง ถ้าใช้วิธี systemd ให้เขียนไว้ในไฟล์รหัสผ่าน

**ให้แค่ Docker ผ่านเส้นทางได้ไหม?** ได้: ตั้งตัวแปรพร็อกซีให้ Docker daemon อย่างเดียว (ทางที่สอง) หรือรันคอนเทนเนอร์ที่มี OpenVPN อยู่ข้างใน (gluetun) เพื่อให้เฉพาะคอนเทนเนอร์ที่ต้องการผ่านเส้นทาง

**แล้วเครือข่ายส่วนตัว (Tailscale) บน Linux ล่ะ?** สคริปต์ทางการติดตั้งได้ในบรรทัดเดียว แล้ว tailscale up --login-server=<เซิร์ฟเวอร์ควบคุมของเว็บไซต์นี้> เพื่อล็อกอิน เหมาะกับกรณีที่ต้องเข้าเครื่องนี้จากข้างนอก หรืออยากตั้งค่าครั้งเดียวแล้วออนไลน์ตลอด ถ้าแค่อยากให้ดึงไฟล์เร็วขึ้น OpenVPN หรือพร็อกซีง่ายกว่า

**OpenWrt บนเราเตอร์ทำแบบเดียวกันไหม?** บน OpenWrt ให้ติดตั้ง luci-app-openvpn แล้วอัปโหลด .ovpn ทั้ง LAN ก็จะผ่านเส้นทาง เราเตอร์ที่ใช้เฟิร์มแวร์ของเว็บไซต์นี้ไม่ต้องทำแบบนี้ แค่ล็อกอินบัญชีก็พอ
