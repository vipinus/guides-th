# 06 · ให้ NAS ของ Synology หรือ QNAP ผ่านเส้นทาง

NAS คืออุปกรณ์ในบ้านที่ต้องใช้เส้นทางมากที่สุด แต่คนมักลืมนึกถึง: โปรแกรมดาวน์โหลดต้องเข้าแหล่งไฟล์ต่างประเทศ Docker ต้องดึงอิมเมจ Cloud Sync ต้องซิงก์คลาวด์ไดรฟ์ต่างประเทศ และ Plex ต้องดึงข้อมูลหนัง NAS รัน Hiddify ไม่ได้ แต่ทั้ง Synology และ QNAP มีไคลเอนต์ OpenVPN ในตัว: ดาวน์โหลดไฟล์ .ovpn จากหน้า OpenVPN ของเว็บไซต์นี้ นำเข้าแล้วก็เชื่อมต่อได้ และเชื่อมต่อใหม่เองเมื่อเปิดเครื่อง บทความนี้อธิบายว่าเมนูนำเข้าอยู่ตรงไหนบน Synology และ QNAP ตัวเลือกสำคัญ "Use default gateway" (ใช้เกตเวย์เริ่มต้น) ต้องทำอะไรหลังเปลี่ยนรหัสผ่าน และทำไม "การเข้า NAS จากข้างนอก" เป็นอีกเรื่องหนึ่งที่ต้องใช้เครือข่ายส่วนตัว

## แยกสองเรื่องนี้ออกจากกันก่อน

ให้ตัว NAS เองผ่านเส้นทาง (ดาวน์โหลด ดึงอิมเมจ ซิงก์คลาวด์ไดรฟ์ต่างประเทศ): ใช้ OpenVPN ซึ่งเป็นเรื่องที่บทความนี้อธิบาย

เข้า NAS จากข้างนอก (เปิดโฟลเดอร์แชร์ตอนเดินทางไปทำงาน ดูกล้อง): ใช้เครือข่ายส่วนตัว (Tailscale) ซึ่งเอา NAS กับมือถือของคุณมาไว้ในเครือข่ายส่วนตัวเดียวกัน ดู "ดูกล้องวงจรปิดและ NAS ที่บ้านในจีนจากต่างประเทศ" งานนี้ให้เครือข่ายส่วนตัวทำ: OpenVPN ต่อ NAS เข้ากับเส้นทางของเรา ส่วนเครือข่ายส่วนตัวต่อคุณเข้าบ้าน

## Synology

1. ล็อกอินเว็บไซต์นี้ แล้วในหน้า OpenVPN คลิกธงของภูมิภาคเพื่อดาวน์โหลดไฟล์ .ovpn ของภูมิภาคนั้น
2. Control Panel (แผงควบคุม) → Network (เครือข่าย) → Network Interface (อินเทอร์เฟซเครือข่าย) → Create (สร้าง) → Create VPN profile (สร้างโปรไฟล์ VPN) → OpenVPN (via importing a .ovpn file) (OpenVPN แบบนำเข้าไฟล์ .ovpn) แล้วใส่อีเมลบัญชีและรหัสผ่านของเว็บไซต์นี้
3. "Use default gateway" (ใช้เกตเวย์เริ่มต้น): ถ้าติ๊ก ข้อมูลขาออกทั้งหมดของ NAS จะผ่านเส้นทาง (ดาวน์โหลด Docker และ Cloud Sync ได้ประโยชน์หมด) ถ้าไม่ติ๊ก จะแค่สร้างอุโมงค์ไว้ แต่ข้อมูลขาออกยังออกทางเน็ตที่บ้านเหมือนเดิม เกือบทุกกรณีควรติ๊ก
4. ติ๊ก "Reconnect when the VPN connection is lost" (เชื่อมต่อใหม่เมื่อการเชื่อมต่อ VPN หลุด) เพื่อให้กลับมาเชื่อมต่อเองหลัง NAS รีสตาร์ตหรือเส้นทางสะดุด เชื่อมต่อแล้วลองดึงอะไรสักอย่างในแพ็กเกจดู

## QNAP

1. ดาวน์โหลดไฟล์ .ovpn แบบเดียวกัน
2. QVPN Service → VPN Client → Add (เพิ่ม) → OpenVPN นำเข้าไฟล์ แล้วใส่บัญชีและรหัสผ่าน
3. ในการตั้งค่าการเชื่อมต่อ ติ๊ก "Use VPN as the default gateway of the NAS" (ใช้ VPN เป็นเกตเวย์เริ่มต้นของ NAS) และการเชื่อมต่อใหม่อัตโนมัติ แล้วกดเชื่อมต่อ

## ข้อมูลไหนผ่าน ข้อมูลไหนไม่ผ่าน

- ผ่าน: งาน BT และ HTTP ใน Download Station, การดึงอิมเมจ Docker, Cloud Sync ที่ซิงก์ Google Drive / Dropbox / OneDrive, การดึงข้อมูลหนังของ Plex และ Emby และการอัปเดตใน Package Center
- ไม่ผ่าน: ข้อมูลตอนคุณเข้า NAS ในวงแลน ซึ่งอยู่ในวงแลนอยู่แล้วและไม่ได้รับผลกระทบ
- ถ้าคุณอยู่ในจีนและอยากให้เว็บจีนวิ่งตรง: NAS ไม่มีสคริปต์แยกเส้นทาง พอ OpenVPN เชื่อมต่อแล้ว ข้อมูลขาออกทั้งหมดของ NAS จะผ่านเส้นทาง ถ้าแหล่งดาวน์โหลดในจีนช้า ให้ใช้ที่อยู่มิร์เรอร์ในจีนในงานดาวน์โหลด หรือเชื่อมต่อเส้นทางเฉพาะตอนที่ต้องใช้

## สิ่งที่ควรรู้

- ไฟล์ตั้งค่ามีบัญชีของคุณอยู่ในนั้น และรหัสผ่านที่ใส่ไว้บน NAS จะใช้ไม่ได้หลังคุณเปลี่ยนรหัสผ่าน: ดาวน์โหลดไฟล์ .ovpn ใหม่มาแทน หรือแก้แค่รหัสผ่านในโปรไฟล์ VPN
- เมื่อบัญชีหมดอายุ NAS จะถูกตัดการเชื่อมต่อ ต่ออายุแล้วจะเชื่อมต่อใหม่เอง ไม่ต้องเปลี่ยนการตั้งค่า
- NAS นับเป็นหนึ่งเครื่อง และใช้โควตาออนไลน์พร้อมกันร่วมกับอุปกรณ์อื่นของคุณ (ส่วนตัว 2 เครื่อง ครอบครัว 4 เครื่อง องค์กร 8 เครื่อง)
- เส้นทางวิ่งบน UDP และ NAS ที่ต่อเน็ตบ้านแทบไม่เคยเจอการจำกัด UDP

## คำถามที่พบบ่อย

**ติ๊ก "Use default gateway" แล้ว ยังเข้า NAS ในวงแลนได้ไหม?** ได้ ข้อมูลในวงแลนไม่ผ่านเกตเวย์ โฟลเดอร์แชร์ การเล่น Plex และหน้าแอดมินไม่ได้รับผลกระทบเลย

**ให้ NAS ผ่านเส้นทางแล้ว Plex เล่นจากระยะไกลช้าลง?** การเล่น Plex จากระยะไกลใช้ข้อมูลขาออกของ NAS พอติ๊กเกตเวย์เริ่มต้นแล้วจึงต้องอ้อมผ่านเส้นทาง สำหรับการเล่นจากระยะไกล เข้า NAS ผ่านเครือข่ายส่วนตัวตรงกว่า หรือเชื่อมต่อ OpenVPN เฉพาะตอนที่ต้องดาวน์โหลด

**ให้แค่ Download Station ผ่านเส้นทางได้ไหม?** Synology และ QNAP ไม่มีการแยกเส้นทางรายแอป ถ้าต้องการคุมละเอียด ให้รันคอนเทนเนอร์ดาวน์โหลดที่มี OpenVPN ใน Docker (เช่น qbittorrent + gluetun) แล้วส่งเฉพาะตัวนั้นผ่านเส้นทาง

**ถ้า NAS ใช้ระบบ Linux (TrueNAS, Unraid) ล่ะ?** ทำแบบ Linux: ติดตั้งแพ็กเกจ openvpn แล้ววางไฟล์ตั้งค่าไว้ใน /etc/openvpn/client/ ดู "ให้เซิร์ฟเวอร์ Linux และเครื่องมือบรรทัดคำสั่งผ่านเส้นทาง"
