# 07 · ติดตั้ง Telegram และ Discord

ทั้งสองตัวเป็นแอปแชตกลุ่มที่ใช้กันแพร่หลาย และกลุ่มซัพพอร์ตของเราก็อยู่บนสองแอปนี้ การติดตั้งเองไม่ยาก ที่ติดกันบ่อยคือ "เปิดสโตร์แอปไม่ได้"

## Telegram

| แพลตฟอร์ม | วิธีติดตั้ง |
|---|---|
| Windows / macOS / Linux / Android | [หน้าติดต่อของเว็บไซต์นี้](https://www.leotun.com/th/contact?utm_source=github&utm_content=client-07) มีไฟล์ติดตั้งที่เหมือนกับเวอร์ชันทางการทุกอย่าง (Android เป็นไฟล์ APK ทางการฉบับเต็ม ไม่ต้องใช้ Google Play) หรือจะไปที่เว็บทางการ <https://desktop.telegram.org> หรือ Google Play ก็ได้ |
| iOS | ติดตั้งได้จาก App Store เท่านั้น ปัญหาเรื่องภูมิภาคของสโตร์ ดู[บทความก่อนหน้า](06-ios-app-store.md) |

การสมัครต้องใช้เบอร์มือถือที่รับ SMS ได้ หลังจากนั้นตั้งชื่อผู้ใช้ (username) ได้ และคนอื่นไม่จำเป็นต้องรู้เบอร์ของคุณ

## Discord

| แพลตฟอร์ม | วิธีติดตั้ง |
|---|---|
| Windows / macOS / Linux | เว็บทางการ <https://discord.com/download> |
| Android | ทางการมีให้แค่บน Google Play มือถือที่ติดตั้ง Play ไม่ได้ ใช้ไฟล์แบบแยกส่วน (.apks) ได้ ซึ่งต้องติดตั้งตัวติดตั้งโอเพนซอร์สชื่อ SAI ก่อน และรองรับเฉพาะอุปกรณ์ arm64 |
| iOS | App Store |

## หลังติดตั้ง

- อ่านกฎของกลุ่มก่อนเข้าร่วม กลุ่มส่วนใหญ่ห้ามโฆษณา ก่อนถามอะไร ลองค้นประวัติแชตในกลุ่มก่อน หลายคำถามมีคำตอบอยู่แล้ว
- ถ้าติดตั้งไม่ได้ หรือเปิดแล้วเด้งออก ให้บอกฝ่ายซัพพอร์ตว่าใช้ระบบเวอร์ชันอะไรและอุปกรณ์รุ่นไหน ส่วนใหญ่เป็นเพราะรุ่นหรือเวอร์ชันไม่ตรงกัน
