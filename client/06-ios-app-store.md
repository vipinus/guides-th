# 06 · iOS ไม่ยอมให้ติดตั้งแอป ทำอย่างไร

ถ้าหา Hiddify, Tailscale หรือ Telegram บน iPhone ไม่เจอ หรือขึ้นว่า "แอปนี้ไม่มีให้บริการในประเทศหรือภูมิภาคของคุณในขณะนี้" แอปไม่ได้หายไปไหน: App Store แบ่งสโตร์ตามภูมิภาคของ Apple ID และสโตร์จีนไม่มีแอปด้านเครือข่ายส่วนใหญ่ บน iOS ให้ติดตั้งจาก App Store ด้วย Apple ID ที่ไม่ใช่ภูมิภาคจีน ขั้นตอนอยู่ในหน้านี้ เราแนะนำให้สมัครบัญชีใหม่แทนการเปลี่ยนบัญชีเดิม ด้านล่างคือขั้นตอน เคล็ดลับการเลือกวิธีชำระเงินเป็น "ไม่มี" และเหตุผลที่ห้ามใช้บัญชีที่คนอื่นแชร์มาเด็ดขาด

## ทำไมถึงเป็นแบบนี้

App Store แบ่งสโตร์ตามภูมิภาคของ Apple ID และแต่ละภูมิภาคมีแอปไม่เหมือนกัน สโตร์จีนไม่มีทั้ง Hiddify และ Tailscale ส่วน Telegram กับ Discord ก็มีบ้างหายบ้าง Cisco Secure Client และ OpenVPN Connect มีในภูมิภาคส่วนใหญ่ นี่เป็นความต่างของรายการแอปในสโตร์ ไม่ใช่ปัญหาของตัวแอป บัญชีภูมิภาคอื่นติดตั้งได้

บน iPhone ทั้ง Hiddify และเครือข่ายส่วนตัว (Tailscale) ของเว็บไซต์นี้ติดตั้งจาก App Store แค่ทำตามขั้นตอนด้านล่างเพื่อสลับไปใช้ Apple ID ภูมิภาคอื่น ส่วนตัวติดตั้งสำหรับ Android, Windows และ macOS เว็บไซต์นี้ให้ดาวน์โหลดโดยตรง จึงไม่ได้รับผลกระทบ

## ทางที่ 1 (แนะนำ): สมัคร Apple ID ใหม่ที่ไม่ใช่ภูมิภาคจีน

1. ออกจากบัญชี App Store ปัจจุบัน: การตั้งค่า (Settings) → ชื่อของคุณด้านบนสุด → สื่อและการซื้อ (Media & Purchases) → ออกจากระบบ (Sign Out) ขั้นนี้ออกจาก App Store เท่านั้น ไม่ได้ออกจาก iCloud รูปภาพ ข้อมูลสำรอง และรายชื่อติดต่อจึงไม่ได้รับผลกระทบ
2. ใน App Store หาแอปฟรีสักตัว แตะ "รับ" (Get) แล้วทำตามที่ระบบบอกเพื่อ "สร้าง Apple ID ใหม่" (Create New Apple ID) เลือกภูมิภาคเป็นสหรัฐอเมริกา ฮ่องกง ญี่ปุ่น หรือสิงคโปร์ก็ได้ และเลือกวิธีชำระเงินเป็น "ไม่มี" (None) ตัวเลือก "ไม่มี" นี้จะขึ้นเฉพาะตอนสมัครระหว่างดาวน์โหลดแอปฟรีเท่านั้น ถ้าสมัครผ่านเว็บโดยตรงมักไม่มีให้เลือก
3. ล็อกอิน App Store ด้วยบัญชีใหม่ แล้วค้นหาและดาวน์โหลด Hiddify, Tailscale และ Telegram
4. ติดตั้งเสร็จแล้วจะสลับกลับไปบัญชีเดิมก็ได้ แอปที่ติดตั้งไว้ยังใช้และอัปเดตได้ตามปกติ เมื่อต้องการติดตั้งแอปใหม่ค่อยสลับอีกครั้ง

## ทางที่ 2: เปลี่ยนภูมิภาคของบัญชีเดิม

ล็อกอินที่ account.apple.com แล้วเปลี่ยนประเทศหรือภูมิภาค คุณต้องยกเลิกการสมัครสมาชิกทั้งหมดและใช้ยอดคงเหลือให้หมดก่อน บางกรณียังต้องเพิ่มวิธีชำระเงินของภูมิภาคใหม่ และจะเปลี่ยนกลับก็ยุ่งยากพอกัน ไม่แนะนำ เว้นแต่คุณตั้งใจจะย้ายภูมิภาคระยะยาวอยู่แล้ว

## สิ่งที่ห้ามทำเด็ดขาด

- อย่าใช้ Apple ID ที่คนอื่นแชร์มา รวมถึง "บัญชีแชร์" ในกลุ่มหรือในเน็ต เจ้าของบัญชีล็อกเครื่องคุณจากระยะไกลได้ และ iPhone ที่ถูกล็อกจะปลดได้โดยเขาคนเดียว เมื่อเปิดการตรวจสอบสิทธิ์สองปัจจัยแล้วจะปิดไม่ได้ ความเสี่ยงและข้อพิพาททั้งหมดตกอยู่ที่คุณ ฝ่ายซัพพอร์ตของเว็บไซต์นี้ก็จะไม่ให้บัญชีแชร์ใดๆ เช่นกัน
- อย่าติดตั้งโปรไฟล์การตั้งค่าที่ไม่รู้ที่มา หรือตัวติดตั้งที่ "เซ็นด้วยใบรับรององค์กร" สิ่งเหล่านี้เป็นทางลัดเลี่ยงสโตร์ที่พบบ่อย และก็เป็นช่องให้ฝังใบรับรองและดักทราฟฟิกด้วย

## หลังติดตั้ง

Hiddify: กลับไปที่หน้า Hiddify ของเว็บไซต์นี้แล้วสแกนโค้ด หรือแตะปุ่ม "ซับสคริปชัน sing-box" เพื่อคัดลอก แล้วสลับไป Hiddify เพื่อเพิ่ม Tailscale: ออกจากบัญชีทางการก่อน แล้วทำตามขั้นตอนในหน้าส่วนตัว (เครือข่ายส่วนตัว) เพื่อใส่ที่อยู่เซิร์ฟเวอร์ควบคุมของเว็บไซต์นี้ Telegram, Discord: ไปที่หน้าติดต่อของเว็บไซต์นี้แล้วสแกนโค้ดเข้ากลุ่ม

## คำถามที่พบบ่อย

**สมัครภูมิภาคอื่นต้องใช้บัตรเครดิตไหม?** ไม่ต้อง ถ้าสมัครตามทางที่ 1 (สมัครระหว่างดาวน์โหลดแอปฟรี) เลือกวิธีชำระเงินเป็น "ไม่มี" ได้

**บัญชีใหม่จะกระทบ iCloud และรูปภาพไหม?** ไม่กระทบ คุณสลับบัญชีแค่ใน App Store ส่วน iCloud ยังอยู่ในบัญชีเดิม

**บน iPad เหมือนกันไหม?** เหมือนกัน iPadOS ใช้กฎ App Store เดียวกัน

**มือถือ Android มีปัญหานี้ไหม?** ไม่มี ตัวติดตั้งสำหรับ Android, Windows, macOS และ Linux เว็บไซต์นี้แจกโดยตรง ไม่ต้องพึ่งร้านแอป
