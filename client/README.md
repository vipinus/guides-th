# คู่มือไคลเอนต์ · การติดตั้งและตั้งค่า

ขั้นตอนทีละขั้นสำหรับ**ติดตั้งและเชื่อมต่อ**แต่ละวิธี ได้แก่ Cisco AnyConnect, Hiddify, ส่วนขยายเว็บพร็อกซี, OpenVPN และเครือข่ายส่วนตัว (Tailscale) รวมถึงวิธีรับมือเมื่อ iOS ไม่ยอมให้ติดตั้งแอป วิธีติดตั้ง Telegram / Discord วิธีตั้งค่าหลายอุปกรณ์ในครั้งเดียว และวิธีทำเมื่อโปรแกรมอย่าง Dropbox ขอให้ใส่พร็อกซี ถ้ายังไม่รู้จะเลือกวิธีไหน ดู[วิธีเชื่อมต่อแบบไหนเหมาะกับสถานการณ์ใด](../network/02-choose-your-connection-method.md) ถ้าติดตั้งแล้วแต่เชื่อมต่อไม่ได้ ดู[การแก้ปัญหา](../troubleshooting/)
