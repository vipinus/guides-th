# 09 · ติดตั้ง Hiddify บนทุกแพลตฟอร์ม: Windows, macOS, Linux, Android, iOS

ไคลเอนต์ที่ใช้กับหมวด Hiddify ของเว็บไซต์นี้คือ Hiddify แบบโอเพนซอร์ส ซึ่งมีแกน sing-box อยู่ในตัว ติดตั้งเสร็จจึงไม่ต้องตั้งค่าอะไรเพิ่ม ทั้งห้าแพลตฟอร์มใช้แอปเดียวกัน แต่ด่านที่ต้องผ่านตอนเปิดครั้งแรกต่างกัน: บน Windows อาจถูกโปรแกรมแอนตี้ไวรัสบล็อกหรือลบ บน Mac อาจขึ้นว่าไฟล์ "เสียหาย" และต้องอนุญาตส่วนขยายเครือข่ายด้วย บน Linux ต้องรันคำสั่งให้สิทธิ์ก่อนโหมด VPN จึงจะทำงาน และบน iPhone หาไม่เจอใน App Store ภูมิภาคจีน บทความนี้อธิบายแยกตามแพลตฟอร์มว่าดาวน์โหลดที่ไหน ติดตั้งอย่างไร เปิดครั้งแรกต้องทำอะไร และปิดท้ายด้วยขั้นตอนสั้นที่สุดในการนำเข้าซับสคริปชันและเชื่อมต่อ

## ดาวน์โหลดที่ไหน

| แพลตฟอร์ม | ไฟล์ติดตั้ง | หาได้ที่ |
|---|---|---|
| Windows | ตัวติดตั้ง (.exe) เฉพาะ x64 | ส่วนดาวน์โหลดในหน้า Hiddify |
| macOS | .dmg แพ็กเกจเดียวใช้ได้ทั้ง Apple silicon และ Intel | ส่วนดาวน์โหลดในหน้า Hiddify |
| Linux | .deb (ตระกูล Debian / Ubuntu) เฉพาะ x64 | ส่วนดาวน์โหลดในหน้า Hiddify |
| Android | .apk มีสองแบบ: ARM64 และ x86-64 | ส่วนดาวน์โหลดในหน้า Hiddify หรือ Google Play |
| iPhone / iPad | Hiddify Proxy & VPN ใน App Store | App Store ต้องใช้ Apple ID ที่ไม่ใช่ภูมิภาคจีน |

ส่วนดาวน์โหลดในหน้า Hiddify จะแนะนำแพ็กเกจสำหรับระบบที่คุณใช้อยู่ให้อัตโนมัติ และมีแพ็กเกจของระบบอื่นเรียงอยู่ด้านล่าง แต่ละแถวมีไอคอน "เว็บไซต์ทางการ" ที่ลิงก์ไปหน้าเผยแพร่ทางการของ Hiddify ให้เทียบเวอร์ชันได้ ระบบเดสก์ท็อปทั้งสาม (Windows, macOS, Linux) มีวิดีโอสอนด้วย

ตัวติดตั้งสำหรับเดสก์ท็อปเป็นสำเนาแพ็กเกจเผยแพร่ทางการของ Hiddify แบบไม่แก้ไข ไม่ได้ดัดแปลงหรือแพ็กใหม่ ก่อนกดอนุญาตให้ผ่าน คุณตรวจเองได้ โดยอัปโหลดไฟล์ติดตั้งไปที่ VirusTotal ดู วิธีทำดูที่[การแก้ปัญหา 06](../troubleshooting/06-antivirus-false-positive.md)

## Windows

1. ดาวน์โหลดตัวติดตั้งจากส่วนดาวน์โหลดในหน้า Hiddify แล้วดับเบิลคลิกเพื่อติดตั้ง (จากการทดสอบล่าสุดของเรา Windows Security ไม่แจ้งเตือน ถ้าโปรแกรมแอนตี้ไวรัสที่คุณติดตั้งไว้แจ้งเตือน ดูคำถามที่พบบ่อยท้าย[การแก้ปัญหา 06](../troubleshooting/06-antivirus-false-positive.md))

## macOS

1. ดาวน์โหลด .dmg จากส่วนดาวน์โหลดในหน้า Hiddify เปิดไฟล์แล้วลาก Hiddify ไปไว้ใน "แอปพลิเคชัน" (Applications)
2. ใน "Finder" → "แอปพลิเคชัน" กด Control ค้างไว้แล้วคลิกไอคอน Hiddify เลือก "เปิด" (Open) แล้วคลิก "เปิด" อีกครั้งในหน้าต่างที่ขึ้นมา
3. ถ้ายังเปิดไม่ได้: "การตั้งค่าระบบ" (System Settings) → "ความเป็นส่วนตัวและความปลอดภัย" (Privacy & Security) ในส่วน "ความปลอดภัย" คลิก "ยังคงเปิด" (Open Anyway) แล้วใส่รหัสผ่านเพื่อยืนยัน
4. ถ้าขึ้นว่า "เสียหายและไม่สามารถเปิดได้" (is damaged and can't be opened): ไฟล์ไม่ได้เสียหาย แต่ Gatekeeper ของระบบบล็อกไว้ เปิด "Terminal" รันคำสั่งด้านล่าง กด Return แล้วใส่รหัสผ่านล็อกอินเครื่อง จากนั้นเปิด Hiddify อีกครั้ง:

```bash
sudo xattr -dr com.apple.quarantine /Applications/Hiddify.app
```

คำสั่งนี้แค่ลบป้ายกักกันที่ระบบติดไว้ว่าไฟล์นี้ดาวน์โหลดมา และมีผลกับแอปนี้แอปเดียว **อย่า**ใช้ `sudo spctl --master-disable` ปิด Gatekeeper ทั้งเครื่อง

ครั้งแรกที่กดเชื่อมต่อหลังติดตั้ง ระบบจะขอให้อนุญาต "ส่วนขยายเครือข่าย" (Network Extension) ด้วย ถ้าข้ามขั้นตอนนี้ ไอคอนจะหมุนไปเรื่อยๆ และไม่มีวันเชื่อมต่อได้:

- **macOS 15 Sequoia ขึ้นไป**: "การตั้งค่าระบบ" → "ทั่วไป" (General) → "รายการเข้าสู่ระบบและส่วนขยาย" (Login Items & Extensions) เลื่อนลงไปที่ "ส่วนขยาย" (Extensions) ด้านล่าง เปลี่ยนมุมมองเป็น "ตามหมวดหมู่" (By Category) คลิก ⓘ ข้าง "ส่วนขยายเครือข่าย" (Network Extensions) เปิดสวิตช์ของ Hiddify แล้วใส่รหัสผ่านหรือสแกนลายนิ้วมือเมื่อระบบถาม
- **macOS 13 Ventura / 14 Sonoma**: เปิด Hiddify แล้วกดเชื่อมต่อหนึ่งครั้งก่อน จะมีหน้าต่าง "ส่วนขยายระบบถูกปิดกั้น" (System Extension Blocked) เด้งขึ้นมา จากนั้นไปที่ "การตั้งค่าระบบ" → "ความเป็นส่วนตัวและความปลอดภัย" เลื่อนลงไปหาข้อความ "ซอฟต์แวร์ระบบจากนักพัฒนา … ถูกบล็อกไม่ให้โหลด" (System software from developer … was blocked from loading) คลิก "อนุญาต" (Allow) แล้วใส่รหัสผ่าน

ถ้าเป็น Mac ที่บริษัทแจก และปุ่มเหล่านี้เป็นสีเทากดไม่ได้ แปลว่านโยบายจัดการอุปกรณ์ของบริษัทล็อกไว้ ให้ถามฝ่ายไอที หรือเปลี่ยนไปใช้ไคลเอนต์ Cisco, OpenVPN หรือเครือข่ายส่วนตัว (Tailscale) แทน

## Linux

1. ดาวน์โหลด .deb จากส่วนดาวน์โหลดในหน้า Hiddify แล้วดับเบิลคลิกติดตั้งด้วยศูนย์ซอฟต์แวร์ หรือเปิดเทอร์มินัลในโฟลเดอร์ที่ดาวน์โหลดแล้วรัน (Debian, Ubuntu และดิสโทรที่แตกมาจากสองตัวนี้):

```bash
sudo apt install ./downloaded-file-name.deb
```

2. ถ้ากดเชื่อมต่อทันทีหลังติดตั้ง จะขึ้น "operation not permitted" (ไม่มีสิทธิ์ทำรายการนี้) และโหมด VPN ไม่เริ่มทำงาน เพราะแพ็กเกจ deb ทางการไม่ได้ให้สิทธิ์นี้หลังติดตั้ง เปิดเทอร์มินัลแล้วรันคำสั่งด้านล่างเพื่อให้สิทธิ์ Hiddify จากนั้นเปิด Hiddify ใหม่:

```bash
echo /usr/share/hiddify/lib | sudo tee /etc/ld.so.conf.d/hiddify.conf && sudo ldconfig && sudo setcap cap_net_admin,cap_net_raw+ep /usr/share/hiddify/hiddify
```

3. **ทุกครั้งที่อัปเกรด Hiddify ต้องรันซ้ำ**: สิทธิ์นี้ผูกอยู่กับไฟล์โปรแกรม การอัปเกรดจะแทนที่ไฟล์ สิทธิ์จึงหายไป

แพ็กเกจ deb เป็น x64 ถ้าเป็นอุปกรณ์ Linux แบบ ARM ให้ใช้ OpenVPN ซึ่งใช้บัญชีเดียวกันได้

## Android

1. ดาวน์โหลด .apk จากส่วนดาวน์โหลดในหน้า Hiddify หน้าเว็บจะแนะนำสถาปัตยกรรมที่ตรงกับมือถือของคุณให้อัตโนมัติ มือถือส่วนใหญ่เป็น ARM64 ถ้าใช้ Google Play ได้ จะติดตั้งจากสโตร์โดยตรงก็ได้
2. ถ้าระหว่างติดตั้งมีข้อความเรื่อง "แหล่งที่ไม่รู้จัก" หรือคำเตือนจากแอปความปลอดภัย ให้กดอนุญาต
3. ครั้งแรกที่แตะเชื่อมต่อ ระบบจะขอสิทธิ์ VPN ให้แตะอนุญาต

## iPhone / iPad

1. ค้นหา "Hiddify" ใน App Store แล้วติดตั้ง แอปนี้ฟรี
2. ถ้าหาไม่เจอ หรือขึ้นว่า "แอปนี้ไม่มีให้บริการในประเทศหรือภูมิภาคของคุณในขณะนี้": บน iOS ให้ติดตั้งจาก App Store ด้วย Apple ID ที่ไม่ใช่ภูมิภาคจีน (Hiddify มีในสโตร์สหรัฐอเมริกา ฮ่องกง ไต้หวัน ญี่ปุ่น และสิงคโปร์) เราแนะนำให้สมัครใหม่: ใน App Store แตะ "รับ" (Get) ที่แอปฟรีตัวไหนก็ได้ → "สร้าง Apple ID ใหม่" (Create New Apple ID) เลือกภูมิภาคอย่างฮ่องกงหรือสหรัฐอเมริกา และเลือกวิธีชำระเงินเป็น "ไม่มี" (None) การสลับบัญชีทำแค่ใน App Store ไม่กระทบ iCloud ขั้นตอนเต็มดูที่ [06 · iOS ไม่ยอมให้ติดตั้งแอป ทำอย่างไร](06-ios-app-store.md)
3. ครั้งแรกที่แตะเชื่อมต่อ ระบบจะขอสิทธิ์ VPN ให้แตะอนุญาต

**อย่า**ใช้ Apple ID ที่คนอื่นแชร์มา เจ้าของบัญชีล็อกเครื่องคุณจากระยะไกลได้

## หลังติดตั้ง: นำเข้าซับสคริปชันแล้วเชื่อมต่อ

1. ล็อกอินเว็บไซต์แล้วเปิดหน้า Hiddify
2. คลิกธงของภูมิภาคที่ต้องการ จะมี QR โค้ดเด้งขึ้นมา หรือคลิก "นำเข้าทุกภูมิภาค · เลือกอัตโนมัติ" ด้านบนของหน้า เพื่อนำเข้าทุกภูมิภาคนอกจีนในครั้งเดียวแล้วให้ไคลเอนต์เลือกเอง **ภูมิภาคจีนต้องนำเข้าแยก**: ถ้าจะดูวิดีโอจีนหรือใช้ธนาคารออนไลน์ของจีนจากต่างประเทศ ให้คลิกธงจีนเพื่อนำเข้า
3. ใต้ QR โค้ดมีสามปุ่ม แบ่งตามประเภทซับสคริปชัน Hiddify ใช้ปุ่มแรก (แสดง Hiddify / sing-box / GUI.for.SingBox / Karing พร้อมคำบรรยายใต้ว่า "ซับสคริปชัน sing-box") และใช้ปุ่มเดียวกันทั้งบนมือถือและคอมพิวเตอร์ มือถือ: แตะปุ่ม แล้วสลับไป Hiddify และเพิ่มตามที่แอปบอก หรือใช้ Hiddify บนอีกเครื่องสแกนโค้ด คอมพิวเตอร์: คลิกเพื่อคัดลอกที่อยู่ https:// แล้วใน Hiddify คลิก "+" → "Add from clipboard" (เพิ่มจากคลิปบอร์ด)
4. คลิกเชื่อมต่อ

ความต่างของสามปุ่ม วิธีนำเข้าใน Clash และไคลเอนต์อื่น และซับสคริปชันหมดอายุไหม ดูที่ [02 · วิธีนำเข้าลิงก์ซับสคริปชัน (Hiddify, Clash, Shadowrocket)](02-singbox-subscription-links.md) ถ้านำเข้าแล้วเชื่อมต่อไม่ได้ ดู[การแก้ปัญหา 04](../troubleshooting/04-singbox-import-not-connecting.md)

## คำถามที่พบบ่อย

**พวกคุณแก้ไขตัวติดตั้งหรือเปล่า?** ไม่ ตัวติดตั้งเดสก์ท็อปเป็นสำเนาแพ็กเกจเผยแพร่ทางการของ Hiddify แบบไม่แก้ไข ทุกแถวในหน้า Hiddify มีลิงก์ไปหน้าเผยแพร่ทางการให้เทียบเวอร์ชันเองได้ และจะอัปโหลดไฟล์ไปที่ VirusTotal เพื่อตรวจซ้ำก็ได้


**รันคำสั่ง xattr บน Mac แล้ว แต่ยังเชื่อมต่อไม่ได้?** ส่วนใหญ่เป็นเพราะยังไม่ได้อนุญาต "ส่วนขยายเครือข่าย" ทำตามหัวข้อ macOS ด้านบน แล้วเปิดสวิตช์ของ Hiddify ในการตั้งค่าระบบ

**อัปเกรด Hiddify บน Linux แล้วโหมด VPN ใช้ไม่ได้อีก?** เป็นเรื่องปกติ หลังอัปเกรดให้รันคำสั่งให้สิทธิ์อีกครั้ง

**ใช้กับคอมพิวเตอร์ Windows หรือ Linux แบบ ARM ได้ไหม?** ได้ แต่ต้องใช้วิธีเชื่อมต่ออื่นอย่าง OpenVPN ซึ่งใช้บัญชีเดียวกันได้ ตอนนี้แพ็กเกจเดสก์ท็อปของ Hiddify เป็น x64

**ไม่อยากวุ่นกับขั้นตอนกดอนุญาต?** Cisco (Cisco Secure Client), OpenVPN (OpenVPN Connect) และเครือข่ายส่วนตัว (Tailscale) ดับเบิลคลิกเปิดได้เลย ไม่ถูกโปรแกรมแอนตี้ไวรัสแจ้งเตือน Mac ก็ไม่ขึ้นว่า "เสียหาย" และใช้บัญชีเดียวกัน
