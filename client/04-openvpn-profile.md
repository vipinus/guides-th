# 04 · OpenVPN: ดาวน์โหลดโปรไฟล์ .ovpn นำเข้าแล้วเชื่อมต่อ ใช้ได้กับเราเตอร์ NAS และ Linux

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/openvpn-setup?utm_source=github&utm_content=client-04

OpenVPN เป็นโปรโตคอลโอเพนซอร์สที่มีมานาน ระบบปฏิบัติการ เฟิร์มแวร์เราเตอร์ และ NAS แทบทุกตัวมีไคลเอนต์ของมันติดมาด้วย ไฟล์โปรไฟล์ของ LeoTun ใส่บัญชี รหัสผ่าน และข้อมูลเข้ารหัสไว้ให้ครบแล้ว นำเข้าแล้วเชื่อมต่อได้เลย สำหรับใช้งานทั่วไปบนมือถือและคอมพิวเตอร์ AnyConnect หรือ Hiddify สะดวกกว่า จุดเด่นของ OpenVPN อยู่ที่**อุปกรณ์ที่รับแค่ OpenVPN**: เราเตอร์ OpenWrt, NAS ของ Synology / QNAP, เซิร์ฟเวอร์ Linux และอุปกรณ์รุ่นเก่า

## สามขั้นตอน

1. จากตารางใน[หน้า OpenVPN ของเว็บไซต์](https://www.leotun.com/th/openvpn?utm_source=github&utm_content=client-04) ติดตั้งไคลเอนต์สำหรับระบบของคุณ (ทุกแพลตฟอร์มมี OpenVPN Connect ทางการ บน Windows ใช้ OpenVPN GUI ก็ได้ บน macOS ใช้ Tunnelblick ก็ได้)
2. ล็อกอินแล้ว**คลิกธงของภูมิภาค**เพื่อดาวน์โหลด .ovpn ของภูมิภาคนั้น หนึ่งไฟล์ต่อหนึ่งภูมิภาค
3. เปิดไฟล์ในไคลเอนต์แล้วเชื่อมต่อ

| แพลตฟอร์ม | หมายเหตุ |
|---|---|
| Windows / macOS / Android / iOS | โปรไฟล์ใส่บัญชีและรหัสผ่านไว้แล้ว นำเข้าแล้วเชื่อมต่อ |
| Linux | การตั้งค่า VPN ของระบบ → นำเข้าจากไฟล์ แล้วใส่อีเมลและรหัสผ่านของเว็บไซต์ตอนเชื่อมต่อครั้งแรก บรรทัดคำสั่ง `openvpn --config file` ถ้าจะให้เปิดเองตอนบูต วางไว้ใน `/etc/openvpn/client/` |
| เราเตอร์ OpenWrt | ติดตั้ง luci-app-openvpn อัปโหลด .ovpn แล้วเปิดใช้ ถ้าติดตั้งเฟิร์มแวร์ของเว็บไซต์นี้ไว้แล้วไม่ต้องทำ |
| NAS Synology | Control Panel (แผงควบคุม) → Network (เครือข่าย) → Network Interface (อินเทอร์เฟซเครือข่าย) → Create (สร้าง) → VPN → OpenVPN (นำเข้า .ovpn) ถ้าจะให้ทราฟฟิกขาออกของ NAS ผ่านเส้นทาง ให้ติ๊ก "Use default gateway on remote network" (ใช้เกตเวย์เริ่มต้นบนเครือข่ายระยะไกล) |
| NAS QNAP | QVPN → VPN Client → Add (เพิ่ม) → OpenVPN แล้วนำเข้า |

## ผู้ใช้ในจีน: ให้เว็บจีนต่อตรง

เมื่อเชื่อมต่อแล้ว ทราฟฟิกที่ไปเว็บจีนจะต้องอ้อม เว็บไซต์มี "เครื่องมือต่อตรงสำหรับจีน" ให้ ดับเบิลคลิกรัน แล้ว IP ของจีนจะต่อตรง ที่เหลือทั้งหมดผ่านเส้นทาง ใช้ได้ทั้งกับ Cisco และ OpenVPN ผู้ใช้ที่อยู่นอกจีนไม่ควรใช้

## ถ้าเชื่อมต่อไม่ได้ ไล่ตรวจตามลำดับนี้

| คำในล็อก / อาการ | สาเหตุ | ทำอย่างไร |
|---|---|---|
| AUTH_FAILED | บัญชีหรือรหัสผ่านผิด หรือหมดอายุ | ล็อกอินเว็บไซต์แล้วดูวันหมดอายุ ถ้าเปลี่ยนรหัสผ่านไปแล้ว ให้ดาวน์โหลดโปรไฟล์ใหม่ |
| UDP หมดเวลาก่อน แล้วค่อยเชื่อมต่อผ่าน TCP | เครือข่ายที่ใช้อยู่จำกัด UDP จึงสลับไป TCP เอง | ใช้ได้แต่ช้ากว่า ถ้าช้าเกินไป ให้เปลี่ยนเครือข่ายหรือใช้ AnyConnect แทน |
| ทั้ง UDP และ TCP ขึ้น TLS handshake failed / key negotiation failed | เส้นทางเครือข่ายไปเซิร์ฟเวอร์ใช้ไม่ได้ | เปลี่ยนภูมิภาคหรือเครือข่าย |
| นำเข้าแล้วขึ้นข้อผิดพลาด | ไคลเอนต์เก่าเกินไป (ก่อน OpenVPN 2.5) | อัปเดตไคลเอนต์ |
| กำลังใช้อยู่แล้วหลุดกะทันหัน | บัญชีหมดอายุและเซิร์ฟเวอร์ตัดการเชื่อมต่อ | ต่ออายุแล้วเชื่อมต่อใหม่ ไม่ต้องเปลี่ยนโปรไฟล์ |

## UDP หรือ TCP

มีให้ทั้งคู่ และไม่ต้องเลือกเอง ในโปรไฟล์ UDP มาก่อน ไคลเอนต์จึงลอง UDP ก่อน ถ้า UDP ถูกจำกัดหรือเชื่อมต่อไม่ได้ จะสลับไป TCP เองในไม่กี่วินาที UDP หน่วงน้อยกว่าและเร็วกว่า TCP เป็นแค่ทางสำรองและช้ากว่าอย่างเห็นได้ชัดเมื่อข้ามประเทศ บนเครือข่ายที่จำกัด UDP ตลอด (เครือข่ายมหาวิทยาลัยและบริษัทบางแห่ง) แนะนำให้ใช้ AnyConnect ไปเลย

> โปรไฟล์ที่ดาวน์โหลดก่อนวันที่ 15 กันยายน 2026 มีแค่ UDP ถ้าอยากได้การสลับอัตโนมัติ ให้ดาวน์โหลดใหม่

## ความปลอดภัย

ไฟล์โปรไฟล์มีบัญชีและรหัสผ่านของคุณอยู่ข้างใน จึงมีค่าเท่ากับตัวบัญชีเอง อย่าส่งต่อให้ใคร ถ้าหลุดออกไป ให้เปลี่ยนรหัสผ่านบนเว็บไซต์ ไฟล์เดิมจะใช้ไม่ได้ทันที ตัวการจับมือ (handshake) เองก็เข้ารหัสด้วย ถ้าไม่มีคีย์ในโปรไฟล์ แม้แต่จะเริ่มจับมือก็ทำไม่ได้ และเครื่องสแกนก็มองไม่เห็นเซิร์ฟเวอร์
