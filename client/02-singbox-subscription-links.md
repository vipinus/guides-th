# 02 · วิธีนำเข้าลิงก์ซับสคริปชัน (Hiddify, Clash, Shadowrocket)

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/singbox-subscription?utm_source=github&utm_content=client-02

"ลิงก์ซับสคริปชัน" ที่ผู้ให้บริการพร็อกซีให้มา จริงๆ ก็คือที่อยู่ HTTPS ที่ไคลเอนต์ใช้ดาวน์โหลดการตั้งค่าทั้งชุด: เซิร์ฟเวอร์ พอร์ต และข้อมูลล็อกอินอยู่ในนั้นหมด ไม่ต้องพิมพ์อะไรเอง หน้า Hiddify ของ LeoTun ก็ให้ของแบบเดียวกัน และให้มาสามรูปแบบเลย Hiddify, Clash และ Shadowrocket ต่างก็ได้แบบของตัวเอง ไม่ต้องแปลงอะไร

## ปุ่มสามปุ่มในหน้าต่างป๊อปอัป

ล็อกอินเว็บไซต์ → หน้า Hiddify → คลิกธงของภูมิภาค QR โค้ดจะเด้งขึ้นมาพร้อมปุ่มสามปุ่มด้านล่าง ปุ่มแบ่ง**ตามประเภทซับสคริปชัน** ไม่ได้แบ่งตามระบบปฏิบัติการ มือถือกับคอมพิวเตอร์จึงเห็นชุดเดียวกัน:

| ไคลเอนต์ที่เขียนบนปุ่ม | ข้อความใต้ปุ่ม | คลิกแล้วคัดลอกอะไร |
|---|---|---|
| Hiddify / sing-box / GUI.for.SingBox / Karing | sing-box subscription (ซับสคริปชัน sing-box) | บนมือถือ เป็นลิงก์นำเข้า `sing-box://import-remote-profile?url=…` ที่เปิดแอปให้เลย บนคอมพิวเตอร์ เป็น URL การตั้งค่าแบบ `https://…` ธรรมดาไว้วาง การตั้งค่ามีกฎแยกเส้นทางและกฎปฏิเสธ IPv6 อยู่แล้ว ไม่ต้องห่อด้วย "เทมเพลตซับสคริปชัน" อีก |
| Clash Meta / Clash Verge / FlClash / Stash / Mihomo Party / Clash Nyanpasu / ClashX Meta / OpenClash | Clash subscription (ซับสคริปชัน Clash) | URL ซับสคริปชันรูปแบบ Clash (YAML) ไว้วางในรายการซับสคริปชัน / โปรไฟล์ของไคลเอนต์ |
| NekoBox / Shadowrocket / v2rayN / v2rayNG / Streisand / V2Box / Loon / Egern / Husi / NekoRay / Pharos Pro / Bedlam / Furious / daed / Lumen KVN / Kitty Pro | Share link (ลิงก์แชร์) | `hysteria2://…` หนึ่งบรรทัด มีแค่โหนด ไม่มีกฎแยกเส้นทาง |

- ถ้าชื่อยาวเกินหนึ่งบรรทัด มันจะเลื่อนวนไปเรื่อยๆ เป็นเรื่องปกติ
- **คลิกปุ่มไหน QR โค้ดด้านบนก็จะเปลี่ยนเป็นประเภทนั้นด้วย** ไคลเอนต์ที่ตรงกันจึงสแกนได้ ตอนเปิดหน้าต่างครั้งแรก QR โค้ดเป็นแบบ Hiddify / sing-box ไคลเอนต์อื่นสแกนตรงๆ จะขึ้นว่า "Invalid QR code" (QR โค้ดไม่ถูกต้อง): ให้คลิกปุ่มของไคลเอนต์คุณก่อน แล้วค่อยสแกนหรือวาง
- หน้าต่าง "Import all regions · auto-select" (นำเข้าทุกภูมิภาค · เลือกอัตโนมัติ) ที่ด้านบนของหน้ามีแค่สองปุ่มแรก ไม่มีลิงก์แชร์

**การแปลงซับสคริปชัน**: เว็บของบุคคลที่สามที่แปลงรูปแบบหนึ่งเป็นอีกรูปแบบ LeoTun ให้ครบทั้งสามรูปแบบอยู่แล้ว จึง**ไม่ต้องแปลง** การยื่นลิงก์ที่มีข้อมูลล็อกอินของคุณให้เว็บแปลง ก็เท่ากับยื่นบัญชีให้คนอื่น อย่าทำ

## กลุ่ม Hiddify / sing-box: ปุ่มแรก

1. ติดตั้ง Hiddify (Android: หน้าดาวน์โหลดของเว็บไซต์หรือ Google Play iOS: App Store แอปเดสก์ท็อปใช้ได้กับ Windows / macOS / Linux) มีแกน sing-box ในตัว
2. คลิกธงของภูมิภาค QR โค้ดจะเด้งขึ้นมา
3. มือถือ: แตะปุ่มแรกแล้วสลับไป Hiddify แอปจะเสนอให้เพิ่มจากคลิปบอร์ด หรือใช้ "Scan QR code" (สแกน QR โค้ด) ใน Hiddify บนอีกเครื่อง คอมพิวเตอร์: คลิกปุ่มเดียวกัน ซึ่งจะคัดลอกที่อยู่ https:// แล้วใน Hiddify กด "+" → "Add from clipboard" (เพิ่มจากคลิปบอร์ด) แล้วบันทึก
4. แตะเชื่อมต่อ และอนุญาตสิทธิ์ VPN ในครั้งแรก จะเพิ่มภูมิภาคก็คลิกธงอื่น แต่ละภูมิภาคเป็นโปรไฟล์แยกกัน

## กลุ่ม Clash: ปุ่มที่สอง

สำหรับ Clash Meta (mihomo), Clash Verge, FlClash, Stash และตัวที่คล้ายกัน ให้คลิกปุ่ม "Clash subscription" แล้ววาง URL ที่คัดลอกมาลงในรายการซับสคริปชัน / โปรไฟล์ของไคลเอนต์ ไม่ต้องใช้ตัวแปลงซับสคริปชัน

**ไคลเอนต์กลุ่ม Clash ห้ามใช้ลิงก์แชร์**: มันนำเข้า `hysteria2://` บรรทัดเดียวเป็นโปรไฟล์ไม่ได้

## ไคลเอนต์อื่น: ปุ่มที่สาม

คลิกปุ่ม "Share link" แล้วใช้ "Import from clipboard" (นำเข้าจากคลิปบอร์ด) ใน NekoBox / Shadowrocket / v2rayN / v2rayNG และตัวอื่นๆ หรือคลิกปุ่มแล้วสแกน QR โค้ดด้านบน ลิงก์แชร์ไม่มีกฎ คุณต้องตั้งการแยกเส้นทางและ IPv6 เอง: ถ้าอยู่ต่างประเทศและอยากดูเนื้อหาจีน ให้ส่งโดเมนจีนผ่านโหนด และปิด IPv6

ไคลเอนต์ที่อยู่หลัง v2rayN บนปุ่มรองรับ hysteria2 ทั้งหมด แต่ลิงก์แชร์ใช้รูปแบบ hysteria2 แบบขยาย ซึ่งไคลเอนต์บางตัวอ่านไม่ออก ถ้านำเข้าไม่สำเร็จหรือเชื่อมต่อไม่ได้ ให้เปลี่ยนไปใช้ Hiddify

## ไคลเอนต์ที่ใช้ไม่ได้

| ไคลเอนต์ | เหตุผล |
|---|---|
| Surge | รองรับ hysteria2 แต่อ่านได้แค่รูปแบบการตั้งค่าของตัวเอง ทั้งสามแบบจึงใช้ไม่ได้ |
| Quantumult X | ไม่รองรับเส้นทางแบบนี้ |
| Clash ตัวดั้งเดิม, Clash for Windows | แกนไม่มี hysteria2 ให้ใช้ไคลเอนต์ที่ใช้แกน mihomo แทน |

## ซับสคริปชันหมดอายุไหม?

- **ไม่หมดอายุตามเวลา** โทเคนใน URL ซับสคริปชันผูกกับบัญชีของคุณ ใช้ได้ตราบที่บัญชียังไม่หมดอายุ ต่ออายุหรือเปลี่ยนแพ็กเกจก็ไม่ต้องนำเข้าใหม่
- **เปลี่ยนรหัสผ่านแล้ว URL เก่าใช้ไม่ได้ทันที** นี่คือวิธียกเลิกสิทธิ์ถ้ามือถือหายหรือลิงก์หลุด เปลี่ยนแล้วให้สแกนโค้ดใหม่
- **หลังบัญชีหมดอายุ** URL จะตอบกลับเป็น 401 พอต่ออายุแล้ว โปรไฟล์เดิมไม่ต้องเปลี่ยน
- **โปรไฟล์ที่นำเข้าก่อนเดือนกันยายน 2026** ไม่มีกฎปฏิเสธ IPv6 ให้ลบแล้วนำเข้าใหม่

ถ้านำเข้าแล้วแต่เชื่อมต่อไม่ได้ ดู[การแก้ปัญหา 04](../troubleshooting/04-singbox-import-not-connecting.md)

## คำถามที่พบบ่อย

**ซับสคริปชัน Hiddify กับซับสคริปชัน Clash ต่างกันอย่างไร?** รูปแบบต่างกัน (JSON กับ YAML) ไคลเอนต์แต่ละฝั่งไม่รู้จักซับสคริปชันของอีกฝั่ง แต่โหนดเองใช้ได้ทั้งสองแบบ LeoTun ให้ทั้งสองแบบมาเลย: ไคลเอนต์กลุ่ม Clash ให้คลิกปุ่ม "Clash subscription" และห้ามใช้ลิงก์แชร์

**โปรไฟล์เดียวรวมทุกภูมิภาคได้ไหม?** นำเข้าจากธงจะได้หนึ่งโปรไฟล์ต่อหนึ่งภูมิภาค แล้วสลับกันในรายการโปรไฟล์ของไคลเอนต์ แบบนี้ถ้าที่อยู่ของภูมิภาคไหนเปลี่ยน ก็กระทบแค่ภูมิภาคนั้น ถ้าจะนำเข้าทุกภูมิภาคนอกจีนในครั้งเดียวแล้วให้ไคลเอนต์เลือกเอง ให้คลิก "Import all regions · auto-select" ที่ด้านบนของหน้า (มีแค่ปุ่ม sing-box subscription กับ Clash subscription)

**ส่ง QR โค้ดให้คนในครอบครัวได้ไหม?** QR โค้ดมีข้อมูลล็อกอินบัญชีของคุณ ส่งให้ใครคนนั้นก็ได้บัญชีคุณไป แชร์ให้ครอบครัวได้ (จำนวนเครื่องพร้อมกันตามแพ็กเกจ: ส่วนตัว 2 ครอบครัว 4 องค์กร 8) แต่อย่าโพสต์ในที่สาธารณะ ถ้าหลุด เปลี่ยนรหัสผ่านแล้วมันจะใช้ไม่ได้
