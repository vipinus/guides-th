# 08 · ตั้งค่าหลายอุปกรณ์ครั้งเดียว เปลี่ยนมือถือก็ไม่ต้องเริ่มใหม่

สำหรับคนที่มีอุปกรณ์หลายเครื่อง เรื่องน่าหงุดหงิดที่สุดคือต้องตั้งค่าทีละเครื่อง เปลี่ยนมือถือแล้วต้องทำใหม่หมด และออกไปข้างนอกก็ต้องกดเชื่อมต่อทีละเครื่อง เครือข่ายส่วนตัว (Tailscale) ตัดเรื่องพวกนี้ทิ้งไปหมด: แต่ละเครื่องล็อกอินด้วยบัญชีเว็บไซต์นี้ครั้งเดียวแล้วออนไลน์ค้างไว้ รีสตาร์ตหรือเปลี่ยน Wi‑Fi ก็ไม่ต้องทำอะไร แต่ละเครื่องเลือกภูมิภาคขาออกของตัวเอง โน้ตบุ๊กใช้ญี่ปุ่น มือถือใช้ภูมิภาคจีน ไม่กระทบกัน อุปกรณ์ในบัญชีเดียวกันเข้าถึงกันได้ โน้ตบุ๊กที่อยู่นอกบ้านจึงเปิดโฟลเดอร์แชร์บน NAS ที่บ้านได้โดยตรง มือถือเครื่องใหม่แค่ล็อกอินก็ใช้ได้ บทความนี้อธิบายวิธีเอาอุปกรณ์ทั้งบ้านเข้ามา การนับโควตา และการรับมือเมื่อหมดอายุหรือเปลี่ยนเครื่อง

## สิ่งที่ทำแค่ครั้งเดียวต่อเครื่อง

1. ติดตั้งไคลเอนต์ Tailscale (Android, Windows, macOS และ Linux ดาวน์โหลดได้จากส่วนดาวน์โหลดในหน้าส่วนตัว (เครือข่ายส่วนตัว) ของเว็บไซต์นี้ ส่วน iPhone / iPad ติดตั้งจาก App Store ซึ่งต้องใช้ Apple ID ที่ไม่ใช่ภูมิภาคจีน)
2. ถ้าเคยล็อกอินบัญชี Tailscale ทางการไว้ ให้ออกจากระบบก่อน แล้วชี้การล็อกอินไปที่เซิร์ฟเวอร์ควบคุมของเว็บไซต์นี้ (มือถือ: "⋯" ในหน้าจอที่ออกจากระบบแล้ว → Use custom server (ใช้เซิร์ฟเวอร์ที่กำหนดเอง) คอมพิวเตอร์: คัดลอกคำสั่งจากหน้าเว็บ macOS: Account Settings → Accounts → ลูกศรข้าง "Add Account…" → Add Account Using Alternate Server (เพิ่มบัญชีด้วยเซิร์ฟเวอร์อื่น))
3. ยืนยันในเบราว์เซอร์ด้วยบัญชีเว็บไซต์นี้ จากนั้นเครื่องนี้ก็อยู่ในเครือข่ายส่วนตัว ไม่ต้องดูแลอะไรอีก
4. เลือกขาออก: แต่ละเครื่องเลือกในเมนูของตัวเอง ไม่ขึ้นกับเครื่องอื่น ถ้าไม่ต้องการขาออก ให้เลือก None (ไม่มี) ซึ่งจะเหลือแค่การเข้าถึงกันระหว่างอุปกรณ์

## นับอุปกรณ์ที่ออนไลน์พร้อมกันอย่างไร

บัญชีเดียวติดตั้งได้กี่เครื่องก็ได้ ที่จำกัดมีแค่จำนวนที่ออนไลน์พร้อมกัน: แพ็กเกจส่วนตัว 2 ครอบครัว 4 องค์กร 8 และใช้โควตาเดียวกันกับ Cisco, Hiddify และวิธีอื่น ถ้าเกินโควตาของแพ็กเกจ ก็อัปเกรดประเภทบัญชีชั่วคราวได้ (เวลาที่เหลือแปลงตามมูลค่าราคาเท่ากัน) ใช้เสร็จค่อยเปลี่ยนกลับ

เราเตอร์นับเป็นหนึ่งเครื่อง อุปกรณ์ที่ต่ออยู่หลังเราเตอร์ไม่นับ เราเตอร์หรือ NAS หนึ่งเครื่องที่บ้าน บวกมือถือกับโน้ตบุ๊กที่พกติดตัว ส่วนใหญ่ก็พอแล้ว

## อุปกรณ์เข้าถึงกันได้

- อุปกรณ์แต่ละเครื่องในบัญชีเดียวกันมีที่อยู่ในเครือข่ายส่วนตัว และเรียกด้วยชื่ออุปกรณ์ได้ด้วย ไม่ต้องมี IP สาธารณะหรือทำ port forwarding
- เปิดโฟลเดอร์แชร์บน NAS ที่บ้านจากโน้ตบุ๊กนอกบ้าน ดูเครื่องบันทึกวิดีโอที่บ้านจากมือถือ หรือรีโมตเดสก์ท็อปเข้าคอมพิวเตอร์ที่บ้าน ทั้งหมดต่อตรงด้วยที่อยู่ในเครือข่ายส่วนตัว
- เราเตอร์ที่บ้านซึ่งใช้เฟิร์มแวร์ของเว็บไซต์นี้แชร์ LAN ทั้งวงเข้าเครือข่ายส่วนตัวได้ อุปกรณ์ที่ลงไคลเอนต์ไม่ได้อย่างเครื่องพิมพ์และทีวีจึงเข้าจากข้างนอกได้ด้วย
- อุปกรณ์ของลูกค้าคนอื่นไม่ได้อยู่ในเครือข่ายส่วนตัวของคุณเลย ไม่ใช่แค่ว่าคุณมองไม่เห็น

## หมดอายุ เปลี่ยนเครื่อง ถอนการติดตั้ง

- บัญชีหมดอายุ: ทุกเครื่องออฟไลน์ภายในไม่กี่นาที ต่ออายุแล้วล็อกอินอีกครั้งทีละเครื่อง การตั้งค่าขาออกยังอยู่
- เปลี่ยนมือถือ: ล็อกอินบนเครื่องใหม่ตามขั้นตอนด้านบน ถ้าขึ้นว่าเกินโควตา ให้ออกจากระบบบนเครื่องเก่า หรืออัปเกรดประเภทบัญชีชั่วคราวแล้วเปลี่ยนกลับเมื่อใช้เสร็จ
- ถ้าไม่อยากให้เครื่องไหนอยู่ในเครือข่ายส่วนตัวต่อ: ออกจากระบบในไคลเอนต์ ถ้าจะบังคับให้เครื่องไหนออฟไลน์ ติดต่อฝ่ายซัพพอร์ต
- อย่าเปิด VPN ตัวอื่นบนเครื่องเดียวกันพร้อมกัน (ไคลเอนต์ Cisco ของบริษัท โปรแกรม mesh network ตัวอื่น) มันจะแย่ง DNS และเส้นทางกัน

## คำถามที่พบบ่อย

**แต่ละเครื่องเลือกภูมิภาคขาออกต่างกันได้ไหม?** ได้ แต่ละเครื่องเลือกขาออกของตัวเอง โน้ตบุ๊กใช้ญี่ปุ่นดูวิดีโอ มือถือใช้ภูมิภาคจีนเข้าธนาคารออนไลน์ ไม่กระทบกัน

**เปิดเครือข่ายส่วนตัวไว้ตลอดจะเปลืองแบตไหม?** ถ้าไม่ได้เลือกขาออก แทบไม่มีทราฟฟิกเลย จะใช้ก็ต่อเมื่อคุยกับอุปกรณ์ในเครือข่ายส่วนตัว เปลืองแบตพอๆ กับ VPN ของระบบ

**ติดตั้งบน NAS ที่บ้านอย่างไร?** Synology และ QNAP มีแพ็กเกจ Tailscale ส่วนระบบ Linux ใช้สคริปต์ติดตั้งทางการ ตอนล็อกอินให้ชี้ไปที่เซิร์ฟเวอร์ควบคุมของเว็บไซต์นี้แบบเดียวกัน เราเตอร์ที่ใช้เฟิร์มแวร์ของเว็บไซต์นี้ไม่ต้องติดตั้ง แค่ล็อกอินบัญชีก็อยู่ในเครือข่ายส่วนตัวแล้ว

**ทำไมไม่ตั้ง Cisco ทุกเครื่องไปเลย?** ทำได้ แต่ Cisco ต้องกดเชื่อมต่อทุกครั้ง หลุดแล้วต้องต่อใหม่ จะเปลี่ยนขาออกก็ต้องเปลี่ยนที่อยู่ ถ้ามีหลายเครื่อง เครือข่ายส่วนตัวสบายกว่ามาก ยกเว้นเครื่องที่อยู่ในเครือข่ายมหาวิทยาลัยซึ่งจำกัด UDP เครื่องนั้นให้ใช้ Cisco
