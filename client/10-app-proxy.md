# 10 · Dropbox และโปรแกรมอื่นขอพร็อกซี HTTP / SOCKS ทำอย่างไร

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/app-proxy?utm_source=github&utm_content=client-10

**ก่อนอื่น สถานการณ์เป็นแบบนี้: พร็อกซีต้องเข้ารหัส** พร็อกซีที่ไม่เข้ารหัส (HTTP ธรรมดา, SOCKS4, SOCKS5) จะถูกตรวจจับและรบกวนบนเครือข่ายในจีน ใช้ไปสักพักก็ช้าลงหรือหลุด แถมบัญชีกับรหัสผ่านก็วิ่งไปแบบข้อความธรรมดาให้ใครก็อ่านได้ มีแค่การเชื่อมต่อที่เข้ารหัสเท่านั้นที่ใช้ได้ยาวๆ เว็บพร็อกซีของเว็บไซต์นี้จึงเข้ารหัสทั้งหมด **สำหรับโปรแกรมที่รับแค่ HTTP / SOCKS5 ให้ Hiddify ดูแลทั้งเครื่องแทน** (ดูด้านล่าง)

โปรแกรมที่ทำงานแยกเองอย่าง Dropbox, Telegram Desktop, Steam, ไคลเอนต์คลาวด์ไดรฟ์ และเครื่องมือนักพัฒนา ไม่อ่านการตั้งค่าของเบราว์เซอร์ และช่องตั้งพร็อกซีของมันเองก็รับแค่ HTTP / SOCKS5 ที่ไม่เข้ารหัส สองฝั่งไม่ตรงกัน ใส่พร็อกซีไปก็เชื่อมต่อไม่ได้ ทางแก้คือ**ไม่ต้องใส่พร็อกซี**: ใช้ Hiddify ส่งทั้งคอมพิวเตอร์ผ่านเส้นทาง แล้วตั้งพร็อกซีในโปรแกรมเป็น "ไม่ใช้พร็อกซี"

## ทำไมใส่พร็อกซีแล้วยังเชื่อมต่อไม่ได้

| สาเหตุ | คำอธิบาย |
|---|---|
| ประเภทไม่ตรงกัน | โปรแกรมมีให้เลือกแค่ HTTP, SOCKS4 และ SOCKS5 ซึ่งไม่เข้ารหัสสักตัว แต่พร็อกซีของเว็บไซต์นี้ต้องเข้ารหัส จึงใส่ไม่ได้ |
| ใช้พร็อกซีไม่เข้ารหัสที่หาจากเน็ต | ต่อได้พักหนึ่ง แล้วก็ถูกรบกวน ใช้ได้บ้างไม่ได้บ้าง |
| ครอบคลุมแค่บางส่วนของทราฟฟิก | หลายโปรแกรมใช้พร็อกซีแค่ตอนล็อกอินและซิงก์ ส่วนการอัปเดต การโทร และการซิงก์ใน LAN ยังต่อตรง และพร็อกซี HTTP ไม่ส่งต่อทราฟฟิก UDP ของเกมและการโทรเลย |
| ต้องดูแลแยกทีละโปรแกรม | จะเปลี่ยนภูมิภาคหรือรหัสผ่านก็ต้องแก้ทีละโปรแกรม ลืมตัวไหนตัวนั้นก็ใช้ไม่ได้ |

## วิธีที่แนะนำ: ให้ Hiddify ดูแลทั้งเครื่อง

1. ติดตั้ง Hiddify ตาม [09 · ติดตั้ง Hiddify บนทุกแพลตฟอร์ม](09-hiddify-install-all-platforms.md) แล้วนำเข้าโปรไฟล์ตาม [02](02-singbox-subscription-links.md)
2. เชื่อมต่อในโหมด "VPN" (ค่าเริ่มต้น) บน Windows การเชื่อมต่อครั้งแรกต้องใช้สิทธิ์ผู้ดูแลระบบ
3. ตั้งพร็อกซีในโปรแกรมกลับเป็น "ไม่ใช้พร็อกซี": ใน Dropbox เลือก "No proxy" (ไม่ใช้พร็อกซี) หรือ "Auto-detect" (ตรวจหาอัตโนมัติ) ที่ "Preferences → Network → Proxies" ใน Telegram Desktop เลือก "Disable proxy" (ปิดพร็อกซี) ที่ "Settings → Advanced → Connection type" โปรแกรมอื่นที่มีตัวเลือกพร็อกซีก็ปิดเสีย
4. ตรวจสอบ: ไอคอน Dropbox ในถาดระบบขึ้น "Up to date" (เป็นปัจจุบัน) และเริ่มซิงก์ เปิดเว็บที่แสดง IP ในเบราว์เซอร์ ขาออกอยู่ในภูมิภาคที่คุณเลือก

เมื่อเปิด "แยกเส้นทางอัตโนมัติ" ไว้ บริการต่างประเทศอย่าง Dropbox จะผ่านเส้นทาง ส่วน WeChat ธนาคารออนไลน์ และเว็บจีนยังต่อตรงตามปกติ

## โปรแกรมที่ใช้กันบ่อย

| โปรแกรม | ตั้งอย่างไร |
|---|---|
| Dropbox | พร็อกซีเป็น "No proxy" หรือ "Auto-detect" ถ้าค้างไว้ที่ "Manual" กับที่อยู่อื่น พอปิด Hiddify มันจะออฟไลน์ไปเลย |
| Telegram Desktop | Connection type เป็น "Disable proxy" การซ้อน MTProto / SOCKS5 ในตัวบนอุโมงค์อีกชั้นมีแต่จะช้าลง |
| OneDrive, Google Drive, iCloud เดสก์ท็อป | ใช้เครือข่ายของระบบ ไม่ต้องตั้งอะไร |
| Steam, Epic, Battle.net | ไม่ต้องใช้พร็อกซี ถ้าดาวน์โหลดช้า ให้เปลี่ยนไปภูมิภาคที่ใกล้กว่า |
| Zoom, Teams, Slack, Discord | เสียงและวิดีโอเป็น UDP ซึ่งมีแค่วิธีแบบทั้งเครื่องที่ส่งได้ |
| VS Code, JetBrains, Cursor | ใช้เครือข่ายของระบบ ถ้าตั้งพร็อกซีแยกไว้ในตัวโปรแกรม ให้ลบออก |

## เมื่อติดตั้งไคลเอนต์ไม่ได้ (คอมพิวเตอร์ที่ทำงาน)

- ใช้ Dropbox และคลาวด์ไดรฟ์ผ่านเว็บ: เปิด dropbox.com ในเบราว์เซอร์ที่ใช้[เว็บพร็อกซี](03-web-proxy-extension.md) อัปโหลดดาวน์โหลดได้ แต่ไม่มีการซิงก์อัตโนมัติ
- เครื่องมือบรรทัดคำสั่ง (git, pip, npm, curl) รับพร็อกซีแบบเข้ารหัสได้: ใส่ที่อยู่เว็บพร็อกซีใน `https_proxy` ดู[เข้าบริการต่างประเทศจากในจีน 05 · Linux และบรรทัดคำสั่ง](https://github.com/vipinus/guides-zh-CN/blob/main/overseas-access/05-linux-server.md) (ภาษาจีน ฉบับภาษาไทยอยู่ในคลังนี้ที่ overseas-access/05-linux-server.md)
- โปรแกรมเดสก์ท็อปอื่นที่รับแค่ HTTP / SOCKS5 ควรใช้บนคอมพิวเตอร์หรือมือถือของตัวเอง อย่าลง VPN แบบทั้งเครื่องบนคอมพิวเตอร์บริษัทเพื่อเรื่องนี้ เพราะจะไปกระตุ้นระบบแจ้งเตือนความปลอดภัยของบริษัท

## คำถามที่พบบ่อย

**ขอที่อยู่พร็อกซี SOCKS5 หรือ HTTP ได้ไหม?** พร็อกซีของเว็บไซต์นี้เข้ารหัสทั้งหมด แบบไม่เข้ารหัสใช้ไปไม่นานก็เริ่มติดๆ ดับๆ ให้ Hiddify ดูแลทั้งเครื่องเสถียรกว่า และครอบคลุมทุกโปรแกรมในคราวเดียว

**เปิด Hiddify แล้ว ยังต้องใส่พร็อกซีในโปรแกรมอีกไหม?** ไม่ต้อง ใส่ไปก็เท่ากับอ้อมสองรอบ อย่างดีก็ช้าลง อย่างแย่ก็เชื่อมต่อไม่ได้

**แล้ว Dropbox บนมือถือล่ะ?** แอปบนมือถือไม่มีช่องตั้งพร็อกซี ให้ติดตั้ง Hiddify หรือใช้ Cisco (AnyConnect) เชื่อมต่อแล้วทุกแอปจะผ่านเส้นทาง

**ไม่ใช้ Hiddify ได้ไหม?** ได้ Cisco, เครือข่ายส่วนตัว (Tailscale) และ OpenVPN ก็ดูแลทั้งเครื่องเหมือนกัน และตั้งโปรแกรมเป็น "ไม่ใช้พร็อกซี" เช่นกัน ข้อดีของ Hiddify คือมีการแยกเส้นทางในตัว และเร็วกว่าบนเครือข่ายที่แพ็กเก็ตหายเยอะ
