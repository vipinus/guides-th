# 01 · Cisco AnyConnect: ติดตั้ง เชื่อมต่อ และอัปเดตบนทุกแพลตฟอร์ม

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/anyconnect-china?utm_source=github&utm_content=client-01

AnyConnect คือไคลเอนต์ VPN สำหรับองค์กรของ Cisco ตอนนี้ชื่อทางการคือ **Cisco Secure Client** แต่ใช้งานเหมือนเดิม ไม่ต้องมีไฟล์ใบรับรองหรือนำเข้าโปรไฟล์: ใส่ที่อยู่ บัญชี และรหัสผ่าน ก็เชื่อมต่อได้ ส่วนเรื่องใช้ในจีนได้ไหม และถ้าเชื่อมต่อไม่ได้ควรเปลี่ยนไปใช้อะไร ดู[เข้าบริการต่างประเทศจากในจีน คู่มือ 02](https://github.com/vipinus/guides-zh-CN/blob/main/overseas-access/02-anyconnect-in-china.md) (ภาษาจีน)

## การติดตั้ง

| แพลตฟอร์ม | ติดตั้งอะไร | หาได้ที่ |
|---|---|---|
| Windows 10 ขึ้นไป | Cisco Secure Client 5.x | [หน้า Cisco บนเว็บไซต์](https://www.leotun.com/th/anyconnect?utm_source=github&utm_content=client-01) |
| Windows 7 / 8 | AnyConnect 4.9 (เวอร์ชันสุดท้ายที่รองรับ ไม่มีอัปเดตแล้ว) | ที่เดียวกับด้านบน |
| macOS | Cisco Secure Client 5.x | ที่เดียวกับด้านบน |
| iOS | Cisco Secure Client | App Store ถ้าสโตร์ไม่มี ให้ติดตั้ง OpenConnect แบบโอเพนซอร์สซึ่งใช้โปรโตคอลเดียวกัน |
| Android | Cisco Secure Client | Google Play หรือไฟล์ APK ในหน้าเว็บไซต์ |
| Linux | ตัวติดตั้งในหน้าเว็บไซต์ หรือ openconnect จากคลังแพ็กเกจของดิสโทรคุณ | ที่เดียวกับด้านบน |

บน Windows ยังมี OpenConnect-GUI แบบโอเพนซอร์ส ใช้บัญชีเดียวกันได้

## เชื่อมต่อในสี่ขั้นตอน

1. เปิดไคลเอนต์แล้วใส่ที่อยู่เซิร์ฟเวอร์ในช่องที่อยู่ ผู้ใช้ LeoTun **คลิกธงของภูมิภาค**บนเว็บไซต์เพื่อคัดลอกที่อยู่ของภูมิภาคนั้นได้
2. ใส่บัญชี (อีเมลที่ใช้สมัคร) และรหัสผ่าน
3. เมื่อเห็น "Connected" (เชื่อมต่อแล้ว) ให้เปิดเว็บที่แสดง IP เพื่อยืนยันว่าขาออกอยู่ในภูมิภาคที่คุณเลือก
4. ถ้าจะเปลี่ยนภูมิภาค ให้ใช้ที่อยู่อื่น ไคลเอนต์จำที่อยู่ที่เคยใช้ไว้ ครั้งหน้าเลือกจากรายการแบบเลื่อนลงได้เลย

## การอัปเดต

ไม่ต้องถอนการติดตั้งก่อน: ติดตั้งเวอร์ชันใหม่ทับเวอร์ชันเดิมได้เลย ที่อยู่ที่บันทึกไว้ยังอยู่ครบ บนมือถืออัปเดตจากร้านแอป หลังอัปเกรดระบบปฏิบัติการครั้งใหญ่ ให้อัปเดตไคลเอนต์ก่อน แล้วค่อยไล่หาปัญหาการเชื่อมต่อ

## ข้อความที่พบบ่อย

| ข้อความ | ความหมาย |
|---|---|
| Login failed | บัญชีหรือรหัสผ่านผิด หรือบัญชีหมดอายุ |
| Untrusted server certificate | ส่วนใหญ่เป็นเพราะนาฬิกาของระบบไม่ตรง หรือเครือข่ายที่ใช้อยู่ดักการเชื่อมต่อที่เข้ารหัส ลองเครือข่ายอื่น |
| Connection attempt has failed | ที่อยู่นี้เข้าไม่ได้ชั่วคราว ให้เปลี่ยนภูมิภาค |
