# 03 · เว็บพร็อกซี: ตั้งค่าส่วนขยาย ZeroOmega ในสองขั้นตอน

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/web-proxy?utm_source=github&utm_content=client-03

เว็บพร็อกซีให้แค่**เบราว์เซอร์ตัวนี้**วิ่งผ่านเส้นทาง โปรแกรมอื่นในระบบไม่ถูกแตะต้อง ไม่ต้องติดตั้งไคลเอนต์ ไม่ต้องใช้สิทธิ์แอดมิน และไม่มีสถานะ "เชื่อมต่ออยู่" จึงไม่มีอะไรให้หลุดตั้งแต่ต้น เหมาะกับคอมพิวเตอร์ของบริษัท เครื่องที่ต่อ VPN ของบริษัทอยู่แล้ว หรือเมื่ออยากให้แค่เบราว์เซอร์ตัวเดียวใช้เส้นทาง เมื่อไรควรใช้แบบนี้และเมื่อไรต้องใช้ VPN ดู[คู่มือเครือข่าย 02](../network/02-choose-your-connection-method.md)

## สองขั้นตอน

1. **ติดตั้งส่วนขยาย**: ติดตั้ง ZeroOmega (ตัวต่อยอดของ SwitchyOmega) ใน Chrome / Edge / Firefox [หน้าพร็อกซี (Web Proxy) บนเว็บไซต์](https://www.leotun.com/th/httpproxy?utm_source=github&utm_content=client-03) มีลิงก์ติดตั้งสำหรับแต่ละเบราว์เซอร์
2. **นำเข้า**: ล็อกอินเว็บไซต์ ในหน้าพร็อกซีคลิกธงของภูมิภาคที่ต้องการ (หรือคลิก "คัดลอกลิงก์นำเข้าทุกภูมิภาค" เพื่อนำเข้าทั้งหมดในครั้งเดียว) ลิงก์การตั้งค่าจะถูกคัดลอกไว้ เปิด "Import/Export" (นำเข้า/ส่งออก) ของส่วนขยาย วางลิงก์ในช่อง "Restore from online" (กู้คืนจากออนไลน์) แล้วคลิก "Restore" (กู้คืน) ภูมิภาค ที่อยู่ และวิธีเข้ารหัสจะเข้ามาครบในครั้งเดียว ไม่ต้องพิมพ์เอง

จากนั้นคลิกไอคอนส่วนขยาย เลือกภูมิภาค แล้วใส่บัญชีและรหัสผ่านของเว็บไซต์ในกล่องล็อกอินที่เบราว์เซอร์แสดง จะเปลี่ยนภูมิภาคก็คลิกภูมิภาคอื่นในเมนูของไอคอน จะกลับไปต่อตรงก็เลือก "Direct" (ต่อตรง)

## กรณีเหล่านี้ ให้ใช้วิธีที่ครอบทั้งเครื่อง

- แอปวิดีโอ แอปเพลง และโปรแกรมเล่นสื่อ: ส่วนใหญ่ไม่ใช้พร็อกซีของเบราว์เซอร์ จึงเจออาการ "เว็บเปิดได้ แต่วิดีโอเล่นไม่ได้"
- แอปบนมือถือ เกม และโปรแกรมบนเดสก์ท็อป ช่องตั้งพร็อกซีในโปรแกรมอย่าง Dropbox รับแค่ HTTP / SOCKS5 แบบไม่เข้ารหัส แต่ในการใช้งานจริงพร็อกซีต้องเข้ารหัส จึงใส่เว็บพร็อกซีของเว็บไซต์นี้ตรงนั้นไม่ได้ ให้ใช้ Hiddify คุมทั้งเครื่องแทน ดู[10](10-app-proxy.md)
- ดู Tencent Video หรือ iQIYI จากต่างประเทศ: เว็บวิดีโอเช็ก IPv6 และ DNS ด้วย ซึ่งเว็บพร็อกซีไม่ได้ครอบคลุม ให้ใช้ VPN แบบทั้งเครื่อง

## คำถามที่พบบ่อย

| อาการ | สาเหตุ |
|---|---|
| กล่องล็อกอินเด้งขึ้นมาไม่หยุด | บัญชีหมดอายุ หรือรหัสผ่านผิด |
| บางเว็บเปิดไม่ได้ แต่เว็บอื่นปกติ | กฎ "auto switch" (สลับอัตโนมัติ) ในส่วนขยายส่งเว็บนั้นไปต่อตรง ลองสลับเป็นโหมดพร็อกซีทั้งหมดดูสักครั้ง |
| ในจีน เปิดได้แค่เว็บ HTTPS | HTTP ธรรมดาจะถูกแก้ไขระหว่างทาง มีแต่การเชื่อมต่อที่เข้ารหัสที่ผ่านไปได้ ทุกวันนี้เว็บแทบทั้งหมดเป็น HTTPS แล้ว |
| ช้า | เปลี่ยนภูมิภาค พร็อกซีกับ VPN ใช้เซิร์ฟเวอร์ชุดเดียวกัน |
