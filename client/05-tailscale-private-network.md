# 05 · เครือข่ายส่วนตัว (Tailscale): ติดตั้ง ล็อกอินเข้าเซิร์ฟเวอร์ควบคุมของเว็บไซต์นี้ และเลือกทางออก

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/tailscale-mesh?utm_source=github&utm_content=client-05

หมวดส่วนตัว (เครือข่ายส่วนตัว) ใช้ Tailscale (เครื่องมือสร้างเครือข่ายที่ทำงานบน WireGuard) LeoTun มีเซิร์ฟเวอร์ควบคุมของตัวเอง คุณล็อกอินด้วย**บัญชีของเว็บไซต์นี้** ไม่เกี่ยวกับบัญชี Tailscale ทางการ ล็อกอินครั้งเดียวก็ออนไลน์ค้างไว้ ส่วนภูมิภาคขาออกเปลี่ยนจากเมนูได้ตลอด ต่างจาก VPN อย่างไรและเหมาะกับใคร ดู[คู่มือเครือข่าย 03](../network/03-private-network-vs-vpn.md)

## ติดตั้ง

| แพลตฟอร์ม | ดาวน์โหลดจากที่ไหน |
|---|---|
| Windows / macOS / Linux / Android | ส่วนดาวน์โหลดใน[หน้าส่วนตัว (เครือข่ายส่วนตัว) ของเว็บไซต์](https://www.leotun.com/th/mesh?utm_source=github&utm_content=client-05) (ดาวน์โหลดจากเว็บไซต์นี้โดยตรง ไม่ต้องไปเว็บทางการ) |
| iPhone / iPad | App Store ต้องใช้ Apple ID ที่ไม่ใช่ภูมิภาคจีน (ดู[ไคลเอนต์ 06](06-ios-app-store.md)) |

## ล็อกอิน

1. **ออกจากบัญชีทางการก่อน** (ถ้าเคยล็อกอินไว้): มือถือ แตะรูปโปรไฟล์ → Log Out (ออกจากระบบ) คอมพิวเตอร์ รัน `tailscale logout` ถ้ายังออกจากระบบไม่หมด ตัวเลือกที่ต้องใช้ในขั้นถัดไปจะไม่โผล่มา
2. **ชี้การล็อกอินมาที่เว็บไซต์นี้**:
   - มือถือ: ในหน้าจอที่ออกจากระบบแล้ว แตะ "⋯" มุมขวาบน → Use custom server (ใช้เซิร์ฟเวอร์ที่กำหนดเอง บางเวอร์ชันชื่อ Use an alternate server) ใส่ที่อยู่ที่แสดงในหน้าส่วนตัว (เครือข่ายส่วนตัว) ของเว็บไซต์ แล้วแตะ Log in
   - Windows / Linux: คัดลอกคำสั่ง `tailscale up --login-server=…` จากหน้าเว็บ แล้วรันใน PowerShell / เทอร์มินัล
   - macOS: **อย่ากด Log in** ในหน้าต่าง Tailscale คลิกลูกศรที่แถวบัญชี → Account Settings… → Accounts → ลูกศรเล็กข้าง "Add Account…" → Add Account Using Alternate Server (เพิ่มบัญชีด้วยเซิร์ฟเวอร์อื่น) วางที่อยู่แล้วคลิก Add Account…
3. เบราว์เซอร์จะเปิดหน้าล็อกอินของเว็บไซต์นี้ให้เอง ยืนยันด้วยบัญชีของเว็บไซต์นี้ กลับมาที่ไคลเอนต์ก็ออนไลน์แล้ว

## เลือกทางออก

- มือถือ: เมนู → Exit Node (โหนดทางออก) เลือกภูมิภาค มีผลทันที
- คอมพิวเตอร์: ไอคอนที่ถาดระบบ / แถบเมนู → เมนูย่อย Exit Node หรือใช้ `tailscale set --exit-node=<region-name>` (`tailscale exit-node list` ดูว่ามีอะไรให้เลือก)
- ถ้าไม่ใช้ทางออก ให้เลือก None (ไม่มี) (บนบรรทัดคำสั่ง เว้นค่าหลังเครื่องหมายเท่ากับไว้ว่างๆ) ใช้ทางออกได้ทีละหนึ่งเท่านั้น

## หมดอายุและจำนวนอุปกรณ์

- อายุการล็อกอินของแต่ละเครื่องเป็นไปตามวันหมดอายุของบัญชี หมดอายุแล้วเครื่องจะออฟไลน์ภายในไม่กี่นาที ต่ออายุแล้วแค่ล็อกอินอีกครั้ง ไม่ต้องติดตั้งใหม่
- จำนวนอุปกรณ์ที่ออนไลน์พร้อมกันขึ้นกับแพ็กเกจ (ส่วนตัว 2 ครอบครัว 4 องค์กร 8) และใช้โควตาร่วมกับวิธีเชื่อมต่ออื่น ถ้าเกินโควตาของแพ็กเกจ ก็อัปเกรดประเภทบัญชีชั่วคราวได้ (เวลาที่เหลือแปลงตามมูลค่าราคาเท่ากัน) ใช้เสร็จค่อยเปลี่ยนกลับ

## สองกรณีที่ควรใช้วิธีอื่น

- มี VPN ตัวอื่นเปิดอยู่บนเครื่องเดียวกัน (AnyConnect ของบริษัท โปรแกรม mesh network ตัวอื่น): มันจะแย่ง DNS และเส้นทางกัน นี่คือต้นเหตุที่ดูวิดีโอจีนแล้วขึ้นแจ้งเรื่องลิขสิทธิ์ และอินทราเน็ตของบริษัทเปิดไม่ได้
- อยู่ในเครือข่ายมหาวิทยาลัย / บริษัทที่จำกัด UDP: WireGuard วิ่งบน UDP จึงต้องไปผ่าน relay ของ Tailscale ซึ่งช้ามาก ให้เปลี่ยนไปใช้ AnyConnect
