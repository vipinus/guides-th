# 08 · ยืนยันอย่างไรว่าเชื่อมต่อจริง และออกจากภูมิภาคไหน

ไคลเอนต์ขึ้นว่า "Connected" (เชื่อมต่อแล้ว) ไม่ได้แปลว่าเว็บที่คุณเข้าจะเห็นที่อยู่ของ VPN วิธีเช็กที่ง่ายที่สุดอยู่ที่แถบด้านบนของเว็บไซต์นี้: ช่อง "เครือข่ายปัจจุบัน" แสดง**ตัวคุณในสายตาของเว็บไซต์นี้ ณ ตอนนี้** ว่าออกมาจากประเทศไหน มณฑล/รัฐไหน และเครือข่ายไหน บทความนี้อธิบายวิธีอ่านช่องนี้ วิธีเทียบก่อนและหลังเชื่อมต่อ วิธีดูว่าหกวิธีเชื่อมต่อแต่ละแบบเชื่อมต่อแล้วหรือยัง ไฟแดง เหลือง เขียวในรายการภูมิภาคหมายถึงอะไร และสิ่งที่เช็กเองได้เมื่อ "เชื่อมต่อแล้วแต่ยังขึ้นเป็นที่อยู่ท้องถิ่น"

## ช่อง "เครือข่ายปัจจุบัน" ที่แถบด้านบนแสดงอะไร

| ตำแหน่ง | เนื้อหา |
|---|---|
| ด้านหน้า | ธงของประเทศที่เป็นทางออก ถ้าระบุประเทศไม่ได้จะแสดงไอคอน Wi‑Fi แทน |
| ตรงกลาง | ชื่อมณฑล/รัฐ แสดงตามภาษาของหน้าเว็บ (สหรัฐฯ แคนาดา ออสเตรเลีย ฯลฯ ใช้ตัวย่อที่ใช้กันทั่วไป เช่น CA, ON, NSW) ฮ่องกง มาเก๊า และสิงคโปร์แสดงชื่อเขตโดยตรง |
| ด้านท้าย | ชื่อเครือข่าย: ค่ายใหญ่สามค่ายของจีน เครือข่ายการศึกษา ฯลฯ ในหน้าเว็บภาษาจีนจะแสดงเป็นชื่อย่อ เช่น 电信 (China Telecom), 移动 (China Mobile), 联通 (China Unicom) และ 教育网 (เครือข่ายการศึกษา) ที่เหลือแสดงชื่อแบรนด์ภาษาอังกฤษ (เช่น Comcast, Bell) |

- **ถ้าหามณฑล/รัฐไม่เจอ จะแสดงแค่ "ธง · ชื่อเครือข่าย"** ไม่เอาชื่อประเทศมาเติมแทน ธงก็บอกประเทศอยู่แล้ว
- บนคอมพิวเตอร์ เอาเมาส์ไปวางบนช่องนี้ จะเด้งชื่อองค์กรเต็ม มณฑล/รัฐ รหัสประเทศ และ **IP ขาออก** ขึ้นมา IP นี้แสดงให้คุณคนเดียวเห็น และเป็นข้อมูลที่มีประโยชน์ที่สุดเวลาติดต่อซัพพอร์ต
- Chrome / Edge บน Windows ไม่มีฟอนต์ธง ธงจึงแสดงเป็นตัวอักษรสองตัว (เช่น JP, US) ความหมายเหมือนกัน
- บนคอมพิวเตอร์ ช่องนี้จะขึ้นที่แถบด้านบนหลังล็อกอินเท่านั้น บนมือถือแสดงโดยไม่ต้องล็อกอิน

## เทียบก่อนและหลังเชื่อมต่อ ดูแวบเดียวก็รู้

1. **ตอนปิด VPN** เปิดเว็บไซต์นี้ดู: ควรเป็นค่ายเน็ตบ้านหรือเน็ตมือถือของคุณ และธงเป็นประเทศที่คุณอยู่
2. **เชื่อมต่อ VPN** แล้วกลับมาที่เบราว์เซอร์: ธงเปลี่ยนเป็นภูมิภาคที่คุณเลือก และชื่อเครือข่ายมักเปลี่ยนเป็นชื่อดาต้าเซ็นเตอร์หรือผู้ให้บริการคลาวด์ แทนค่ายเน็ตที่บ้าน
3. ถ้าก่อนและหลังเหมือนกัน แปลว่าเบราว์เซอร์นี้ไม่ได้ผ่าน VPN ตอนเข้าเว็บไซต์นี้ ดู "เชื่อมต่อแล้ว แต่ยังขึ้นเป็นที่อยู่ท้องถิ่น" ด้านล่าง

**ไม่ต้องรีเฟรชหน้าเว็บรัวๆ** ช่องนี้จะเช็กใหม่เองเมื่อคุณสลับกลับมาที่หน้าต่างเบราว์เซอร์ เช็กเพิ่มอีกสองสามครั้งภายในไม่กี่วินาทีหลังตรวจพบว่าเครือข่ายเปลี่ยน และอัปเดตทุกสิบถึงยี่สิบวินาทีขณะเปิดหน้าไว้ ถ้าเชื่อมต่อแล้วยังเห็นค่าเดิม ให้รอสิบถึงยี่สิบวินาทีหรือสลับหน้าต่าง ถ้ายังไม่เปลี่ยน ค่อยรีเฟรชเอง

**ถ้าคุณอยู่ในจีนและเลือก "ทางเข้าในจีน"** แถบด้านบนแสดงเป็นต่างประเทศถือเป็นเรื่องปกติ: ทางเข้าในจีนใช้การแยกเส้นทาง เว็บจีนออกจากในจีน ส่วนเว็บต่างประเทศออกทางฝั่งต่างประเทศ เว็บไซต์นี้อยู่ต่างประเทศ สิ่งที่แสดงจึงเป็นปลายทางฝั่งต่างประเทศ

## ดูอย่างไรว่าแต่ละวิธีเชื่อมต่อแล้ว

| วิธี | ดูอะไรในไคลเอนต์ | แถบด้านบนของเว็บไซต์นี้เปลี่ยนไหม |
|---|---|---|
| Cisco (AnyConnect) | ไคลเอนต์ขึ้นว่า "Connected" | เปลี่ยน พอ Cisco เชื่อมต่อแล้ว ทราฟฟิกทั้งหมดผ่าน VPN |
| Hiddify | ไคลเอนต์แสดงว่าเชื่อมต่อแล้ว | โหมด global (ทั้งหมด) เปลี่ยน ถ้าเป็นการแยกเส้นทางอัตโนมัติ ขึ้นกับรายการ |
| OpenVPN | ไคลเอนต์แสดงว่าเชื่อมต่อแล้ว | เปลี่ยน โดยค่าเริ่มต้นทราฟฟิกทั้งหมดผ่าน VPN |
| ส่วนตัว (เครือข่ายส่วนตัว Tailscale) | ไคลเอนต์ออนไลน์ **และ**เลือกภูมิภาคเป็น Exit Node (โหนดทางออก) แล้ว | เปลี่ยนเฉพาะเมื่อเลือกทางออก ถ้าเลือก None (ไม่มี) อุปกรณ์จะเข้าถึงกันได้อย่างเดียว ทราฟฟิกไม่ผ่าน VPN |
| พร็อกซี (Web Proxy) | ไม่มีสถานะ "เชื่อมต่อแล้ว" ดูว่าไอคอนส่วนขยายเลือกโหมดภูมิภาคไหนอยู่ | เปลี่ยนแค่เบราว์เซอร์ที่ติดตั้งส่วนขยาย กฎ "auto switch" (สลับอัตโนมัติ) อาจทำให้เว็บไซต์นี้ต่อตรง |
| เราเตอร์ | ในหน้าแอดมิน สถานะบัญชีปกติและแสดงวันหมดอายุ | ดูจากอุปกรณ์ที่ต่อ Wi‑Fi ของเราเตอร์นี้ ในโหมดแยกเส้นทาง ขึ้นกับรายการ |

การแยกเส้นทางหมายความว่าเว็บที่อยู่ในรายการผ่าน VPN ที่เหลือต่อตรง ถ้าเปิดการแยกเส้นทางอยู่แล้วแถบด้านบนแสดงเป็นที่อยู่ท้องถิ่น ไม่ได้แปลว่ายังไม่เชื่อมต่อเสมอไป: **สลับเป็น "global" ชั่วคราวแล้วดูอีกครั้ง** ถ้าเปลี่ยน แปลว่า VPN ทำงานอยู่ แค่เว็บไซต์นี้ไม่อยู่ในรายการ

## ไฟแดง เหลือง เขียวในรายการภูมิภาค

ในหน้า Cisco, Hiddify, พร็อกซี และ OpenVPN มีไฟดวงเล็กใต้ธงของแต่ละภูมิภาค และในไคลเอนต์ของเครือข่ายส่วนตัวก็มีไฟแบบเดียวกันอยู่หน้าชื่อทางออก ระดับไฟคำนวณอัตโนมัติจากแบนด์วิดท์เฉลี่ยแบบเรียลไทม์ของทุกเซิร์ฟเวอร์ในภูมิภาคนั้น และอัปเดตประมาณนาทีละครั้ง:

| ไฟ | ความหมาย |
|---|---|
| เขียว (ติดค้าง) | ว่าง |
| เหลือง (กะพริบ) | มีคนใช้อยู่ |
| แดง (กะพริบ) | ยุ่ง |
| ไม่มีไฟ | ตอนนั้นยังไม่ได้ข้อมูล ไม่ได้แปลว่าเซิร์ฟเวอร์ล่ม |

บนคอมพิวเตอร์ เอาเมาส์ไปวางบนไฟเพื่อดูภาระเฉลี่ยของภูมิภาคนั้น

**เห็นไฟแดงแล้วทำอย่างไร:**

- ไฟแดงไม่ได้แปลว่าเสีย แค่บอกว่าตอนนั้นคนเยอะ ถ้าเชื่อมต่ออยู่แล้วและความเร็วพอใช้ ก็ปล่อยไว้
- ถ้ารู้สึกช้า ให้เปลี่ยนไปภูมิภาคไฟเขียว Cisco: คลิกธงอื่นบนหน้าเว็บเพื่อคัดลอกที่อยู่ใหม่ Hiddify: นำเข้าการตั้งค่าของภูมิภาคอื่น เครือข่ายส่วนตัว: เปลี่ยนใน Exit Node พร็อกซี: คลิกภูมิภาคอื่นในไอคอนส่วนขยาย
- หนึ่งภูมิภาคมีหลายเครื่องอยู่เบื้องหลัง ตอนเชื่อมต่อระบบจะเลือกเครื่องที่ว่างที่สุดให้เอง ไม่ต้องเลือกเครื่องเอง
- สองทุ่มถึงห้าทุ่มคือช่วงพีค ช่วงนี้ให้เลือกภูมิภาคไฟเขียวหรือเปลี่ยนวิธีเชื่อมต่อ ถ้ายังช้า ส่วนใหญ่เป็นที่เน็ตบ้านเอง (เน็ตแบบแชร์ทั้งหมู่บ้านหรือคอนโด หรือค่ายเน็ตกับภูมิภาคไม่เข้ากัน) วิธีเลือกภูมิภาคตามค่ายเน็ต ดูในอ่านเพิ่มเติม

## เชื่อมต่อแล้ว แต่ยังขึ้นเป็นที่อยู่ท้องถิ่น

เรียงตามที่พบบ่อย:

1. **กฎการแยกเส้นทางทำให้เว็บไซต์นี้ต่อตรง** การแยกเส้นทางอัตโนมัติของ Hiddify "auto switch" ของส่วนขยายพร็อกซี และโหมดแยกเส้นทางของเราเตอร์ ล้วนทำให้เว็บไซต์นี้ไม่ผ่าน VPN ได้ สลับเป็น global ชั่วคราวเพื่อเช็ก ผู้ใช้พร็อกซีจะเพิ่มเว็บไซต์นี้ลงในกฎก็ได้
2. **เว็บพร็อกซีครอบคลุมแค่เบราว์เซอร์ตัวนั้น** ดูจากเบราว์เซอร์อื่นหรือแอปบนมือถือก็ต้องขึ้นเป็นที่อยู่ท้องถิ่นอยู่แล้ว
3. **ไม่ได้เลือกทางออกในเครือข่ายส่วนตัว** ออนไลน์ ≠ ผ่าน VPN ถ้า Exit Node เป็น None อุปกรณ์จะเข้าถึงกันได้อย่างเดียว
4. **ดูผิดเครื่อง** ถ้าใช้เราเตอร์ ต้องดูจากอุปกรณ์ที่ต่อ Wi‑Fi ของเราเตอร์ตัวนั้น ไม่ใช่มือถือที่ต่อ Wi‑Fi ของโมเด็มหรือใช้เน็ตมือถืออยู่
5. **เปิด VPN หรือโปรแกรม mesh network ตัวอื่นไว้พร้อมกัน** VPN ของบริษัทหรือตัวเร่งความเร็วของเจ้าอื่นจะแย่งเส้นทางกัน ให้เหลือไว้ตัวเดียว
6. **ยังไม่ได้รีเฟรช** รอสิบถึงยี่สิบวินาที สลับหน้าต่าง หรือรีเฟรชเองหนึ่งครั้ง

## แถบด้านบนเช็ก IP ส่วน IPv6 และ DNS ต้องเช็กแยก

แถบด้านบนดูที่อยู่ IPv4 ของการเชื่อมต่อที่เว็บไซต์นี้ได้รับ ถ้าแสดงถูก ก็แปลแค่ว่าเบราว์เซอร์นี้ผ่าน VPN ตอนเข้าเว็บไซต์นี้:

- **IPv6 และ DNS ดูจากตรงนี้ไม่ได้** เมื่อเบราว์เซอร์เข้าเว็บไซต์นี้ผ่าน IPv6 ช่องนี้จะไม่แสดงเลย มันจะไม่เอาเครือข่ายที่ผิดมาแสดงเหมือนเป็นของจริง ถ้าเว็บวิดีโอยังขึ้นแจ้งข้อจำกัดลิขสิทธิ์ ส่วนใหญ่เป็นเพราะ IPv6 หรือ DNS วิ่งอ้อม VPN ดู[03 · IPv6 และ DNS คือช่องที่หลุดออกไป](03-ipv6-and-dns-leak.md)
- **แอปจำผลการเช็กภูมิภาคไว้** แถบด้านบนค้นหาใหม่ทุกครั้ง ไม่ได้รับผลจากแคช แต่แอปวิดีโอและเพลงจะจำภูมิภาคครั้งก่อนไว้ ให้ปิดแอปให้สนิทแล้วเปิดใหม่ ดู[02 · เชื่อมต่อเข้าจีนแล้วแต่ยังดูไม่ได้](02-still-blocked-after-connecting.md)

## คำถามที่พบบ่อย

**ช่อง "เครือข่ายปัจจุบัน" ที่แถบด้านบนหายไป?** บนคอมพิวเตอร์ ให้ล็อกอินก่อน ถ้าล็อกอินแล้วยังไม่แสดง ส่วนใหญ่เป็นเพราะการเชื่อมต่อนี้ไปทาง IPv6 หรือค้นหาไม่ได้ชั่วคราว รอสิบถึงยี่สิบวินาทีหรือรีเฟรช มันยอมไม่แสดงอะไรเลย ดีกว่าแสดงผิด

**ภูมิภาคเดียวกัน แต่เชื่อมต่อสองครั้งได้ IP ไม่เหมือนกัน?** ปกติ หนึ่งภูมิภาคมีหลายเครื่องอยู่เบื้องหลัง แต่ละครั้งที่เชื่อมต่อจะเลือกเครื่องที่ว่างที่สุดในตอนนั้น การเชื่อมต่อที่ต่ออยู่แล้วจะไม่ถูกย้ายไปที่อื่นกลางทาง

**มณฑลที่แสดงไม่ตรงกับที่คิด?** แถบด้านบนแสดงมณฑล/รัฐที่ IP ขาออกตั้งอยู่ และแม่นยำได้แค่ระดับนั้น ถ้าธงตรง ก็แปลว่าทางออกอยู่ในประเทศหรือเขตที่คุณเลือก

**ติดต่อซัพพอร์ตต้องแจ้งอะไรบ้าง?** เอาเมาส์ไปวางบนช่องนั้นที่แถบด้านบน แล้วส่งสิ่งที่เด้งขึ้นมา (รวม IP ขาออก) พร้อมวิธีเชื่อมต่อ ภูมิภาคที่เลือก และเวลาที่เกิดปัญหา
