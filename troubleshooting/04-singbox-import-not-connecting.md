# 04 · นำเข้า Hiddify แล้วแต่เชื่อมต่อไม่ได้

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/singbox-subscription?utm_source=github&utm_content=troubleshooting-04

เทียบอาการของคุณกับตารางด้านล่าง ถ้ายังไม่รู้วิธีนำเข้าตั้งแต่ต้น ดู[วิธีนำเข้าลิงก์ซับสคริปชัน (Hiddify, Clash, Shadowrocket)](../client/02-singbox-subscription-links.md)

| อาการ | สาเหตุ | ทำอย่างไร |
|---|---|---|
| "Unable to fetch subscription" (ดึงซับสคริปชันไม่ได้), 401 | บัญชีหมดอายุ หรือเปลี่ยนรหัสผ่านไปแล้ว (เปลี่ยนรหัสผ่านแล้วการตั้งค่าเดิมใช้ไม่ได้ทันที ออกแบบไว้แบบนี้) | ล็อกอินเว็บไซต์แล้วดูวันหมดอายุ หลังต่ออายุหรือเปลี่ยนรหัสผ่าน ให้สแกน QR โค้ดใหม่ |
| นำเข้าสำเร็จ แต่เชื่อมต่อแล้วหมดเวลา | ที่อยู่ของภูมิภาคนั้นเพิ่งเปลี่ยน หรือจุดเข้านั้นกำลังถูกผู้ให้บริการเน็ตรบกวน | แตะ "Update subscription" (อัปเดตซับสคริปชัน) ในไคลเอนต์เพื่อดึงการตั้งค่าล่าสุด หรือเปลี่ยนภูมิภาค — แต่ละภูมิภาคเป็นการตั้งค่าแยกกัน ไม่กระทบกัน |
| เชื่อมต่อได้แต่ไม่มีเน็ต | กฎแยกเส้นทางของไคลเอนต์เองส่งทราฟฟิกไป "direct" (ต่อตรง) | เปลี่ยนขาออกเริ่มต้นเป็นโหนดนั้น หรือลบกฎที่คุณเพิ่มเอง |
| สแกนแล้วขึ้น "Invalid QR code" (QR โค้ดไม่ถูกต้อง) | ตอนหน้าต่างเพิ่งเปิด QR โค้ดเป็นแบบ Hiddify / sing-box ไคลเอนต์อื่นสแกนตรงๆ จะเจอข้อผิดพลาดนี้ หรือสแกนจากภาพหน้าจอของคนอื่น | คลิกปุ่มของไคลเอนต์คุณก่อน QR โค้ดจะเปลี่ยนเป็นแบบที่ตรงกัน แล้วค่อยสแกนหรือวาง: ไคลเอนต์ตระกูล Clash คลิก "ซับสคริปชัน Clash" ส่วน Shadowrocket / NekoBox / v2rayN ฯลฯ คลิก "ลิงก์แชร์" QR โค้ดมีข้อมูลล็อกอินของคุณเอง ของคนอื่นใช้ไม่ได้ |
| ความเร็วช้า | ภูมิภาคที่เลือกโหลดสูง หรือเน็ตบ้านกับภูมิภาคไม่เข้ากัน | ดูไฟแดง เหลือง เขียวในรายการภูมิภาคบนเว็บไซต์ แล้วเปลี่ยนไปภูมิภาคที่ไฟเขียว ถ้ายังช้า ให้เลือกภูมิภาคตามผู้ให้บริการเน็ตของคุณ |
| ไคลเอนต์ตระกูล Clash นำเข้าลิงก์แชร์ไม่ได้ | Clash Meta, Clash Verge, FlClash, Stash และตัวอื่นๆ นำเข้า hysteria2:// บรรทัดเดียวเป็นโปรไฟล์ไม่ได้ | คลิกปุ่ม "ซับสคริปชัน Clash" แล้ววาง URL ในรายการซับสคริปชันของไคลเอนต์ Clash ดั้งเดิมและ Clash for Windows ไม่มี hysteria2 ในแกน ให้ใช้ไคลเอนต์ที่ใช้แกน mihomo แทน |
| ลิงก์แชร์นำเข้าไม่ได้หรือเชื่อมต่อไม่ได้ | ลิงก์แชร์ใช้รูปแบบขยายที่ไคลเอนต์บางตัวอ่านไม่ออก | เปลี่ยนไปใช้ Hiddify |

## ต่ออายุ เปลี่ยนแพ็กเกจ หรือเปลี่ยนรหัสผ่านแล้ว ต้องนำเข้าใหม่ไหม

- **ต่ออายุหรือเปลี่ยนแพ็กเกจ (ส่วนตัว / ครอบครัว / องค์กร)**: ไม่ต้อง การตั้งค่าเดิมใช้ต่อได้
- **เปลี่ยนรหัสผ่าน**: การตั้งค่าเดิมใช้ไม่ได้ทันที ให้สแกน QR โค้ดใหม่ ถ้ามือถือหายหรือลิงก์หลุด ใช้วิธีนี้เพิกถอนสิทธิ์
- **บัญชีหมดอายุ**: การตั้งค่าจะได้ 401 ต่ออายุแล้วไม่ต้องใช้การตั้งค่าใหม่ แค่เชื่อมต่อใหม่
- **นำเข้าก่อนกันยายน 2026**: ไม่มีกฎปฏิเสธ IPv6 ดูวิดีโอจีนจากต่างประเทศจึงขึ้นแจ้งเรื่องลิขสิทธิ์ ให้ลบแล้วนำเข้าใหม่ ดู [03](03-ipv6-and-dns-leak.md)

## เมื่อไรควรติดต่อฝ่ายซัพพอร์ต

บอกฝ่ายซัพพอร์ตสามอย่าง: ชื่อและเวอร์ชันของไคลเอนต์ ภูมิภาค และข้อความผิดพลาดแบบตรงตัวหรือภาพหน้าจอ
