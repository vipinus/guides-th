# 09 · ให้ซัพพอร์ตดูคอมพิวเตอร์และเราเตอร์ของคุณจากระยะไกล

บางปัญหาส่งภาพหน้าจอกันไปมาในกลุ่มเป็นสิบรอบก็ยังอธิบายไม่ชัด แต่ถ้าซัพพอร์ตได้ดูหน้าจอตรงๆ สองนาทีก็เจอต้นเหตุ บทความนี้อธิบายว่าเมื่อไรควรขอความช่วยเหลือระยะไกล บนคอมพิวเตอร์ใช้โปรแกรมอะไร นำเข้าการตั้งค่าเซิร์ฟเวอร์ของเว็บไซต์นี้อย่างไร ส่งข้อมูลการเชื่อมต่อให้ซัพพอร์ตอย่างปลอดภัยอย่างไร ระหว่างเซสชันคุณควบคุมอะไรได้บ้าง เสร็จแล้วเอาสิทธิ์คืนอย่างไร และถ้าเป็นเราเตอร์ที่ใช้เฟิร์มแวร์ของเว็บไซต์นี้ คุณต้องทำอะไร

## เมื่อไรควรขอความช่วยเหลือระยะไกล

- คุณไล่ [01 · เช็กลิสต์เมื่อเชื่อมต่อไม่ได้ ช้า หรือหลุดบ่อย](01-cannot-connect-slow-drops.md) ครบหนึ่งรอบแล้ว และถามโดยบอกวิธีเชื่อมต่อ ภูมิภาค ข้อความแจ้งข้อผิดพลาดแบบคำต่อคำหรือภาพหน้าจอ และเวลาที่เกิดปัญหาแล้ว แต่ก็ยังแก้ไม่ได้
- คุณอธิบายขั้นตอนเองไม่ได้: การตั้งค่าซ่อนอยู่ลึก อ่านภาษาของระบบไม่ออก หรือข้อความแจ้งข้อผิดพลาดขึ้นแวบเดียวจับภาพไม่ทัน
- คุณช่วยคนในครอบครัวดูคอมพิวเตอร์ แต่ไม่ได้อยู่ข้างๆ และอธิบายทางโทรศัพท์ไม่เข้าใจ

กรณีต่อไปนี้**อย่าใช้ความช่วยเหลือระยะไกล** ให้คุยเป็นข้อความในกลุ่มแทน:

- คอมพิวเตอร์ที่บริษัทควบคุมจากส่วนกลาง นโยบายกลุ่มมักห้ามรันโปรแกรมแบบนี้ และอาจผิดกฎของบริษัท

## ใช้โปรแกรมอะไร: RustDesk

เว็บไซต์แนะนำ [RustDesk](https://rustdesk.com): เป็นโอเพนซอร์ส (AGPL-3.0) ใครก็ตรวจโค้ดได้ และจะเริ่มหรือจบเซสชันเมื่อไร คุณเป็นคนกดเองทั้งหมด รองรับ Windows, macOS, Linux, Android และ iOS (iPhone / iPad ควบคุมเครื่องอื่นได้อย่างเดียว ถูกควบคุมไม่ได้)

ดาวน์โหลดได้จาก[หน้าติดต่อ](https://www.leotun.com/th/contact#downloads) ที่ "ศูนย์ดาวน์โหลด" → "ความช่วยเหลือระยะไกล" หรือจากเว็บทางการ rustdesk.com อย่าใช้เว็บดาวน์โหลดของบุคคลที่สามจากผลการค้นหา ทั้งสองฝั่งของเซสชันต้องติดตั้ง

## ติดตั้งแล้วต้องอนุญาตอะไร

| ระบบ | ต้องทำอะไร |
|---|---|
| macOS | ใน "การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย" (System Settings → Privacy & Security) ติ๊ก RustDesk ทั้งใต้ "การบันทึกหน้าจอ" (Screen Recording) และ "การช่วยการเข้าถึง" (Accessibility) แล้วปิดโปรแกรมให้สนิทและเปิดใหม่ ถ้าให้สิทธิ์แค่อย่างเดียวจะเจออาการ "เห็นแต่ควบคุมไม่ได้" หรือจอดำสนิท ถ้าขึ้นว่า "เสียหาย" ดู[06](06-antivirus-false-positive.md) |
| Android | ตอนรับความช่วยเหลือ แตะ "Start service" (เริ่มบริการ) ใน RustDesk แล้วอนุญาตการบันทึกหน้าจอ ถ้าจะให้ซัพพอร์ตแตะบนหน้าจอคุณได้ ต้องเปิด RustDesk ใน "การช่วยเหลือพิเศษ" (Accessibility) ของระบบด้วย |
| Windows / Linux | ปกติติดตั้งแล้วใช้ได้เลย |

## เชื่อมต่อกับเซิร์ฟเวอร์ของเราเอง

ความช่วยเหลือระยะไกลวิ่งผ่านเซิร์ฟเวอร์ RustDesk ที่เว็บไซต์นี้ตั้งเอง ซึ่งเชื่อมต่อจากในจีนได้นิ่งเช่นกัน **ทั้งสองฝั่งของเซสชันต้องนำเข้าหนึ่งครั้ง** สองฝั่งจะหากันเจอก็ต่อเมื่อใช้เซิร์ฟเวอร์เดียวกัน:

1. ล็อกอินเว็บไซต์ก่อน แล้วใน[หน้าติดต่อ](https://www.leotun.com/th/contact#downloads) ไปที่ "ศูนย์ดาวน์โหลด" → "ความช่วยเหลือระยะไกล" → "เชื่อมต่อกับเซิร์ฟเวอร์ของเรา" แล้วคลิก "คัดลอก"
2. บนคอมพิวเตอร์ เปิด RustDesk "Settings → Network" (การตั้งค่า → เครือข่าย) คลิก "Unlock network settings" (ปลดล็อกการตั้งค่าเครือข่าย) ก่อน แล้วคลิก "ID/Relay server" (เซิร์ฟเวอร์ ID/Relay) บนมือถืออยู่ที่ "Settings → ID/Relay server"
3. ในหน้าต่างที่เด้งขึ้นมา คลิกไอคอนคลิปบอร์ดมุมขวาบน (บนมือถือแตะ "Import" (นำเข้า)) การตั้งค่าจะถูกกรอกให้เอง แล้วคลิก "OK"

**อย่าวางการตั้งค่าลงในช่องกรอกข้อมูล** จะขึ้น "failed to lookup address" (หาที่อยู่ไม่เจอ) การตั้งค่านี้ใช้กับบัญชีของเว็บไซต์นี้เท่านั้น อย่าส่งต่อ

## ส่ง ID และรหัสผ่านใช้ครั้งเดียวให้ซัพพอร์ต

เปิด RustDesk หน้าหลักจะแสดง ID ของเครื่องนี้และรหัสผ่านใช้ครั้งเดียว ก่อนส่งให้ใคร เช็กสามข้อนี้:

1. **คุณเป็นฝ่ายถามก่อน** คุณเล่าปัญหาในกลุ่มทางการที่อยู่ใน[หน้าติดต่อ](https://www.leotun.com/th/contact?utm_source=github&utm_content=troubleshooting-09) และซัพพอร์ตเห็นว่าต้องใช้ความช่วยเหลือระยะไกล แล้วค่อยไปขั้นต่อไป ซัพพอร์ตของเราจะไม่ทักมาเอง ไม่ขอให้ติดตั้งโปรแกรมรีโมต และไม่ขอรหัสเชื่อมต่อ ใครทักมาขอก็ตาม ให้ยืนยันในกลุ่มทางการก่อน
2. **ส่งผ่านช่องทางซัพพอร์ตทางการเท่านั้น**: ช่องทางติดต่อเจ้าหน้าที่ที่อยู่ในหน้าติดต่อ แชตส่วนตัวนอกกลุ่มที่อ้างว่าเป็น "ซัพพอร์ต LeoTun" ไม่ใช่เรา
3. **อย่าโพสต์ในกลุ่ม** กลุ่มเป็นที่ที่คนเห็นเยอะ ID กับรหัสผ่านก็เหมือนเอากุญแจคอมพิวเตอร์ไปแปะไว้หน้าประตู

## ระหว่างเซสชัน

- ตลอดเซสชันคุณเห็นว่ากำลังทำอะไรบนหน้าจอ และตัดการเชื่อมต่อในหน้าต่าง RustDesk ได้ทุกเมื่อ
- ถ้ามีคนขอให้ย่อหน้าต่าง ลุกออกจากคอมพิวเตอร์ หรือเปิดธนาคารออนไลน์หรือแอปชำระเงิน **ตัดการเชื่อมต่อทันที**
- ถ้าต้องใส่รหัสผ่านบัญชี ให้พิมพ์เอง อย่าอ่านให้ซัพพอร์ตฟัง

## เอาสิทธิ์คืนหลังเสร็จ

1. คลิกตัดการเชื่อมต่อในหน้าต่าง RustDesk และดูให้แน่ใจว่าอีกฝั่งออฟไลน์แล้ว
2. รีเฟรชรหัสผ่านใช้ครั้งเดียว ให้รหัสที่เพิ่งส่งไปใช้ไม่ได้
3. ปิด RustDesk ถ้าไม่ต้องใช้แล้วก็ถอนการติดตั้งได้เลย ครั้งหน้าค่อยดาวน์โหลดใหม่

## เราเตอร์: คุณต้องทำอะไร

เราเตอร์ที่ใช้เฟิร์มแวร์ของเว็บไซต์นี้ ไม่ต้องติดตั้งโปรแกรมรีโมตใดๆ บนเราเตอร์หรือคอมพิวเตอร์ และไม่ต้องส่งรหัสผ่านหน้าแอดมินเราเตอร์ให้ซัพพอร์ต สิ่งที่ต้องทำมีแค่:

- เปิดเราเตอร์ไว้ เสียบสายเน็ตไว้ และล็อกอินบัญชีไว้บนเราเตอร์
- บอกบัญชี รุ่นเราเตอร์ และอาการในกลุ่มทางการ ที่เหลือซัพพอร์ตจัดการเอง
- ระหว่างที่กำลังแก้ อย่าถอดปลั๊กรีสตาร์ตซ้ำๆ เว้นแต่ซัพพอร์ตบอกให้ทำ

## คำถามที่พบบ่อย

**ซัพพอร์ตจะทักแชตส่วนตัวมาเองแล้วบอกให้ติดตั้งโปรแกรมรีโมตไหม?** ไม่ เมื่อไรที่มีคนทักมาเองโดยคุณไม่ได้ถาม ให้ยืนยันตัวตนในกลุ่มทางการก่อนทุกครั้ง

**นำเข้าแล้วขึ้น "failed to lookup address"?** ส่วนใหญ่เป็นเพราะวางการตั้งค่าลงในช่องกรอกข้อมูล ล้างช่องเหล่านั้น กลับไปที่หน้าต่าง "ID/Relay server" แล้วนำเข้าด้วยการคลิกไอคอนคลิปบอร์ดมุมขวาบน

**บน macOS เชื่อมต่อได้แต่จอดำ หรือเห็นแต่ควบคุมไม่ได้?** สิทธิ์ไม่ครบ ติ๊กทั้ง "การบันทึกหน้าจอ" และ "การช่วยการเข้าถึง" แล้วปิดโปรแกรมให้สนิทและเปิดใหม่

**จบเซสชันแล้วต้องทำอะไรอีก?** ตัดการเชื่อมต่อ รีเฟรชรหัสผ่านใช้ครั้งเดียว ปิดโปรแกรม ทำครบสามขั้นนี้แล้ว อีกฝั่งจะเชื่อมต่อเข้ามาอีกไม่ได้
