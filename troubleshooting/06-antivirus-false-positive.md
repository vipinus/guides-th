# 06 · Mac แจ้งว่าแอป "เสียหาย" ทำอย่างไร

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/antivirus-false-positive?utm_source=github&utm_content=troubleshooting-06

สรุปก่อน: ไฟล์ไม่ได้เสีย และไม่มีใครแก้ไขมัน เมื่อดับเบิลคลิก Hiddify บน Mac แล้วขึ้นว่า "เสียหายและไม่สามารถเปิดได้" หรือ "ไม่สามารถตรวจสอบนักพัฒนาได้" นั่นคือ Gatekeeper ของระบบกำลังบล็อกอยู่ ทำตามขั้นตอนด้านล่างเพื่ออนุญาต

ติดตั้ง Hiddify บน Windows ตอนนี้ไม่มีการแจ้งเตือนไวรัสแล้วในการทดสอบล่าสุดของเรา ถ้าโปรแกรมแอนตี้ไวรัสที่คุณติดตั้งไว้ยังแจ้งเตือนอยู่ ให้ทำตามลำดับเดียวกันนี้: ตรวจสอบก่อน แล้วค่อยอนุญาต

## ทำไมถึงถูกบล็อก

**ไฟล์ที่ดาวน์โหลดจากหน้าเว็บจะถูกติดป้ายกักกัน (quarantine)** เมื่อ Gatekeeper ของ macOS เห็นป้ายนี้ ก็จะบล็อกแอป ข้อความบางครั้งบอกว่า "เสียหาย" บางครั้งบอกว่า "ไม่สามารถตรวจสอบนักพัฒนาได้" แต่สาเหตุเดียวกัน

สิ่งที่เราทำ: ไคลเอนต์บนเดสก์ท็อปเป็น**สำเนาที่ไม่ได้แก้ไข**ของแพ็กเกจที่โปรเจกต์โอเพนซอร์สต้นทางปล่อยออกมา เราไม่ได้แก้ ไม่ได้แพ็กใหม่ ไม่ได้ฝังอะไรเข้าไป แค่วางไว้บนเว็บดาวน์โหลดของเราเพื่อให้ดาวน์โหลดง่ายขึ้น

## ตรวจสอบเองก่อน อย่าอนุญาตแบบไม่ดูอะไรเลย

การอนุญาตแอปหมายความว่าระบบจะเลิกตรวจมัน ลำดับจึงต้องเป็นตรวจสอบก่อน แล้วค่อยอนุญาต

**อัปโหลดขึ้น VirusTotal เพื่อตรวจซ้ำ** ลากไฟล์ติดตั้งไปวางที่ [virustotal.com](https://virustotal.com/gui/home/upload) ถ้ามีเอนจินแบบฮิวริสติกไม่กี่ตัวแจ้งเตือน แต่ค่ายหลักผ่านหมด นั่นคือรูปแบบทั่วไปของการแจ้งเตือนผิด ถ้าเอนจินค่ายหลักส่วนใหญ่แจ้งเตือน **อย่าติดตั้ง** ติดต่อเรามาเลย

ผ่านการตรวจแล้วค่อยทำต่อ ถ้าไม่แน่ใจ ติดต่อซัพพอร์ตก่อน เราจะตรวจเว็บดาวน์โหลดให้

## สามวิธีอนุญาต จากแคบไปกว้าง

หลังดับเบิลคลิกอาจเห็น ""ชื่อไคลเอนต์" เสียหายและไม่สามารถเปิดได้ คุณควรย้ายไปที่ถังขยะ" หรือ "ไม่สามารถเปิดได้เนื่องจากไม่สามารถตรวจสอบนักพัฒนาได้" สามขั้นตอนด้านล่างเรียงจากแคบไปกว้าง **ถ้าขั้นแรกได้ผลแล้ว อย่าใช้ขั้นที่สาม**

1. ใน Finder ไปที่ "แอปพลิเคชัน" (Applications) กด Control ค้างแล้วคลิกไอคอน (หรือคลิกขวา) เลือก "เปิด" (Open) แล้วคลิก "เปิด" อีกครั้งในหน้าต่างที่ขึ้นมา นี่คือการอนุญาตครั้งเดียวเฉพาะแอปนี้แอปเดียว
2. ถ้าเมนูคลิกขวาไม่มี "เปิด" ที่ใช้ได้ ให้ไปที่ "การตั้งค่าระบบ" (System Settings) → "ความเป็นส่วนตัวและความปลอดภัย" (Privacy & Security) แล้วเลื่อนลงไปที่ส่วนความปลอดภัย จะเห็นข้อความว่า ""ชื่อไคลเอนต์" ถูกบล็อกไม่ให้ใช้งานเนื่องจากไม่ได้มาจากนักพัฒนาที่ระบุตัวตนได้" คลิก "เปิดอยู่ดี" (Open Anyway) ทางขวา แล้วใส่รหัสผ่านเพื่อยืนยัน
3. ถ้าข้อความบอกว่า "เสียหาย" สองขั้นแรกมักไม่ได้ผล เปิด "เทอร์มินัล" (Terminal) แล้วรัน `sudo xattr -dr com.apple.quarantine` ตามด้วยพาธของแอป (ปกติคือ `.app` ใต้ `/Applications/`) กด Return ใส่รหัสผ่านที่ใช้ล็อกอิน แล้วเปิดแอปอีกครั้ง คำสั่งนี้ทำแค่ลบป้ายกักกันที่บอกแหล่งที่มาของการดาวน์โหลด

ตอนเปิดครั้งแรก ระบบจะขอรหัสผ่านเพื่ออนุญาตให้ติดตั้งส่วนขยายเครือข่ายด้วย แอปจะรับทราฟฟิกได้ก็ต่อเมื่อคุณกดยอมรับแล้ว

ข้อควรจำบางข้อ:

- ใช้คำสั่ง `xattr` **เฉพาะกับไฟล์ที่ตรวจสอบแหล่งที่มาแล้ว**เท่านั้น วิธีตรวจดูหัวข้อก่อนหน้า
- **อย่า**ใช้ `sudo spctl --master-disable` ปิด Gatekeeper ทั้งระบบ นั่นคือการปิดการป้องกันทั้งเครื่อง ขณะที่คลิกขวาแล้วเปิดมีผลแค่แอปเดียว
- ตั้งแต่ macOS 15 Apple เข้มงวดเรื่องคลิกขวาแล้วเปิดมากขึ้น ส่วนใหญ่ต้องไปทางขั้น "การตั้งค่าระบบ" นี่คือพฤติกรรมของระบบที่เปลี่ยนไป ไม่ใช่ปัญหาของแพ็กเกจเรา
- Mac ที่บริษัทแจกมักถูกควบคุมด้วยโปรไฟล์ MDM ทั้งสามขั้นด้านบนอาจถูกปิดไว้ อย่าฝืน ให้ใช้สามตัวเลือกด้านล่าง

## ไม่อยากอนุญาต? ใช้หนึ่งในสามตัวนี้

ไคลเอนต์ของพวกนี้**ดับเบิลคลิกบน macOS ก็ใช้ได้เลย** ไม่มีข้อความด้านบนสักข้อ ใช้บัญชีเดียวกัน ไม่ต้องจ่ายเพิ่ม:

- **เครือข่ายส่วนตัว (ไคลเอนต์ Tailscale ทางการ)**: ติดตั้งเสร็จก็ใช้ได้ เหมาะกับการเปิดค้างไว้ระยะยาว
- **OpenVPN Connect**: ไฟล์ติดตั้งของ OpenVPN เอง แค่นำเข้าการตั้งค่า
- **Cisco Secure Client**: ไคลเอนต์ระดับองค์กร คอมพิวเตอร์บริษัทหลายเครื่องติดตั้งไว้แล้ว

## คำถามที่พบบ่อย

**โปรแกรมของคุณมีไวรัสจริงไหม?**
ไม่มี มันคือสำเนาที่ไม่ได้แก้ไขของแพ็กเกจทางการที่โปรเจกต์โอเพนซอร์สต้นทางปล่อยออกมา แต่คุณไม่ควรเชื่อเราเฉยๆ วิธีตรวจเองอยู่ด้านบนแล้ว: อัปโหลดขึ้น VirusTotal แล้วดูว่าผลของแต่ละเอนจินกระจายตัวอย่างไร

**บน Windows จะยังถูกแจ้งเตือนไหม?**
ตอนนี้ ในการทดสอบของเรา ศูนย์ความปลอดภัยที่มากับ Windows ไม่แจ้งเตือนการติดตั้ง Hiddify แล้ว ถ้าโปรแกรมแอนตี้ไวรัสที่คุณติดตั้งไว้ยังแจ้งเตือน ให้อัปโหลดขึ้น VirusTotal ตรวจซ้ำก่อน ผ่านแล้วค่อยตั้งโฟลเดอร์ติดตั้งของ Hiddify เป็นที่เชื่อถือได้ในโปรแกรมแอนตี้ไวรัส อย่าปิดการป้องกันแบบเรียลไทม์เพื่อติดตั้ง

**ติดตั้งบน Mac แล้วเปิดไม่ได้ ไฟล์ดาวน์โหลดเสียหรือเปล่า?**
ไม่ได้เสีย เปิดไม่ได้เพราะ Gatekeeper บล็อกอยู่ ใช้สามวิธีอนุญาตด้านบนจัดการ

**ควรติดตั้งแอนตี้ไวรัสบน Mac ด้วยไหม?**
ไม่ต้อง สิ่งที่บล็อกคุณบน macOS คือ Gatekeeper ที่มากับระบบ ไม่ใช่โปรแกรมแอนตี้ไวรัส ติดตั้งแอนตี้ไวรัสของเจ้าอื่นก็ไม่ทำให้ข้อความนี้หายไป และอาจเพิ่มการบล็อกใหม่เข้ามาอีก

**บนมือถือจะเจอปัญหานี้ไหม?**
บน iOS ติดตั้งจาก App Store ไม่มีปัญหานี้ Android บางครั้งเตือนเรื่องแหล่งที่ไม่รู้จัก กดอนุญาตก็พอ
