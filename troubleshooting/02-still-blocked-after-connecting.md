# 02 · เชื่อมต่อเข้าจีนแล้วแต่ยังดูไม่ได้ ทำอย่างไร

ไล่เช็กตามลำดับ แต่ละข้อใช้เวลาไม่ถึงนาที

1. **ดูว่า IP ขาออกเปลี่ยนจริงหรือยัง** เปิดเว็บที่บอกตำแหน่ง IP ในเบราว์เซอร์ แล้วดูว่าเป็นจีนแผ่นดินใหญ่หรือไม่ ถ้าไม่ใช่ แปลว่า VPN ยังไม่ทำงาน ให้เชื่อมต่อใหม่
2. **IPv6 และ DNS รั่ว** ถ้า IP ขาออกถูกแล้วแต่เว็บยังมองว่าคุณอยู่ต่างประเทศ ส่วนใหญ่เป็นเพราะ IPv6 หรือ DNS ในเครื่องวิ่งอ้อม VPN ออกไป กรณีนี้พบบ่อยที่สุด และมีบทความแยกไว้แล้ว: [03 · IPv6 และ DNS คือช่องที่หลุดออกไป](03-ipv6-and-dns-leak.md)
3. **แคชของแอป** แอปวิดีโอและเพลงจะจำผลการเช็กภูมิภาคไว้ ให้ปิดแอปให้สนิทแล้วเปิดใหม่ ถ้ายังไม่ได้ ให้ล้างข้อมูลแอป
4. **เวอร์ชันของแอป** ถ้าติดตั้งเวอร์ชันสากล (iQIYI, WeTV) คลังเนื้อหาจะไม่เหมือนกัน ให้เปลี่ยนไปใช้เวอร์ชันจีนแผ่นดินใหญ่
5. **ภูมิภาคที่สมัครบัญชี** บางแพลตฟอร์มจำกัดเนื้อหาตามภูมิภาคที่ใช้สมัครบัญชี ไม่ว่าตอนนี้ IP จะอยู่ที่ไหน กรณีนี้แก้ได้ทางเดียวคือใช้บัญชีอื่น
6. **ภูมิภาคและภาษาของระบบ** บางแอปอ่านค่าภูมิภาคของระบบ ให้เปลี่ยนภูมิภาคของระบบเป็นจีนแล้วลองใหม่
7. **จุดเชื่อมต่อ** เนื้อหาบางอย่างต่างกันตาม IP ของแต่ละมณฑลด้วย ให้เปลี่ยนไปใช้จุดเชื่อมต่ออื่นแล้วลองใหม่

## ยังไม่ได้อยู่ดี

บอกซัพพอร์ตสี่อย่างนี้: เว็บไซต์หรือแอปที่จะใช้ ข้อความแจ้งข้อผิดพลาดแบบคำต่อคำ ตำแหน่งของ IP ขาออกตอนนี้ และวิธีเชื่อมต่อที่ใช้อยู่ มีครบสี่อย่างนี้ก็หาต้นเหตุได้ในรอบเดียว
