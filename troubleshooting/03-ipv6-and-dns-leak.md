# 03 · เชื่อมต่อแล้ว แต่เว็บวิดีโอยังขึ้นแจ้งเรื่องลิขสิทธิ์: IPv6 และ DNS คือช่องที่หลุดออกไป

> ฉบับบนเว็บไซต์ (ละเอียดกว่า): https://www.leotun.com/th/guides/overseas-video?utm_source=github&utm_content=troubleshooting-03

คุณผ่านขั้นที่ 1 ของ [02 · เชื่อมต่อเข้าจีนแล้วแต่ยังดูไม่ได้](02-still-blocked-after-connecting.md) แล้ว — IP ขาออกเช็กแล้วเป็นจีนแผ่นดินใหญ่ — แต่เว็บยังขึ้นว่า "ไม่สามารถเล่นได้เนื่องจากข้อจำกัดด้านลิขสิทธิ์" เก้าในสิบครั้ง ในเครื่องยังมีช่องทางหนึ่งที่ไม่ผ่าน VPN: **IPv6** หรือ **DNS** เว็บวิดีโอตัดสินว่าคุณอยู่ที่ไหนจากที่อยู่ที่มันเห็น ขอแค่มีช่องหนึ่งหลุดออกไป สิ่งที่มันเห็นก็ยังเป็นต่างประเทศ

## ทำไมถึงหลุด

- อุปกรณ์สมัยนี้มีทั้งที่อยู่ IPv4 และ IPv6 และเบราว์เซอร์ชอบใช้ IPv6 ก่อน ถ้า VPN ดูแลแค่ IPv4 คำขอทาง IPv6 จะออกไปทางเน็ตบ้านโดยตรง
- "DNS ที่ปลอดภัย" ในตัวเบราว์เซอร์ "DNS ส่วนตัว" (Private DNS) ของ Android หรือเครื่องมือ mesh network ตัวอื่นที่เปิดอยู่ (Tailscale และอื่นๆ) ล้วนแย่งทำหน้าที่ค้นหาชื่อโดเมนก่อน VPN

"เชื่อมต่อแล้ว" แปลว่าอุโมงค์ถูกสร้างขึ้นแล้วเท่านั้น ไม่ได้แปลว่าทราฟฟิกทั้งหมดวิ่งผ่านอุโมงค์

## ตรวจห้าขั้น

1. **ตรวจ IPv6** หลังเชื่อมต่อ ค้นหาคำว่า "test ipv6" แล้วเปิดหน้าทดสอบ ถ้าช่อง IPv6 แสดงที่อยู่ในประเทศที่คุณอยู่ → ปัญหาอยู่ตรงนี้ ไปขั้นที่ 2 ถ้าทั้งสองช่องแสดงจีนแผ่นดินใหญ่ หรือ IPv6 ใช้ไม่ได้ → ไปขั้นที่ 3
2. **ปิด IPv6 หรือเปลี่ยนไปใช้ไคลเอนต์ที่บล็อก IPv6** Windows: ในคุณสมบัติของอะแดปเตอร์เครือข่าย เอาติ๊ก "Internet Protocol Version 6" ออก macOS: การตั้งค่าเครือข่าย → TCP/IP → ตั้ง IPv6 เป็น "เฉพาะลิงก์โลคัล" (Link-local only) มือถือ: ปิด Wi‑Fi แล้วลองด้วยเน็ตมือถือหนึ่งครั้ง เน็ตบ้านมักมี IPv6 ส่วนเน็ตมือถือของผู้ให้บริการมักไม่มี
3. **ตรวจ DNS** Chrome การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → ปิด "ใช้ DNS ที่ปลอดภัย" บน Android ปิด "DNS ส่วนตัว" และปิด VPN ตัวอื่น เครื่องมือ mesh network และส่วนขยายพร็อกซีให้หมด
4. **ปิดแอปให้สนิทแล้วเปิดใหม่ ถ้าเป็นเวอร์ชันเว็บให้ล้างข้อมูลเว็บไซต์** แพลตฟอร์มจะจำผลตรวจภูมิภาคครั้งก่อนไว้
5. **เปลี่ยนไปจุดเข้าอื่นแล้วลองใหม่** ที่อยู่ของขาออกบางตัวอาจเพิ่งถูกแพลตฟอร์มตั้งธงไว้

## LeoTun จัดการเรื่องนี้อย่างไร

ตั้งแต่กันยายน 2026 ทั้งสามวิธีเชื่อมต่อของ LeoTun (Hiddify, Cisco AnyConnect, OpenVPN) ปฏิเสธ IPv6 ตั้งแต่ในอุโมงค์ และส่งการตั้งค่า DNS ที่บังคับให้ค้นหาชื่อในอุโมงค์ — ไม่ต้องเปลี่ยนการตั้งค่าอะไรในเครื่องคุณ **การตั้งค่า Hiddify ที่นำเข้าก่อนกันยายนยังไม่มีกฎนี้ ให้ลบแล้วสแกน QR โค้ดนำเข้าใหม่**

ถ้าใช้เราเตอร์จะไม่หลุดตั้งแต่ต้น: ทั้ง LAN ออกผ่านเราเตอร์ IPv6 และ DNS ของอุปกรณ์จึงไม่มีทางออกไปข้างนอกเอง

## กรณีที่ยังขึ้นแจ้งเตือนอยู่

| กรณี | อาการ | แก้อย่างไร |
|---|---|---|
| ขาออกไม่ใช่จีนแผ่นดินใหญ่ | เช็ก IP แล้วขึ้นฮ่องกง / ไต้หวัน / ญี่ปุ่น | เปลี่ยนไปจุดเข้าจีน ที่อยู่ฮ่องกงและไต้หวันก็นับเป็นต่างประเทศสำหรับ Tencent และ iQIYI |
| กฎแยกเส้นทางที่ตั้งเองกำหนดโดเมนวิดีโอเป็น "ต่อตรง" | หน้าเว็บเปิดได้ แต่วิดีโอเล่นไม่ได้ | เปลี่ยนโดเมนจีนให้ผ่านโหนด ผู้ใช้ในต่างประเทศไม่ควรเปิด "ต่อตรงสำหรับจีน" |
| ใช้เว็บพร็อกซีอยู่ | ในเบราว์เซอร์ได้ ในแอปไม่ได้ | ดูวิดีโอต้องใช้อุโมงค์แบบทั้งเครื่อง เว็บพร็อกซีครอบคลุมแค่เบราว์เซอร์ |
